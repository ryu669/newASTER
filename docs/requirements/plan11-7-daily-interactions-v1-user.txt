# Plan11-7 日常交流・共通特性システム 実装仕様 v1.0

目的： 11-2の箱庭生活AI、11-3の好感度システムを利用し、200人以上のヒロインへ多様な日常交流・デートを効率よく追加できる基盤を構築する。

## 1. コンテンツ構成

| 種類      | 初期目標     |
| ------- | -------- |
| 共通交流パーツ | 20       |
| 単独特性交流  | 20       |
| 特性ペア交流  | 20       |
| 汎用デート   | 5        |
| 反応スタイル  | 8        |
| 生活催事    | 既存10種を利用 |

共通・特性交流60件は台詞なしでも成立する演出を必須とする。

人物専用台詞・デート・イベントはヒロイン実装側で追加し、登録数に上限を設けない。

## 2. 特性8枠

表示・登録順：

ジョブ共通特性 → キャラ固有特性 → 交流特性

標準配分は2＋3＋3。枠数は固定しない。

- 最大8枠
- 交流特性は標準3枠
- 交流特性自体に能力効果なし
- 戦闘条件では表示特性のみ参照
- 日常交流では表示特性＋プロフィール属性を参照
- 特性とイラストの一致は必須ではない
- 同一ID重複は禁止

## 3. 反応スタイル

初期8種類：

積極的、控えめ、クール、甘えん坊、上品、豪快、天然、小悪魔。

人物ごとに、

- メイン1つ必須
- サブ0～1つ
- メイン70%、サブ30%
- サブなしはメイン100%
- 形態別上書き可能
- 好感度Lvによる自動Weight変更なし
- 人物固有の条件付きWeight変更可能

反応スタイルは特性8枠を消費せず、戦闘能力に影響しない。

## 4. 交流候補の抽選

| 候補   | 基本Weight |
| ---- | -------- |
| 人物専用 | 100      |
| 特性ペア | 60       |
| 単独特性 | 35       |
| 共通   | 20       |

条件一致した全候補からWeight抽選する。

- 直近5件の同一交流：Weight×0.2
- 同じ話題の連続：Weight×0.5
- 候補1件なら再利用
- 特性ペアは主体・相手を区別
- 双方向交流は`symmetric=true`で定義

## 5. 交流条件

AND/OR条件式に対応。

参照可能な条件：

- 表示特性・プロフィール属性
- 好感度Lv・恋人状態
- 現在の衣装形態
- 庭・時間帯・天候
- Terraform Lv・極相
- 家具Interaction
- 参加人物・人数

低Lv交流は高Lvでも原則残すが、人物側で有効Lv範囲を指定可能とする。

## 6. 交流パーツ

1パーツ5～20秒を制作目安とする。

```
DailyInteractionDef {
    string id;
    string category;
    string[] topicTags;
    InteractionCondition[] conditions;
    string presentationId;
    string scriptId; // 任意
    int weight;
    bool replayable;
}
```

演出解決順：

人物専用 → 反応スタイル専用 → 共通 → 簡易表示

必要演出能力：

`gaze / expression / gesture / pair_position / furniture_use / contact / special_pose`

不足時は共通動作・状況説明へフォールバックする。

人物固有台詞がない場合、勝手に口調を生成しない。

## 7. 交流パーツの連続再生

同一Session内では、

- 人物位置・向き
- 表情
- 家具利用状態
- 主人公との距離感

を引き継ぐ。

次パーツの開始条件と合わない場合、短い移動・待機演出を挟む。

必要に応じ0～2秒の`pause`を挿入する。

同一デート内での同一パーツ再使用は原則避ける。

## 8. 汎用デート

初期5種類：

散歩・食事・星見・お茶・水辺

基本条件：好感度Lv10以上。

進行：

`開始 → 交流パーツ1～2個 → 終了`

- 主人公＋ヒロイン1人
- 1～3分程度
- 選択肢は最大3択を目安
- 正解・失敗・好感度減少なし
- 何度でも再生可能
- 完了時に好感度EXP+5
- 回想登録は人物専用デートを基本とする

人物専用デートはヒロイン実装側で自由に追加可能。

## 9. 11-2・11-3連携

| 交流       | EXP |
| -------- | --- |
| 自律Social | 0   |
| 主人公との会話  | +5  |
| 一緒に過ごす   | +5  |
| デート完了    | +5  |
| 生活催事参加   | +5  |
| 回想       | 0   |

同一交流の連続取得は11-3の逓減ルールを適用。

11-7は交流完了を通知するだけで、EXP計算・好感度保存を直接行わない。

11-2の通常Socialは最大2人。3人以上は生活催事または専用イベントで扱う。

## 10. セッション管理

交流開始時に対象人物の生活AIを一時停止。

- InteractionSlotを排他確保
- 交流終了時に解放
- 戦闘・ADV・Terraform変更時は安全終了
- デート途中キャンセルはEXPなし
- 回想では進行・報酬を変更しない
- 交流完了報酬の二重付与を禁止

デート進行・直近交流履歴・一時演出状態は通常セーブしない。
