# 2D表現の要求と変更範囲

更新：2026-10-02。状態：現行要求。数量・禁止事項は[ゲーム要求](game.md)を優先。詳細動作をここへ重複定義しません。

## 維持する体験とシステム

世界記憶・15巨神獣・本体＋4〜6部位・5人戦闘・詩・育成・箱庭・万物の書・装備の樹・交流を維持します。通常行動は速度順、チェインは通常行動順と独立した自動固定行動です。動作の定義元は[戦闘](../systems/battle.md)と[速度](../systems/battle-timing.md)です。

## 2D化する表現

人物は立ち絵・表情差分・戦闘絵・カットイン、巨神獣は本体と部位レイヤー・破壊差分、背景は絵と視差・拡縮・パンで表現します。箱庭は背景・人物SDまたは立ち絵・家具、ADVは背景・立ち絵・表情・CGを用います。万物の書・しおり・装備の樹は意味を維持して2D表示します。

詳細は[戦闘表示](../presentation/battle.md)、[箱庭・ADV表示](../presentation/garden-and-adv.md)、[素材契約](../presentation/assets.md)を参照します。

## 廃止と履歴の境界

3D人体・敵・家具モデル、FBX、リグ、物理髪、LOD、3D撮影を正式完成必須工程から廃止します。古いブラウザゲームは廃棄対象で、比較・移植fixtureへの一致を要求しません。参考動画は攻撃テンポ・予告・ヒット・尺の観察資料であり、画像・モデル・文章・音を転用しません。

今回は文書のみを整理し、既存Unity、制作素材、試作ファイル、セーブ形式の削除・変更・復元は行いません。ローカルの実装修正は後続作業です。
