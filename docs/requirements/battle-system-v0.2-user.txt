# newASTER 戦闘システム実装仕様 v0.2

## 1. 基本方針

戦闘は**5人編成＋巨神獣1体を基本とする時間軸型コマンドバトル**。

プレイヤーの基本操作は、

**ヒロインREADY**
→ 時間停止
→ **本人の3スキルから1つ選択**
→ 必要ならジョブ固有操作を設定
→ 行動
→ WT設定
→ 時間再開

とする。

旧検討案の「15スキル→7提示→3選択」は**不採用**。

狙いは、

- 各ヒロインを直接操作する感覚
- 推しを活躍させやすい
- ジョブ固有システムを主役にする
- 速度・WT・詠唱を戦術として成立させる

こと。

---

# 2. 論理時間

既存PR #11の論理時刻`Clock`を継続使用。

現行計算式：

`Delay = ceil(10000 × TimePercent / (Speed × 100))`

を基礎とする。

### 暫定時間係数

| 基準値 | 用途 |
|---:|---|
| 0 | 即時 |
| 25 | 極短 |
| 50 | 短 |
| 75 | やや短 |
| 100 | 標準 |
| 125 | やや長 |
| 150 | 長 |
| 200 | 超長 |

正式バランスはTBD。

---

# 3. Battle Turn

**論理時刻100経過 = 1 Battle Turn**

とする。

キャラクターの行動回数とは独立。

例えば、

`Clock 85 → 125`

ならClock 100を跨ぐため1ターン経過。

`Clock 190 → 310`

なら200・300を跨ぐため2ターン経過。

### Battle Turnを使用するもの

- バフ・デバフ持続
- 状態異常持続
- アーティスト歌唱
- パンツァー生身復帰
- ファイター強化時間
- バーサーカー二重発動時間
- その他「○ターン」の効果

---

# 4. READY

味方WTが0になるとREADY。

READY中は、

**Clock完全停止。**

敵・他味方・詠唱・Battle Turnも進まない。

基本コマンド：

- Skill 1
- Skill 2
- Skill 3
- PASS
- ジョブ固有操作

ジョブ状態によってコマンドを制限できる。

---

# 5. PASS

通常ヒロインはPASS可能。

### 暫定値

**基準WT 25**

### PASS時

- 攻撃なし
- スキルなし
- 行動由来リソース獲得なし
- 通常スキルより短いWT
- Clockは再開する

したがってPASS後には敵・詠唱・Battle Turn等が通常進行する。

---

# 6. 詠唱

既存実装を継続。

スキル選択
→ コスト確定
→ Cast予約
→ 時間再開
→ Cast時間経過
→ 発動
→ Recovery WT開始

とする。

**CastとRecoveryは別々に計算する。**

詠唱中は本人への通常コマンド受付なし。

---

# 7. 巨神獣

巨神獣にも**Speed**を持たせる。

味方と同じ論理時間軸で次回行動を決定。

巨神獣には、

- Speed
- HP
- 物理／魔法防御
- 12属性弱点・耐性
- 状態異常耐性
- BREAK
- 部位
- 行動予兆
- フェーズ
- 特殊攻略条件

を持たせる方向。

正式数値TBD。

# 8. ファイター

### 固有状態

- ブースト珠
- BOOSTゲージ
- 通常モード／捨て身モード

### ブースト珠

スキル使用時に任意数消費。

**1個消費するごとにスキルダメージ増加。**

同時にBOOSTゲージ増加。

最大所持数・倍率TBD。

### BOOSTゲージ

MAX時に任意消費。

一定Battle Turn、

**全能力UP。**

### 捨て身モード

READY時等に切替可能。

**攻撃UP**
**速度UP**
**最終被ダメージUP**

通常モードへ戻すことも可能。

### 目的

BOOST
＋捨て身
＋ブースト珠大量投入
＋BREAK等

を同時に合わせて**瞬間最大火力**を作る。

---

# 9. バーサーカー

### 捕食

攻撃成立ごとに発動。

戦闘中の**全ステータスを段階的に強化**。

上限TBD。

### 固有ゲージ

攻撃等で蓄積。

消費すると一定Battle Turn、

**スキル2回発動状態**

になる。

1回のコマンドで同一スキルを2回解決。

攻撃ならそれぞれ捕食判定を行う。

Recoveryは原則1コマンド分。

---

# 10. ディフェンダー

### 戦闘前設定

味方1人を**護衛対象**として指定。

### 通常かばう

以下を両方満たした場合に自動発動。

1. 護衛対象が敵攻撃の対象。
2. ディフェンダー自身が同じ攻撃の対象ではない。

護衛対象へ向かった攻撃分のみ肩代わり。

### 固有ゲージ

かばう等で蓄積。具体値TBD。

### MAX解放

一定Battle Turn、

**全体攻撃以外の味方への攻撃をすべて肩代わり。**

さらに、

**被攻撃ごとに自動反撃。**

全体攻撃はかばわない。

---

# 11. ブラスター

固有リソースを使用して、1回のスキルについて、

**Cast倍率**
＋
**発動回数**

を組み合わせる。

### Cast候補

- 0%：無詠唱・高コスト
- 50%：半詠唱
- 100%：通常
- 200%：倍詠唱＋威力強化

### 発動回数

- ×1
- ×2
- ×3

組み合わせに応じてリソース消費。

リソース最大値が高いほど強力な組み合わせが可能。

### 初期テスト用WT案

軽砲撃：
Cast 50 / Recovery 75

標準砲撃：
Cast 100 / Recovery 100

大砲撃：
Cast 150 / Recovery 125

多重発動でもRecoveryは原則1コマンド分。

---

# 12. ガンナー

### 二重資源

**弾倉**
＋
**バレットゲージ**

を別管理。

### 弾倉

複数所持可能。

スキル等で弾を消費。

### RELOAD

1行動を消費。

**所有する全弾倉を最大まで回復。**

### バレットゲージ

行動等で蓄積。

MAX時に、

## 全弾射撃

使用可能。

弾倉を1つ選択し、

**現在の残弾すべてを消費。**

残弾数が多いほど威力増加。

使用後、その弾倉は0。

---

# 13. ヒーラー

通常3スキルに回復技を持つ必要はない。

生命操作をジョブ固有能力として持つ。

### 固有リソース

消費して、

**固有リソース最大値そのものを増加**

できる。

### 使用候補

- 回復量増加
- 最大HPを超える回復
- 戦闘中最大HP増加
- 蘇生

具体コスト・上限TBD。

基本判断：

**今使うか、最大値へ投資するか。**

---

# 14. アーティスト

### 通常モード

Skill 1～3使用可能。

通常行動によって**歌唱ゲージ獲得**。

一定値以上で歌唱モードへ移行可能。

### 歌唱モード

- Skill 1～3選択不可
- 歌唱ゲージ獲得不可
- 1 Battle Turnごとにゲージ消費
- 味方全体へバフ
- 歌唱継続Battle Turnごとにバフ効果上昇

### READY

歌唱中も通常WTは進む。

本人READY時のみ、

**歌唱継続**
または
**歌唱解除**

を選択可能。

歌唱解除後は同じREADYで通常3スキル選択へ戻る方向。

### 人物特性

例外として、

- 歌唱開始時Skill 2自動発動
- Stage到達時特定スキル自動発動
- 歌唱終了時スキル発動

などを人物固有特性として許可。

これは「歌唱中のスキル選択」には数えない。

# 15. パンツァー

## 戦闘前

### アーマー

専用装備で、

- 属性耐性
- 物理耐性
- 魔法耐性

等を調整。

### ツール

**2枠。**

有限使用。

戦闘中に使用回数は回復しない。

効果例：

- ARMOR HP修復
- 自己バフ
- 味方バフ
- 味方全体のバフ持続延長

---

## アーマー状態

通常は**ARMOR HP**を使用。

通常ヒロインより非常に高耐久。

### 通常HP回復

**受け付けない。**

ARMOR HP回復はパンツァーツール等のみ。

Skill・Tool使用可能。

---

## ARMOR BREAK

ARMOR HP=0でアーマー喪失。

**生身状態**へ移行。

### 生身HP

他ジョブ通常HPの**約1/5程度**を初期調整目標とする。

極端に低耐久。

### 生身状態

使用可能：

**防御コマンドのみ。**

使用不可：

- Skill 1～3
- Tool
- PASS
- アーマー固有能力

通常HP回復スキルは**有効**。

### 防御

生身で巨神獣の通常攻撃を、

**おおむね一撃だけ耐えられる可能性がある**

程度を目標に調整。

大技等は防御しても基本的に致命的。

軽減率TBD。

### ARMOR CALL

ARMOR BREAKから、

**3 Battle Turn = Clock 300**

生存すると自動的に新アーマーを召喚し復帰。

復帰ARMOR HP量TBD。

消費済みToolは復活しない。

生身HPを再ARMOR BREAK時まで保持するかは実装前に最終確定TBD。

---

# 16. アルケミスト

### 固有リソース

個数として蓄積。

### 属性

人物ごとに、

**12属性中5属性**

を使用可能。

### 錬成

**行動を消費しない。**

現在リソースの範囲で、

- 使用属性
- 各属性への投入個数

を指定。

例：

`火×5`

または、

`火×2 / 雷×2 / 闇×1`

### 効果

属性種類＋投入個数によって、

- 攻撃
- 一時的弱点付与
- その他特殊効果

を決定。

---

# 17. チェイサー

### 固有ゲージ

Battle Turn等によって自然回復。

### GEAR

スキル使用時に選択。

**GEAR 1**
- 消費0
- 通常WT

**GEAR 2**
- リソース消費
- 次回WT短縮
- NITRO COUNT +1

**GEAR 3**
- 約2ターン分のリソース消費
- 次回WT大幅短縮
- NITRO COUNT +1

暫定テスト：

GEAR1 = 100%
GEAR2 = 60～70%
GEAR3 = 30～40%

### NITRO

COUNT 5で使用可能。

5消費して、

**WT=0**

→ 即READY。

### IGNITION

攻撃対象へFlag +1。

3到達時、

## OVER IGNITION

自動発動。

敵全体へ大ダメージ後、Flag消費。

---

# 18. スナイパー

### 戦闘前

味方1人を援護対象に指定。

### 通常

指定味方が攻撃すると自動追撃。

### 固有ゲージ

自身の行動等で蓄積。

MAXで狙撃モード発動可能。

### 狙撃モード

詠唱開始。

詠唱中、

**追撃対象を味方全員へ拡大。**

詠唱完了時、

**超高火力狙撃**

発動。

その後通常状態へ戻る。

---

# 19. ギャンブラー

固有リソースなし。

通常3スキルを直接選択せず、

## SLOT

のみ。

### 盤面

3×3。

判定：

- 横3ライン
- 斜め2ライン

計5ライン。

### 絵柄

- 果物
- Skill 1
- Skill 2
- Skill 3
- 7
- その他TBD

### Skill判定

各ラインの**左位置＋中央位置**が同一Skill
→ 通常発動。

3つ一致
→ 強化発動。

斜めにも適用。

### 複数成立

**成立した効果はすべて発動。**

同一Skillの複数ライン成立も回数分発動。

### 777

1ライン成立ごとに、

Skill 1 ×2
Skill 2 ×2
Skill 3 ×2

を発動。

### 完全ハズレ

効果なし。

ただし、

**WT=0**

→ 即READY。

# 20. ジェネラル

### 編成枠効果

人物ごとに、

**編成枠1～5に固有効果**

を定義可能。

例：

枠1：防御UP
枠2：回復UP
枠3：防御DOWN＋攻撃UP

など。

ジェネラル自身も編成枠を占有する。

---

## 複数ジェネラル

複数編成可能。

ただし戦闘前に、

## 指揮官ジェネラル1人

を選択。

### 指揮官

- その人物の編成枠効果のみ有効
- 指揮ゲージ獲得可能
- 指揮ゲージ強化使用可能

### 非指揮官ジェネラル

- 通常3スキル使用可能
- 編成枠効果無効
- 戦闘中の指揮ゲージ強化不可

### 指揮ゲージ

指揮官本人の行動で蓄積。

MAX消費によって、

- 既存編成枠バフを一定時間強化
- 未強化枠へ新規バフ付与

など人物固有効果を実行。

---

# 21. 自動反応とREADY操作を分離

以下のような能力は本人がREADYでなくても発生可能。

- ディフェンダーのかばう
- ディフェンダーMAX反撃
- スナイパー追撃
- バーサーカー二重発動の2発目
- OVER IGNITION
- 人物特性による自動スキル
- 状態異常処理

これらを**Reaction/Automatic Action**として通常コマンドと区別する。

原則としてReaction自体から新しい通常WTを発生させない。
