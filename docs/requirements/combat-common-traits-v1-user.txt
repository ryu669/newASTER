# 戦闘特性・共通特性 実装仕様 v1.0

目的： ヒロインの特性8枠を、ジョブ共通・キャラ固有・交流特性に整理し、キャラ重複による戦闘特性強化と共通特性の再利用を実現する。

## 1. 特性枠

| 枠   | 分類       | 仕様               |
| --- | -------- | ---------------- |
| 1   | ジョブマスタリー | ジョブごとに固定         |
| 2   | 第2戦闘特性   | ジョブ候補からキャラ制作時に固定 |
| 3～5 | キャラ固有特性  | ヒロイン実装側          |
| 6～8 | 交流特性     | 外見・嗜好・衣装など       |

- 最大8枠。3枠目以降の配分は可変
- プレイヤーによる特性変更なし
- ジョブ共通・キャラ固有・交流特性の順に表示
- 戦闘特性はキャラ重複Rankで効果強化
- 交流特性自体は効果なし・重複強化なし
- 交流特性はスキル等の発動条件に利用可能

## 6. 特殊処理

### ヒーラー

- 味方HP25%以下で緊急割り込み判定
- 初回は高確率～確定、以降は低確率
- 成功時に即時行動機会を付与
- 行動後WTは再設定
- 回復・攻撃スキルはともに攻撃力依存

### ジェネラル

通常モードと強化モードで、編成枠ごとの強化内容・数値を完全独立定義。

- リソース消費で強化モードへ移行
- マスタリー・指導者は両モードの編成枠強化に適用
- マスタリーによるバフ効果量強化は自身のスキルバフのみ
- 強化モードは通常バフではない
- パンツァー・オーパーツで強化モードを延長できない
- 複数ジェネラル時は既存の有効ジェネラル選択を維持

### パンツァー

- マスタリーのHP強化は装甲HPへ適用
- ナノマシン装甲は装甲HPだけ回復
- アーマーブレイク中は防御のみ
- 再召喚で消費済みツールは補充しない

### 共通処理

- 論理時刻100＝1ターン
- 属性IDは既存定義を参照
- 状態異常耐性は既存の耐性計算へ接続
- 同一特性のダメージ補正を1攻撃へ二重適用しない
- 戦闘特性の補正は既存のバフ・オーパーツ計算と整合させる

## 7. 重複Rank

キャラ重複によって戦闘特性の効果が上昇する。

- Rank1～5を暫定基準
- Rankは既存の重複育成段階を参照
- 第1・第2戦闘特性を強化
- キャラ固有戦闘特性も対応可能
- 交流特性は強化対象外
- 効果量・確率・持続時間などは特性ごとにRankテーブルで定義
- 数値バランスは最終工程で調整

## 8. データ定義

```
TraitDef {
    string id;
    string displayName;
    string description;
    string category;
    TraitEffectDef[] effects;
    TraitRankValues[] rankValues;
}

HeroineTraitSet {
    string formId;
    string jobId;
    string masteryTraitId;
    string secondTraitId;
    string[] uniqueTraitIds;
    string[] interactionTraitIds;
}
```

- 第1枠はジョブから固定取得
- 第2枠は人物定義に固定登録
- 同一IDの重複は禁止
- 合計8枠以内
- 未定義特性IDは検証エラー
- 共通特性の定義重複を禁止

## 9. 交流特性

11-7の共通特性27種類を使用。

髪色・体型・嗜好・性格・外見・衣装を扱う。

- 交流特性自体に能力効果なし
- 戦闘では表示特性のみ条件判定
- 日常ではプロフィール属性も参照可能
- 特性とイラストの見た目は一致必須ではない
- 衣装特性は形態単位
- 水着・ハロウィン・クリスマス・正月・バレンタイン・学園を共通衣装特性とする

## 11. 実装方針

1. 既存13ジョブ・特性8枠・重複育成処理を確認
2. ジョブマスタリー13種類を定義
3. 汎用第2特性10種類と専用特性を定義
4. 既存戦闘イベントへ各効果を接続
5. ヒロイン形態定義へ第2特性を固定登録
6. 重複Rank連動・UI表示
7. 交流特性と11-7の共通タグ判定を接続
8. Unityビルド・自動/実操作テスト
9. GitHubへコミット

完了条件： 13ジョブの固定マスタリー、第2特性、重複Rank強化が正常動作し、戦闘・交流・オーパーツ・既存セーブと矛盾しないこと。

数値は暫定値とし、最終バランス調整で確定します。
