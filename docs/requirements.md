# newASTER 正式版 要件定義 v0.1

更新：2026-09-22。状態：既存方針の統合版・未決事項あり。正式版の実装完了や全仕様の承認を意味しない。

本書を正式版の範囲と受入条件の入口とする。詳細仕様は[資料一覧](README.md)から参照する。

## 1. 目的と体験

『巨神と誓女』と『ANGELICA ASTER』を経験したプレイヤーが、両作品終了後の世界でヒロインと再会し、巨大な敵を討ち、歌を集め、仲間との関係と居場所を育てるWindows向け3D RPG。

基本の循環は「拠点 → 編成・装備 → 作戦選択 → 空中ボス戦 → 報酬・歌 → 物語・交流・育成 → 次の作戦」。戦闘の判断、巨大な敵と人物の3D演出、歌と人物交流を同じ進行へつなげる。

## 3. 完成見本と正式版の範囲

2026-09-22ユーザー回答：初期メンバーは保留して要件をまとめる。候補の3人および最初のモデルは確定しない。

以下は要件定義の提案基準。人数以外の数量・初期メンバー・加入順は未確定のため、実装着手前の判断台帳で管理する。完成見本の完成を正式版完成と呼ばない。

| 項目 | 先に検証する完成見本 | 正式版 v1.0の提案範囲 |
| --- | --- | --- |
| 人物 | 初期3人の選定は保留。既存候補はディージェー／スレイヤー／シヴァ | 
| 戦闘 | 5人編成、ボス1体、部位破壊、キャラごとに異なるスキル3種、スキル連携は確率で2人目～最大5人目まで順番に行う | 攻略の異なるボス5体 |
| 作戦 | 準備任務1、ボス任務1 | 3空域、各空域に準備・ボス・物語の導線 |
| 装備 | 遺物3種、武器分岐1人分を検証 | 遺物6種、各人の武器2分岐を目安に調整 |
| 拠点 | 1拠点、独立した配置3枠、3人との交流 | 同じ拠点へ加入済み10人を入れ替えて配置 |
| 歌・物語 | 敵1体の3章、初期3人の各第1章 | 敵5体×3章、ヒロイン人数×3章 |
| 個別シーン | 初期3人×1本、回想まで | 7人×3本＝21本、全員を同一セーブで進行可能 |
| 本編 | 再会・救助から初戦、歌と交流への導入 | 導入、7人が加入する過程、最初の物語の結末 |
| 音・演出 | 基本BGM・SE、飛行・接近・帰還・技・撃破 | 人物別の演出を完成。全編音声・歌唱は必須にしない |
| 配布物 | 開発用エディターなしで動くWindows実行ファイル | 手元で完結する実行ファイル、保存・復旧手順 |

3空域と加入章の数を同じとみなさない。章をどの作戦に割り当てるかは未決。プレイ時間は現時点で保証せず、導入1周と全員分の収集・読了を別に測定する。

## 4. 機能要件と受入条件

| ID | 必須機能 | 受入条件 |
| --- | --- | --- |
| F-01 | 新規開始・続き・プレイヤー名変更 | 日本語名を保存して再起動後も保持。改名後の会話・回想が新しい名前になり、進行は変わらない |
| F-02 | 加入・編成・装備 | 加入済みから重複なく5人を選択。装備は人物に紐付き、並べ替えで他人へ移らない |
| F-03 | 作戦と準備 | 対象・報酬・準備効果を出撃前に確認可能。準備任務を飛ばしてボスへ進める |
| F-04 | 発動・託す・連携 | 指示待ちで戦闘時間停止。託すと所定時間経過し次の候補へ。予約順に一度ずつ解決し、戦闘不能や勝敗後に停止不能にならない |
| F-05 | 部位・予告・資源 | 対象部位、攻撃時刻、参加順、誓いの温存／解放を表示。予告値と実結果が一致し、部位破壊で予定された大技を中断できる |
| F-06 | 戦闘の選択価値 | 同一条件で即発動または2人連携が有効な場面と、3人連携が有効な場面をそれぞれ再現・記録できる |
| F-07 | 休止・撤退・自動指示 | 非アクティブ化・メニュー中は停止し手動再開。撤退確認後に拠点へ戻れる。自動指示での資源消費方針を表示 |
| F-08 | 報酬・育成 | 勝利報酬は一度だけ付与。敗北・撤退で勝利報酬を付けない。装備変更・育成後も再戦可能 |
| F-09 | 敵と人物の歌 | 固有IDの非消費コレクションとして別管理。未取得条件を表示。重複入手で二重進行せず、後加入者も収集可能 |
| F-10 | 物語の解放 | 歌で章を開き、取得・解放・読了を区別。人物の基本物語に好感度や個別シーンの読了を逆要求しない |
| F-11 | 拠点配置・交流 | 戦闘編成と別に3枠へ重複なく配置。交代で全員に会え、未配置期間で進行を失わない。加入人数が枠数（3）を超える段階（正式版で最大10人）でも同じ3枠の入れ替え運用で成立する |
| F-12 | 人物別好感度 | 会話・帰還交流・初回読了の対象本人だけ進行。交流権は人物別に保存。再読・連打・再試行で二重加算しない |
| F-13 | 個別シーン・回想 | 未解放時は不足条件を表示。条件達成後に任意再生。回想では報酬・交流権・進行を変更しない |
| F-14 | 会話操作 | バックログ、文章速度、オート送り、既読スキップ、回想を使用可能。途中で閉じても未読を読了扱いにしない |
| F-15 | セーブ・復旧 | 進行1枠、自動保存、直前の正常バックアップ。書込失敗は再試行可能で、破損時は進行を示して復旧を選べる |
| F-16 | 原作との接続 | 各人物の口調・呼称・過去・関係を出典付き人物資料と照合。本作の追加を原作の事実として表記しない |
| F-17 | 遺物・武器分岐（新規） | 遺物は人物ごとに個別装着でき、表示された効果・条件と実際の戦闘結果が一致する。武器分岐は選択後にスキルや性能へ即時反映され、後から分岐を変更しても既存の進行（好感度・歌・物語）を失わない |
| F-18 | 演出・音響トリガー（新規） | 飛行・接近・帰還・技発動・撃破の各局面で対応するBGM・SEが発火する。演出短縮設定（N-03）を使っても、通常演出と同じ判定結果・報酬になる |

原作から続く関係と本作の好感度は別管理とする。好感度0を全員一律に「初対面」へ変換しない。原作のセーブ読込を前提にしない。

好感度0～100、閾値10／30／60、会話＋5、遺物効果、戦闘秒数などは既存資料の着手値であり、確定要件の数値ではない。調整後も上記の受入条件を満たすこと。

## 5. 非機能要件

| ID | 要件・目標 | 確認方法 |
| --- | --- | --- |
| N-01 | ゲーム初回起動から終了・再開まで通信必須にしない | ネット接続なし、開発用エディターなしで全必須フローを実行 |
| N-02 | 日本語、マウス＋キーボード対応 | 全必須操作を画面ボタンと対応キーで確認。名前入力中は戦闘操作を発火させない |
| N-03 | 演出と計算を分離 | 通常・短縮演出、描画速度の違いで同じ入力列の結果・報酬が一致 |
| N-04 | 手元PCで1080p・60fpsを目標 | Windowsビルドの代表戦闘で通常区間の95%のフレーム時間16.7ms以下を目標に測定。起動・ロードは別記録 |
| N-05 | 読みやすさと演出設定 | 文字サイズ、音量、画質、表示モード、カメラ揺れ軽減、演出短縮を変更・保存可能 |
| N-06 | データ保全 | 保存中終了、書込失敗、二重起動、現行破損、両方破損、旧版移行、未知の将来版を検証。元ファイルを自動破棄しない |
| N-07 | 制作再現性 | エンジン・依存版、ビルド手順、素材出典、移植照合結果を記録 |
| N-08 | 配布実行ファイル（新規） | 開発用エディターや追加ツールなしで、生成したWindows実行ファイル単体から起動〜終了までの必須フローを実行できる。完成見本・正式版いずれの段階でも同じ基準で確認する |

PC構成は既存資料のRTX 4070／Core i7-13700F／メモリ約32GBを暫定基準とする。今回再計測した値ではない。Unity 6＋URPは候補であり、最小Windowsビルド成功後に採用版を固定する。

## 6. 今回の正式版から外すもの

オンライン、アカウント、課金・ガチャ、クラウドセーブ、現実時間の待機・日次制限、自由飛行アクション、拠点建築、対人戦、ストア対応、自動更新、全編音声、戦闘途中からの再開、ブラウザ試作セーブの自動移行。ゲームパッドや別OSは初回必須にしない。

## 7. 実装順と完成判定

1. **戦闘の判断を検証**：F-06の比較ケースを用意。旧試作の移植基準は別モードとして保持する。
2. **3D工程を一周**：人物1人、仮ボス、飛行・接近・帰還、カメラ、Windows実行ファイル。見た目と性能を実測。
3. **完成見本**：初期候補3人・敵（ボス）1体で、5人編成枠と部位破壊・キャラごとスキル3種・連携（2～5人目）を含む戦闘、遺物3種・武器分岐1人分の装備、1拠点3枠での交流、歌の取得と3章の物語、初期3人×1本の個別シーンと回想、再戦、保存・復旧、開発用エディターなしで動くWindows実行ファイルまでを一通り接続して検証する。
4. **正式版内容を制作**：7人と承認したボス（5体）・3空域・物語・装備（遺物6種、各人武器2分岐目安）を追加。拠点は同じ3枠のまま加入済み最大10人を入れ替えて配置できることを確認。歌は敵5体×3章、人物物語はヒロイン人数×3章、個別シーンは7人×3本＝21本を全員同一セーブで進行可能にする。全員の加入・収集・交流に行き止まりがないことを確認。
5. **正式版受入れ**：F-01～18、N-01～08の実測結果、既知問題、素材台帳、オフライン実行ファイルを揃え、ユーザー本人が開始から結末まで確認。

現状はブラウザ試作v0.2のみ実装済み。30テストと移植用6ケース・110地点は試作の根拠であり、3D・7人・歌・好感度・拠点・シーンの完成証明ではない。
