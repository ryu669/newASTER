# 3Dアセット制作方針 v0.2

正式版の人物・巨神獣・家具・環境はゼロから制作する。参考作品の実モデル、テクスチャ、リグ、モーション、音声、抽出データを取り込まない。

## ヒロインの目標

空戦RPGとして読めるアニメ調の人体比率、翼または飛行補助装備、戦闘時に判別しやすいシルエットを採用する。一方、参考作品の人物と同一と認識される顔、髪型、衣装、配色配置、武器、固有の意匠は避ける。

## 最初のモデル制作順

1. オリジナルのシルエット・正面／側面／背面デザインを作る。
2. Blenderで低〜中密度メッシュ、UV、仮マテリアル、汎用人型リグを作る。
3. Unityで立ち、歩き、飛行待機、攻撃、被弾、交流の最小モーションを確認する。
4. 戦闘カメラで輪郭、武器、翼、表情が読めるかを検証する。
5. 同じ工程を巨神獣、家具、箱庭へ拡張する。

正式人物の原作設定を扱う場合も、3D造形は権利を確認した独自制作物だけを登録する。
