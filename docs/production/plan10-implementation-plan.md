# 計画10 ヒロイン量産と物語追加

更新：2026-10-06。状態：R・アナイアレイター通常版／聖夜版・シェル・オリフラムの正式実装・受入れ。ユーザー方針は、ジョブごとに一人ずつ揃え、人物の性格・口調・概要を物語制作用に残すこと。

初期5人の計画9配布候補を出発点とし、13ジョブそれぞれに人物を揃えてから同ジョブの追加人物を小ロットで増やす。まず未登場8ジョブを対象とする。今回指定の2本は別々の人物ではなく、Rの戦闘と人物の対応資料であり、最初の候補はアーティストのRとする。他ジョブの人物選定は資料照合後に決める。

## 工程と完了条件

1. **10-1 資料と人物台帳**：戦闘・人物動画を対応づけ、名前・ジョブ・時刻・観察範囲を記録。性格・口調・概要の人物資料を作成する。観察、解釈、独自設計を区別する。
2. **10-2 ジョブ実行**：v0.2の固有資源と操作を実装。アーティストは歌唱中の選択禁止、Battle Turn消費とバフ成長、本人READYでの解除、解除後の3スキル選択を検証する。
3. **10-3 人物戦闘と育成**：3スキル・固定チェイン・Lv基準と補正・覚醒・特性・装備の樹・入手条件を接続。参考画面のLv90等をそのまま本作の基礎値にしない。
4. **10-4 物語制作**：人物資料を先に読み、既存世界との接続、過去と現在、主人公との関係変化を設計する。人物ごと3章×6詩、好感度3本と恋人後2本の交流を既存契約に沿って追加する。長編化要求の1章約10ページ・1人約30ページを目安とし、詩の取得単位と表示ページ数を分ける。共通の出来事・人物・他ヒロインとの相互接続、巨神獣の詩との対応、回想条件を定義する。
5. **10-5 本人美術**：立ち絵・表情・戦闘・SD・家具利用・カットイン・イベントCGを人物別に制作し、台本の表情指定と対応させる。
6. **10-6 全体接続**：人物IDで所持・図鑑・5人編成・育成・箱庭・ADVを接続。現行の初期5人専用カタログから、検証済みの所持人物を選ぶ実行カタログへ拡張する。
7. **10-7 受入れ**：旧保存の読込、新旧混成5人の出撃、既存5人の効果と確率、歌唱・チェイン・対象消失・中断再開を確認。素材採用と本文整合まで通った人物だけをavailableにする。
8. **10-8 次ジョブと量産**：残り7ジョブを一人ずつ同じ工程で制作。その後、ジョブ別追加ロットへ進む。

## 物語制作用の人物資料

全追加人物に、短い人物概要、価値観と欲求、長所・弱点、平常時と怒り・不安・親密時の反応、一人称・二人称・呼称、語尾・語彙・文のリズム、対人距離、過去と関係、物語の葛藤、執筆上の注意を保存する。根拠動画と時刻を必ず付け、未確認項目を創作設定で上書きしない。既存5人も追加物語を執筆する前に同じ形式へ補完する。

最初の資料は [Rの人物資料](../references/characters/r.md)、制作候補台帳は [計画10人物台帳](plan10-heroine-roster.json)。原作本文・絵・音声・映像は参考専用。新しい本文と素材をオリジナルで制作する。

## 現在の進捗

Rは10-2〜10-6を実装。歌唱・3スキル・固定チェイン・育成・加入・混成5人編成・箱庭・3章30ページ／18詩／5交流・本人美術18点を接続した。検証・配布・生成指示は [R実装記録](plan10-r-implementation.md)。人物動画の全ボイスと全詩の精読は参考調査として未完了で、新規本文は本作独自に制作した。次は残り7ジョブの人物選定へ進む。

追加美術は天使の翼・光輪を明確に描き、参考人物固有の色・髪・装飾・装備の意匠を残す。Rでは白い大翼、二本の羽飾り、紺・シアン・ピンクの配色、金の巻き毛、環形スピーカーを立ち絵・戦闘・SD・交流CGに通した。
