# エクスカリパン：人物制作・交流設計

更新：2026-10-04。人物ID heroine.excalipan／ガンナーを維持。成人として描く。ローカル動画024の15秒は橙赤の長髪と編み込み、琥珀の目、白と青の帽子、青い肩布、白いフリルと暗色の胴衣、白い脚衣、パンを携えた白い羽根の人物の観察に使う。動画のUI・背景・ポーズは転写しない。遮蔽された武器は本作独自の金属と木のパン工房式銃として設計する。
