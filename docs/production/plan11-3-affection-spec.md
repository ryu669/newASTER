# Plan11-3 好感度・恋愛システム実装仕様 v1.0

ユーザー指定の実装基準。貼り付け時の表崩れを整形し、仕様の値を保持する。

## 目的

ヒロインとの繰り返し交流で好感度を育成し、Lv10で自動的に恋人となる。Lv21〜99は長期間交流した証とする。

## 1. 好感度

|項目|仕様|
|---|---|
|初期Lv|0。人物別初期値の指定可|
|通常上限／拡張上限|20／99|
|Lvアップ|100EXPごとに+1。余剰EXPを繰り越す|
|上限到達|EXP0で停止|
|好感度減少|なし|
|恋人判定|Lv10以上で自動成立。独立した恋人フラグを保存しない|
|戦闘能力補正|なし|
|管理単位|人物ID。衣装違いで共有|

Lv20到達時の特別解放・報酬はない。

## 2. EXP

|行動|EXP|
|---|---:|
|箱庭で話す|5|
|一緒に過ごす|5|
|生活催事に参加|5|
|生活発見に参加|3|
|巨神獣討伐成功|2|
|巨神獣戦敗北|1|
|撤退、イベント閲覧・回想|0|

戦闘EXPは編成された人物全員へ付与し、同一巨神獣の再討伐でも取得できる。

同一人物・同一内容の交流を連続実行すると、`5 → 3 → 1 → 1…`。異なる内容の交流が成立すると通常値へ戻る。同じボタンでも会話IDが異なれば別内容。同一家具の同一Interactionは同じ内容。キャンセル・失敗・自律生活の観察にはEXPを付与しない。リアル日付・待機時間による制限はなく、交流完了時に一度だけ付与する。

## 3. 指輪

永遠の誓環は召喚石10,000個で「召喚・交換 → 特別交換」から購入する。共通在庫で管理し、ガチャ排出対象にしない。

好感度Lv20・未使用の対象人物へ指輪1個を使用すると、上限20から99へ即時変更する。返品・付け替え・同一人物への再使用は不可。購入と使用は、それぞれ原子的保存とし、二重消費を防ぐ。

通常は「好感度上限20」、使用後はオリジナルの指輪画像と「99」を表示する。現在LvとEXPは別に維持する。

## 4. イベント・回想

```csharp
HeroineEventDef {
    string id;
    string personId;
    string formId; // 任意
    int requiredAffectionLevel;
    string category;
    string scriptId;
    string visibility;
    int displayOrder;
}
```

人物ごとの登録数に上限を置かない。`currentAffectionLevel >= requiredAffectionLevel` で解放し、他イベントの既読を条件にしない。条件達成後はいつでも閲覧できる。基本イベントはLv0〜20。Lv21〜99に必須イベント・報酬を置かない。

回想UIは登録イベントを動的に列挙する。未解放時の表示は `visible / hint / hidden`。回想でEXP・報酬・進行を変更しない。本文・会話・CG・環境嗜好は人物実装側で管理する。

## 5. 保存

```csharp
AffectionState {
    string personId;
    int level;       // 0..99
    int exp;         // 0..99
    int levelCap;    // 20 or 99
    string[] readEventIds;
}
```

指輪数は共通経済データへ追加する。複数形態は同じ人物の状態を参照する。既存数値の移行は現行形式を確認して実装し、旧イベント既読を保持する。

## 6. UI

人物詳細・万物の書で、Lv、EXP進捗、上限20または指輪画像と99、恋人状態、閲覧可能イベント、未読数、Lv20かつ未使用時の指輪操作を表示する。人物一覧は好感度Lv・恋人・未読で検索／絞り込み可能。Lv99到達時は一度だけ特別演出を表示し、追加報酬はない。

## 7. モジュール

|モジュール|責任|
|---|---|
|AffectionService|EXP・Lv・上限・恋人判定|
|AffectionRewardService|交流・戦闘のEXP付与|
|AffectionEventResolver|Lvによるイベント解放|
|AffectionRingService|指輪購入・使用|
|AffectionSaveAdapter|保存・移行|
|AffectionView|人物詳細・万物の書UI|

11-2箱庭と戦闘結果は報酬イベントを送るだけとし、好感度状態を直接変更しない。

## 9. 実装順と完了条件

既存データと移行 → Lv／EXP・恋人判定 → 戦闘・箱庭EXP → イベント解放・可変回想 → 指輪ショップ → UI・通知・Lv99演出 → 自動試験・Unityビルド・実操作確認。

既存人物・衣装・イベント・セーブを維持して、Lv0→20→指輪使用→99まで進行可能であること。既読依存なしでイベントを追加でき、Lv10で自動的に恋人となること。
