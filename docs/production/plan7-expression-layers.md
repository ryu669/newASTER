# 計画7：表情の部分重ね描画

全身型の生成表情PNGをそのまま差し替えると、衣装・翼・剣の微差も切り替わる。通常の立ち絵を常に土台へ描き、表情画像は左上基準の `(435,178,111,98)` px の領域だけを重ねる方式へ変更した。元画像は1024×1536で、領域を正規化した `overlayRegion01` と `regionalOverlay=true` を素材定義へ保存する。領域は目・口・頬と一部の髪際を含む矩形である。

ADVと美術見本の全身／顔拡大を同じ描画処理へ接続する。画面サイズに合わせた全身の比率を保ち、その画像内の座標へ表情領域を投影する。拡大表示では同じ合成の一部を表示する。画像の寸法不一致は通常立ち絵へ戻し、元PNGを加工・上書きしない。生成PNGそのものの顔以外の一致や、絵の編集レイヤー納品を達成したとは記録しない。

既存の全身差し替え `fullFrame` と透明な全身重ね画像も維持する。新しい部分重ねは表情素材にだけ許可し、非有限値・画像外・ゼロ面積・全身差し替えとの併用を拒否する。Unity JsonUtilityが未設定の参照型を空オブジェクトにする場合を考慮し、有効化はnull判定ではなく明示フラグで行う。保存ゲームの形式とfixtureのcontentVersionは変更しない。

Coreは5,576 assertions、Unityスクリプト87ファイル、Unityの実JSON変換とビルド前検証1,174 assertionsが合格。実行版の通常／喜び／困惑／決意を720p／1080pで撮影した。

`tools/audit-plan7-expression-layers.ps1` は実際の撮影PNGの美術領域を比較する。通常に対して3表情×2解像度の全6比較で、顔の全身表示／拡大表示の矩形内では12,888〜28,961画素が変化し、矩形外の変化は0だった。領域境界にはラスタライズ用に2画面pxの許容を設ける。ボタンと見出しは動的フォントのラスタライズ差を対象にしないため比較範囲に含めない。背景・衣装・翼・剣・足先は比較範囲に含む。

証拠：`tmp/plan7-sample-20261003083719`。目視では喜び1080pの全身と顔拡大を確認した。顔際の境界・表情の読みやすさの最終品質確認は別に残す。
