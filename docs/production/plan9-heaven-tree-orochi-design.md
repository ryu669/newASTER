# 天樹八岐：個別仕様

対象ID colossus.heaven-tree-orochi。巨木と木蛇の八岐。本体は6頭、独立した攻撃蛇枝は2頭で、合成時は計8頭。天樹芽・双頭の攻撃蛇枝・樹皮枝・吸水根を独立部位とし、古い森林の石舞台へ接続する。大技原画も8頭を確認する。

HP2600＋185×Lv、速度84、ゲージ6。蛇枝掃射は全体物理70%・ゲージ2、吸水根の収奪は高資源対象へ魔法70%・資源3減少、天葉の光は低HP比率対象へ魔法100%。蛇枝・根の破壊で対応行動を天葉の光へ代替。待機125／120／100%。

HP50%以下で天樹繁茂、与ダメ135%。攻撃部位破壊後60%。天樹芽破壊はゲージ低下と蓄積停止、樹皮枝破壊は装甲解除。大技は八岐翠嵐、Lv45以上は世界樹回生。大技後待機175%。素材と数値は制作候補、正式採用・最終難度は後続工程。
