# アンダーマイン：人物制作と交流設計

更新：2026-10-04。人物ID heroine.undermine／ディフェンダーを維持する。本作のオリジナル場面設計。

人物の軸は「守られる側にも席がある」。元気に先輩を慕い、自分に攻撃を集めるが、一人で耐えることと仲間を守ることを分けて覚える。紫の長い髪と桃色の毛先、金色の目、黒い小帽子と猫の意匠、紫と白フリルの衣装、黒タイツと桃色の靴紐、白い羽根をローカル資料で確認した。資料の武器細部は遮蔽があるため、本作では猫の布意匠を備えた大型打撃武器として一貫させる。抽出画像は制作参照専用で配布しない。
