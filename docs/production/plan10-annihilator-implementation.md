# 計画10 アナイアレイター／聖夜版

更新：2026-10-06。通常版はファイター、聖夜版はヒーラー。8形態・7人、5人編成。追加対象の人物、意匠、声の執筆方針は [人物資料](../references/characters/annihilator.md)。

## 利用経路と保存

誓女の星図の「新しい天使を迎える」から無償加入。R、通常版、聖夜版を個別に選べる。元の初期5人の排出率は維持。加入の保存失敗時は同じ要求を再試行し、成功するまで付与しない。

通常版と聖夜版は同じ人物なので同時編成できない。編成済みの形態を替えるとその人物の枠が移り、庭でも一人分だけ配置する。好感度・恋人関係を共有し、形態の加入時にも既存の関係を引き継ぐ。Lv、覚醒、スキルLv、神器13ノード、物語の既読は別。既存セーブの資産はそのままに、未加入の追加形態を所有扱いにしない。

新形態の神器倍率は、その形態の最初の攻撃スキルへ乗算する（通常版はスキル2、聖夜版はスキル3）。スキル1の自己強化／回復を武器攻撃へ置き換えない。

現在の正式リソースは `battle-plan10-annihilator.json` と `plan10-annihilator-story-content.json`。初期5人とRの6人版リソースを残し、回帰検証を継続する。

## 戦闘

通常版：宣告で基礎攻撃力90%回復、攻撃30%上昇2ターン、資源+4。紅蝶は物理200%、最大3珠で1珠20%加算。曼珠沙華は物理240%、最大5珠で1珠20%加算、自己最大HP10%損失。通常のファイター準備・行動の資源も加わる。

聖夜版：ひとひらの愛は味方1人を攻撃力130%回復し、状態異常を解除、生命力+6。贈り物は生命力8で味方1人へ攻撃40%、会心25%、会心威力30%を3ターン。哀を込めては生命力8、光の全体魔法200%、生存する味方全員へ基礎攻撃力60%回復。回復・支援は対象確認まで生命力を消費しない。

ヒーラーの生命操作：回復2（攻撃力150%）、上限超過回復4（200%、最大HP125%まで）、最大HP増加4（+20%、累積50%まで）、蘇生8（HP25%）、生命投資3（資源上限+2、20まで）。生命操作は待機100%、チェインを切り、その戦闘だけに適用。生命力は初期6、準備+1、初期上限10。

名称、ジョブ、画面内で読める倍率は指定映像に基づく。一方で基礎値、成長、固定チェイン、生命操作の数値、ダメージ上限10000、資源の固定消費は本作の独自設計。通常版の参考防御低下-150%をそのまま移植せず、曼珠沙華の代償を自己HP10%に置き換えた。聖夜の画面で切れた「消費量に応じる変化」は未確定なので固定8として実装した。

## 物語と美術

各形態3章30ページ・18詩・交流5本。合計60ページ、36詩、交流10本（80段落）。全体では69章・504詩・40交流。原稿は [独自物語JSON](plan10-annihilator-story-content.json)、読みやすい本文は `docs/story-text/アナイアレイターと聖夜の物語.txt`。

各18点の別画像：全身、肖像、表情3、攻撃、被弾、カットイン、庭SD4、CG5、神器の樹。画像は内蔵ImageGenで生成し、通常と聖夜の共通人物基準から派生。黒翼・赤眼・鬼面・彼岸花・和装と、聖夜の角・鈴・赤白衣装・緑リボンを残し、天使の光輪を加えた。元動画のUIや人物画面を配布画像に使わない。

生成画像は `game/art-source/plan10/annihilator/` と `game/art-source/plan10/annihilator-holy/`、実行用画像は `game/unity/Assets/Game/Resources/Illustrations/annihilator-*.png` に保存。[最終プロンプトと生成元](../../game/art-source/plan10/annihilator-generation-final.json)、[画像SHA256・透過検証](plan10-annihilator-art-validation.json)、[8,055項目・49画面の受入れ結果](plan10-annihilator-acceptance.json)を残した。

## 再生成と検証

`author-plan10-annihilator-story.py`、`assemble-plan10-annihilator.py`で本文と実行JSONを生成。戦闘・保存・人物共有の検証は `NEWASTER_PLAN10_ANNIHILATOR=1` を設定して `validate-automatic-chain.ps1`。Unityビルドは `Plan10AnnihilatorBuild.ValidateAndBuild`。プレイヤー画面検証は `validate-plan10-annihilator-player.ps1`。実測の結果は受入れJSONに記録する。
