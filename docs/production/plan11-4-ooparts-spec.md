# Plan11-4 オーパーツシステム実装仕様 v1.0

目的： オーパーツを編成枠に装備し、ステータス強化と最大2つの特殊効果によって戦術の幅を広げる。

既存の収集・同名統合・Lv強化を活用し、全体補正は廃止する。

## 1. 所持・装備

| 項目    | 仕様            |
| ----- | ------------- |
| 所持    | 1種類につき1個      |
| 装備先   | 編成枠           |
| 装備数   | 1枠1個          |
| 装備制限  | 全ヒロイン・全ジョブ共通  |
| 条件不一致 | 装備可能、該当効果のみ無効 |
| 人物入替  | オーパーツは編成枠に残る  |
| 空枠    | 装備状態を維持、効果なし  |
| 装備変更  | 無料・回数制限なし     |
| 戦闘中変更 | 不可            |

同じオーパーツを複数の編成枠へ同時装備できない。

編成プリセットごとに装備状態を保存可能とし、異なるプリセット間では同じオーパーツを設定できる。

## 2. オーパーツの能力構成

全種類が次の3要素を持つ。

| 区分          | 内容              |
| ----------- | --------------- |
| Lvステータス     | Lv1～120で成長する5能力 |
| 累積ランダムステータス | 同名再入手で更新する5能力   |
| 特殊効果        | 0～2個。各効果は独立条件   |

5能力は、HP・攻撃・物理防御・魔法防御・速度。

ステータス補正は固定値加算。特殊効果による割合強化は別処理。

## 3. 累積ランダムステータス

| 能力   | 暫定最大値 |
| ---- | ----- |
| HP   | +400  |
| 攻撃   | +100  |
| 物理防御 | +100  |
| 魔法防御 | +100  |
| 速度   | +12   |

- 初回入手時、各項目を最大値の20～100%から独立抽選
- 同名再入手時、各項目で`max(現在値, 新規値)`を採用
- 所持個数は増えない
- 装備先・Lv・固有能力は維持
- 数値が低下することはない

抽選・最大値はデータ定義から調整可能とする。

## 4. 強化

### Lv強化

- 最大Lv120
- 固定ステータス5項目が成長
- 強化成功率100%
- `+1 / +10 / MAX`を提供
- 強化費用は既存定義を優先

### ランダム能力の直接強化

各項目が最大値の80%以上で解放。

判定式：

`5 × currentValue >= 4 × maxValue`

- 1項目ずつ強化
- 成功率100%
- 1回で最大値の約5%上昇
- 速度は+1
- 最大値で停止
- 強化値は低下しない

直接強化は厳選の高額救済手段とする。

暫定費用：ネクタル50,000＋高Lv巨神獣素材20個／回。

最終バランス調整で変更する。

## 5. 特殊効果

最大2個。組み合わせは原則自由。

各効果は独立して条件判定し、不一致の効果のみ無効にする。

### 対応効果

| 分類      | 効果例              |
| ------- | ---------------- |
| ステータス割合 | 攻撃+20%、防御+15%    |
| 属性      | 火属性ダメージ+20%      |
| 攻撃・スキル  | スキル2威力+25%       |
| 詠唱      | 詠唱WT-20%         |
| WT      | 特定行動のWT-10       |
| ゲージ     | 獲得量+15%          |
| 部位      | 部位ダメージ+20%       |
| 状態異常    | 付与判定値+20         |
| バフ強化    | 自身が発動したバフ効果量+20% |
| ターン成長   | 毎ターン攻撃+5%、最大+20% |
| 固定ターン   | 最初の1ターン攻撃+60%    |
| HP連動    | HP減少に応じ攻撃上昇      |
| 被弾連動    | 被弾1回ごとに防御+5%     |
| ツール     | パンツァーツール使用回数+1   |

ターンは論理時刻100＝1ターンとする。

### 発動条件

ジョブ、スキル、行動、属性、HP割合、被弾回数、経過ターン、対象状態、編成条件などを指定可能。

複数条件はANDを基本とし、ORにも対応する。

状態異常の付与補正は固定値加算。行動不能系の同一状態異常を強化するオーパーツは原則1種類までとし、耐性無視・確定付与は禁止する。

## 6. ジョブ固有効果

ジェネラル・アーティスト

装備者自身が発動したバフのみ強化する。

- バフの対象枠・対象人数・種類は変更しない
- ジェネラルの編成枠別効果を維持
- 複数ジェネラル時は既存の有効対象選択を維持
- 歌唱中のスキル制限・ゲージ獲得禁止を維持

パンツァー

オーパーツでツール最大使用回数を増加可能。

- アーマーブレイク時の制約を維持
- 使用済み回数は回復しない
- ツールによるバフ持続延長は重ねがけ可能

## 7. バフ計算・持続時間

同種ステータスへのバフは基本加算する。

例：攻撃+30%と+20%なら合計+50%。

バフ強化は発動元の個別バフへ先に適用し、その後に合算する。

### パンツァーによる延長

- 持続時間操作はパンツァーツール専用
- ツール使用時点で発動中の延長可能バフだけ対象
- オーパーツの固定ターンバフも対象
- 延長の重ねがけ可能
- ツール使用回数以外の延長累計上限なし
- 使用後に発動したバフには影響しない
- 終了済みバフは復活しない
- 常時効果は対象外
- 減衰量・減衰周期は変更しない

減衰型バフは、初期効果量のみ強化可能。減衰量そのものは軽減できない。

例：攻撃+60%、毎ターン-10ポイント、バフ強化+20%なら初期+72%、以後+62%、+52%と減衰する。

## 8. 発動・終了処理

| タイミング   | 処理                 |
| ------- | ------------------ |
| 戦闘開始    | 固定能力、初期バフ、ツール回数を確定 |
| 論理ターン経過 | 成長・減衰・持続終了         |
| HP変化    | HP連動効果を再評価         |
| 攻撃命中後   | 被弾回数を更新            |
| 行動確定    | 詠唱・WT補正            |
| ダメージ計算  | 属性・部位・スキル補正        |
| バフ発動    | 発動者のバフ強化を適用        |
| ツール使用   | 現在有効な延長可能バフだけ延長    |
| 戦闘終了    | 一時状態を破棄            |

期限切れバフは同じ論理時刻のツールで復活できない。

多段攻撃の被弾カウントは、1攻撃アクションにつき最大1回とする。

## 9. UI

入口：編成 → 隊員設定 → オーパーツ

表示項目：

- 装備中オーパーツ
- 所持一覧と装備先
- Lv・5能力の固定値と累積値
- 特殊効果最大2個
- 発動条件・現在の有効状態
- 装備前後のステータス比較
- Lv強化・直接強化
- 同名再入手時の更新前後比較

条件不一致でも装備可能。

戦闘中にしか判定できない条件は「戦闘中に判定」と表示する。

## 10. データ構造

```
OopartDef {
    string id;
    StatGrowthDef levelStats;
    RandomStatDef[] randomStats;
    OopartEffectDef[] effects; // 最大2
}

OopartProgress {
    string oopartId;
    int level;                 // 1..120
    StatValues accumulatedRandomStats;
}

FormationSlot {
    string heroineFormId;
    string equippedOopartId;
}

OopartEffectDef {
    string id;
    string effectType;
    string targetId;
    EffectCondition[] conditions;
    int baseValue;
    string scalingType;
    int scalingValue;
    int minValue;
    int maxValue;
}
```

バフは`BuffInstance`として、発動者・発動元・効果量・減衰・残り持続時間を保持する。

## 11. 保存・互換

- 所持・Lv・累積ランダム値を保存
- 編成枠ごとの装備IDを保存
- 旧収集遺物の全体補正を廃止
- 旧セーブの所持・強化情報は維持
- 戦闘中の一時バフ・被弾カウンターは通常保存しない
- 強化・統合・装備変更は保存失敗時にロールバック
- 同一操作の再試行で二重消費・二重付与を防止
