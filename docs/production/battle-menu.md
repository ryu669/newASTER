# 戦闘の全画面表示と必要時の操作

2026-10-03のユーザー指示により、箱庭と同じく背景・人物・敵を大きく表示し、必要な情報だけ開く。指定録画 `044戦闘_ザクロ花嫁.mkv`（13:49.15、1928×1080）の00:00、00:30、01:00、01:30、02:00、03:00、04:00、06:00、08:00、10:00、12:00、13:20を静止画で確認した。01:30の広い演出画面、02:00の味方対象選択、03:00の行動選択、04:00の敵部位・予測表示を配置の参考にした。連続再生・音声聴取・入力解析は実施していない。録画原本・抽出画像・ゲーム素材は配布物へ転用せず、確認用画像はローカルの `.reference-analysis` に限定する。

背景を1600×900基準の全画面へ広げた。巨神獣は左の620角（以前340角）、人物は右の高さ550（以前300）へ拡大する。両方とも元PNGの縦横比を維持し、人物のカード参照だけでは主表示を変更しない。未制作人物は別人物の絵で埋めず、準備中表示とする。

常設は敵HP・大技ゲージ・次の敵行動、停止、5人の小さなHPカード。画面下の「行動」からスキル・資源・予測・タイミングを開き、行動またはパスを実行すると閉じる。演出中はスキルを隠してスキップ入口へ切り替える。「対象・部位」から本体・4〜6部位と破壊状態を開き、選択後に閉じる。パネルが閉じている場合は敵の絵でも部位を選べる。描画が未対応の部位もパネルで選べる。

チェイン数は複数参加またはフルチェインの演出中だけ表示する。短い通知は行動・破壊・停止時に表示し、入力待機中の通知帯は隠す。詳細パネルを開いた場合は背景の人物名帯も隠し、パネル端に文字を残さない。対象詳細には部位の破壊効果と、敵に実際に適用されている状態を表示する。

「人物・状態」またはHPカードから資源・状態効果・予測・チェイン補正を表示する。「操作を開く」で行動順・ヘルプ・撤退を展開する。パネルは一つだけ開き、×で閉じられる。Escapeは回復確認・全体モーダルを優先し、その後はパネル、展開操作列、停止の順。パネル操作を裏の敵選択へ通さず、休止・演出・回復確認・ヘルプ・撤退・結果中の新コマンドを拒否する。回復対象確認の段階では費用やHPを変えず、実行時に既存処理へ渡す。

`BattleMenuExperience.cs`は表示と開閉を担当し、`BattleIllustrationView.cs`は拡大した画像・部位の座標を共用する。乱数、戦闘時計、スキル効果、費用、チェイン、報酬、保存は従来の戦闘処理を使用する。開閉状態は保存しない。
