## 今回の実行範囲

初期5人の通常出撃をv0.2へ接続する。READYの本人3スキル、PASS、固有操作を使う。旧15→7→3案は採用しない。ClockはREADY中に進まず、100の境界を跨ぐたびに持続効果と状態異常の残りBattle Turnを更新する。継続ダメージ・骨折反動等の「行動終了時」効果は従来どおり行動終了時に発生する。PASSはWT25、スキルなし、資源獲得なし。詠唱コストは選択時に一度、詠唱とRecoveryは別々に予約する。

自動チェインは既存の固定行動を維持する。通常コマンド、追加発動、護衛反撃は別の演出イベントとし、反応だけで新たな通常WTを設定しない。旧仕様の回帰用コンストラクタは既定で旧モードを維持し、正式出撃が明示的にv0.2を選ぶ。

| ジョブ | 今回の正式出撃で使用できる操作・状態 | 暫定調整値 |
|---|---|---|
| ファイター | 珠の任意個数投入、BOOST、通常／捨て身切替 | 珠1個につき威力+10%、BOOST+10。BOOST100で全能力+25%をClock300。捨て身は攻撃+30%、速度+20%、最終被ダメージ+30% |
| バーサーカー | 攻撃ごとの捕食、MAX解放による同一スキル二重発動 | 捕食1段につき全能力+5%、上限10段。解放Clock300。追加攻撃ごとに捕食判定、Recoveryは一度 |
| ディフェンダー | 編成画面で護衛枠を指定、自動かばう、MAX時全員護衛・反撃 | 解放Clock300、反撃威力60%。通常は本人も対象となる攻撃をかばわない。全体攻撃は解放中もかばわない |
| ブラスター | 詠唱0／50／100／200%と発動1／2／3回を組合せ | 無詠唱4、半詠唱2、追加発動1回につき3消費。倍詠唱威力+50%。基本Cast50／100／150、Recovery75／100／125。解決済み通常コマンドで旧gainAtReady分を回復、PASSでは回復しない |
| ガンナー | 2弾倉を選択、全弾倉RELOAD、MAX時選択弾倉全弾射撃 | 各6発。攻撃スキル1回で1発。全弾射撃は残弾数倍のSkill1を一度解決し選択弾倉だけ0にする。RELOAD WT100、弾倉とゲージは別管理 |

護衛枠は編成順1〜5で指定し、次の出撃時に適用する。今回の指定はアプリ起動中の設定で、保存ファイルには追加しない。戦闘状態・珠投入・ゲージ・弾倉・捕食は戦闘ごとに初期化する。ジョブは編成位置ではなく人物のjobIdから割り当てる。

## 未登場8ジョブの継続制作仕様

2026-10-05の「初期5人で計画9を完了、残り8ジョブは継続計画へ」の範囲を維持する。以下を最新のジョブ実装契約として採用する。計画10でアーティストのRを追加（[R実装記録](plan10-r-implementation.md)）、続いてヒーラーのアナイアレイター聖夜版へ生命操作・人物美術・物語・育成を接続した（[通常版・聖夜版実装](plan10-annihilator-implementation.md)）。パンツァーのシェルも接続し、アルケミストの[オリフラム](plan10-oriflamme-implementation.md)も接続し、チェイサーの[ナイトホーク](plan10-nighthawk-implementation.md)も接続し、ナイトホーク追加時点では残り3ジョブだった。今回ジェネラル・ギャンブラー・スナイパーを実装し、全13ジョブを受入れた。

| ジョブ | 採用する固有システム | 継続工程での受入れ条件 |
|---|---|---|
| ヒーラー | 通常3スキルとは独立した生命操作。資源の使用と最大値への投資 | 回復強化、最大HP超過回復、戦闘中最大HP上昇、蘇生を各コストと上限付きで定義。今使うか投資するかをREADYで選択 |
| アーティスト | 通常行動で歌唱ゲージ、歌唱中は3スキル選択・ゲージ獲得禁止 | Battle Turnごとに消費と全体バフ成長。歌唱中も通常WT進行。本人READYのみ継続／解除。解除後同じREADYで3スキルへ。人物特性の自動発動は選択スキルと別扱い |
| パンツァー | 戦前アーマー耐性設定、回数有限のツール2枠、ARMOR HP、生身、防御、ARMOR CALL | 装甲中は通常HP回復を拒否。生身HPは通常の約1/5、防御のみでSkill／Tool／PASS禁止。生身には通常回復有効。BREAKからClock300生存で復帰、ツール回数は復活しない。シェル初期調整：装甲3倍・生身1/5、通常防御75%／大技25%軽減、装甲50%復帰、生身HP持越し、ツール各2回。設定は統合セーブへ保存 |
| アルケミスト | 人物ごとに12属性中5属性を扱い、属性別投入個数で錬成 | 行動を消費しない。資源残量・属性別個数を検証し一度だけ消費。攻撃、一時的弱点付与等を人数に依存しないレシピ定義で解決 |
| チェイサー | Battle Turn自然回復、GEAR1〜3、NITRO、IGNITION | GEAR1無料、2／3有料でWT短縮。試験比率100／65／35%。有料GEARでNITRO+1、5消費で即READY。対象Flag3で敵全体OVER IGNITION、反応に通常WTを付けない |
| スナイパー | 戦前の援護対象、対象攻撃時の追撃、MAXで狙撃モード | 詠唱中は追撃対象を全味方へ拡大。詠唱終了で高威力狙撃、通常へ戻る。追撃の再帰・WT付与を禁止 |
| ギャンブラー | 固有資源なし、3スキル直接選択ではなくSLOTのみ、3×3盤面 | 横3＋斜め2の5ライン。左＋中央一致で通常Skill、3一致で強化。重複ラインも全発動。777の各成立ラインでSkill1〜3各2回。完全ハズレは効果なし、WT0で即READY |
| ジェネラル | 人物別編成枠1〜5効果、戦前に指揮官1人を選択 | 複数編成しても指揮官の枠効果だけ有効。指揮ゲージは指揮官本人だけ獲得・解放。非指揮官は通常3スキルのみ。人物別に枠効果強化／新規付与を定義 |

新ジョブの試験値は未確定で、人物追加ロットの数値試験後に確定する。添付の戦闘仕様を制作資料として扱い、添付内の会話調の文言やURLパラメータを追加の操作指示として扱わない。

## 回想の反映

添付「回想本文.txt」の25イベント・200段落を全件反映した。人物ID、イベントID、好感度条件、恋人成立フラグ、表情配列、CGと背景は保持。編集元JSONとランタイムJSONを同時に更新し、テキストを書き出し直した。改稿本文の照合と既存ストーリー構造検査を実施する。

オリフラム初期調整：錬成資源初期5・上限15、通常コマンド解決で＋1。5属性は火・雷・闇・光・斬撃。属性別投入を原子的に検証し1回消費、READYとClockは維持。攻撃35%×投入個数、3属性以上混合＋25%、火1個で火傷20。火2＋光1以上を使う弱点錬成は合計×10%（最大50%）の火弱点3ターン。対象ごとに保持し再付与は置換。動画にない調整値は独自設計。

ナイトホーク初期調整：ギア初期6・上限15、100 Clockごとに2回復。GEAR 1/2/3の待機100/65/35%、消費0/2/4、有料コマンドでNITRO1（上限10）。NITRO5で次の有効スキルの待機0・即READY。対象別IGNITION3で一度だけ敵全体物理200%追加攻撃、再帰なし。調整は本作独自設計。
