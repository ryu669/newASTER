# 万物の書 UI・オーパーツ初期仕様

## ページと操作

巨神獣、誓女、庭、物語、召喚、アイテム、レリックハント、新天地、可能世界の9ページ。上部は画像しおりと右上の「？」で構成し、しおりは縦長にし、現在のしおりだけ左側に移動してページ名を縦書きで表示する。非選択のしおりはページごとの固定位置を保ち、並べ直さない。従来の上部タイトルと文字タブは除去。通常画面には操作説明を表示しない。

巨神獣・物語・レリックハントの対象めくりと詳細切替は下部。巨神獣は3Dモデル表示をやめ、専用2D美術を挿絵として使用する。保存は下部システムへ統合し、設定・表紙へ戻る操作も収録する。召喚は独立ページ。アイテムはオーパーツと素材の2面。旧オーパーツ画面は廃止し、画像・名称・実際の効果・装備先・強化操作の一覧に置き換える。

全15人の誓女の肖像は3:2、ネイティブ1536×1024以上、RGBA、128画素以上の顔、同一の顔サイズ・中心・縦横倍率で表示する。旧素材の例外なし。神器の木は全15人分の専用画像へ置き換える。幹・根・枝が見える木に、各人の衣装・武器・装飾の意匠を加える。枝上の座標は `UI/heroine-weapon-trees.json` で登録し、原本と同じ縦横比でノードを重ねる。

## 独立したオーパーツ

追加数はジョブ数と特殊品の加算であり、ジョブと効果種類の掛け合わせにはしない。追加18種、既存15種を含む33種。各追加品は一つの効果カテゴリのみ持つ。ジョブ補正・通常攻撃補正・時間補正は独立した加算値として処理し、効果同士を乗算しない。チェイン確率への補正なし。

|分類|数|初期効果|
|---|---:|---|
|ジョブ職印|13|対応ジョブだけHP・攻撃・物理防御・魔法防御・速度＋30%|
|猛攻の牙|1|攻撃＋45%|
|不壊の殻|1|物理防御・魔法防御＋60%|
|疾風の羽|1|速度＋40%|
|成長する時計|1|開幕0%、敵行動完了ごと攻撃＋5%、最大＋40%|
|燃え尽きる灯|1|開幕攻撃＋50%、敵行動完了ごと−10%、最低0%|

通常討伐は勝利時に5%の抽選を1回。レリックハントは勝利時に各35%でレベル帯の抽選回数1〜5回。職印は13体の巨神獣に一種類ずつ割り当て、5種類の特殊品は全巨神獣の候補へ加える。素材・TP・詩・初回解放の既存報酬も維持する。敗北・撤退では遺物を取得しない。

初期の低確率設定は上記とする。戦闘開始時にハント種別を固定して戦闘記録・保存・取引署名へ保持する。保存に失敗した場合は同一候補を再試行し、再抽選・再取得しない。旧記録ではハント種別なしを通常討伐として扱い、既存の取引署名を変更しない。

## 検証

`tools/BookRedesignTests.cs` は独立した追加種別、ジョブ一致／不一致、実戦の防御と速度、時間変化、加算、ドロップ分布、失敗保存の不変性、同じ抽選の再試行、再起動後の二重取得防止を検証する。従来の15品と既存セーブの互換性は維持し、旧品の能力検証も継続する。

攻撃枝は攻撃・スキル倍率 → 会心率 → 速度 → 固有攻撃特性、防御枝は攻撃・スキル倍率・物防 → 魔防 → 速度 → 固有防御特性、速度枝は攻撃・スキル倍率・速度 → 会心率 → 会心威力 → 固有速度特性を追加する。各ノードはそこまでの全効果の画像アイコンを表示し、先のノードが前段階の効果を失わない。木画像・効果アイコンのプロンプトと原本は `game/art-source/heroine-weapon-trees-v1/generation.json` に収録する。

画像生成は組み込み `image_gen.imagegen` を使用。原本をそのままコピーし、拡大や画像の再サンプリングは行わない。プロンプト・原本パス・SHA-256を `game/art-source/heroine-portraits-v2/all-implemented-generation.json` に保存する。
