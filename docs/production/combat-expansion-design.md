# 列車一枚絵・戦闘操作・属性・状態異常

2026-10-05。初期5人の正式配布候補に追加。残り8ジョブと200人以上の実制作は継続計画。

## ガチャ

imagegen の組み込みツールで、到着、開扉、降車の3枚のオリジナル一枚絵を生成。同じ構図を参照して継続制作し、ゲーム内でクロスフェードする。絵の人物は出会いを表す演出用人物で、抽選された人物の確定表示は結果の顔・名前カードを使う。演出は保存済みの抽選結果を読み、再抽選や報酬の追加付与をしない。短縮・動きを減らす設定とスキップを維持する。

## 戦闘操作とリソース

スキル選択待ちでは左下の3つのスキルを表示し続け、右側のヒロインを隠さない。選択したら既存の攻撃・詠唱・チェインの演出キューに接続。対象変更も左側で操作する。

通常のスキル発動はリソース消費0。任意のチェックを入れた場合だけ、スキルごとの既存消費量を上限として所持分を使い、1個につき主要効果を10%強化。元の消費が0のスキルも1個を使って強化可能。チャージ技の上限は9個。特殊兵装追加効果は6個以上を実際に使う時に有効。確定前は予測値だけを更新し、不正な対象では消費しない。詠唱は開始時に強化値を固定して1回だけ消費する。発動後・パス後は任意消費の選択を解除する。ジョブ資源の獲得・所持上限は維持。

## 属性

斬撃、刺突、打撃、銃弾、ビーム、火、水、氷、風、雷、光、闇。スキルごとに重複なしで0〜5個。0個は無属性。12属性の巨神獣ごとの設定を持ち、初期設定は弱点25%、耐性30%。複数属性は各属性の補正を平均し、弱点を掛け合わせない。既存の物理・魔法防御とは別に適用する。

## 状態異常

蓄積100で発症。耐性は蓄積量を減らす。ヒロインのジョブと巨神獣ごとに発症しやすさを変える。スタンは1行動、その他は3行動。以下の数値は参考画像にないため、newASTERのオリジナル初期調整値。

| 状態 | 効果 |
|---|---|
| 毒 | 発症時・行動終了時に最大HP3%ダメージ |
| 火傷 | 発症時・行動終了時に最大HP2%ダメージ、攻撃力20%低下 |
| 凍傷 | 発症時・行動終了時に最大HP2%ダメージ、速度20%低下 |
| 出血 | 発症時・行動終了時に最大HP2%ダメージ、回復不可 |
| スタン | 次の行動を自動で1回スキップ。詠唱発動もスキップ対象 |
| ジャミング | 生存・未破壊の選択可能対象から戦闘乱数で対象を選ぶ |
| うわの空 | 行動不可、行動終了時HP5%回復、被会心率25%増加、被ダメージで解除 |
| 病弱 | 攻撃力20%低下、受ける最終ダメージ25%増加 |
| 骨折 | 攻撃後に自身の最大HP5%ダメージ。非攻撃スキルでは発生しない |
| 帯電 | 雷の最終ダメージ25%増加、発症時・行動終了時に次行動待機20加算 |

状態蓄積は戦闘中だけに保持し、通常セーブには保存しない。詠唱予約・演出スナップショットは確定したコスト・属性・状態表示を保持する。旧仕様の検証は明示的に任意消費フラグを無効にして継続し、現行フラグを有効にした別テストで新仕様を検証する。

## 画像制作プロンプト

組み込み `imagegen`、CLI不使用。採用ファイルは `Assets/Game/Resources/KinderTrain/{arrival,doors,disembark}.png`。

1. 到着：高品質のオリジナル幻想JRPG背景。金の装飾と星の意匠を持つ深紺と青緑の夜行列車、紫の星空、魔法の庭園駅、石造ホーム、暖かな窓、蒸気。横長16:9、中央右に閉じた両開き扉、人物・文字・UIなし。
2. 開扉：到着の絵を参照して編集。カメラ、列車、駅、空、構図を維持し、中央右の両開き扉を開く。金色の車内と降車階段、扉からこぼれる光の粒。人物・文字・UIなし。
3. 降車：開扉の絵を参照して編集。同じ構図の扉から成人女性の幻想的な人物が降りる。長い髪と装飾的な衣装、金色の逆光で顔は特定しない。魔法の花びらと星の光。実際の抽選人物は別の肖像カードで表示するため既存作品の人物を模写しない。文字・UIなし。
