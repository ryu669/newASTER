# 全画面の画像UI化

初期5人の配布候補 `0.9.5-rc.2`。各画面の単色パネルと操作ボタンを、オリジナルの画像部品へ置き換える。

## 採用素材

内蔵 `image_gen` を使用。生成した4画像を目視確認し、元のPNGを加工せずプロジェクトへ保存した。全文プロンプトは [image-ui-prompts.json](image-ui-prompts.json)、保存先・元画像・SHA256は [image-ui-art.json](image-ui-art.json) に記録。

- `Assets/Game/Resources/UiImages/panel-v1.png`：紺の革、金属枠、植物と星の装飾。
- `Assets/Game/Resources/UiImages/parchment-v1.png`：羊皮紙と金の装飾枠。
- `Assets/Game/Resources/UiImages/button-v1.png`：紺のエナメルと金の装飾ボタン。
- `Assets/Game/Resources/UiImages/library-v1.png`：夜の植物図書宮殿。

## 画面への反映

タイトル・導入・設定・クレジット・操作説明・終了・保存復旧、万物の書・巨神獣・物語一覧、誓女一覧・能力・特性・育成・スキル・神器、編成、素材図鑑・収集・レリック、ガチャ・提供割合・交換・チケット・列車演出、星の恵み、庭園・家具・住人・確認、会話とバックログ、戦闘操作・対象選択・状態表示・結果の共通パネルとボタンを画像化。

既存の人物、敵、庭園、物語CG、神器の木、列車の絵は引き続き使用。背景には植物図書宮殿の画像を使用する。画面内のイラストがある領域は既存の絵を上に描画する。

`ImageUiSkin` が画像をキャッシュし、9分割描画で四隅を保ったまま枠を伸縮する。ボタンは元PNGの中央帯をUV参照する。CPU読み取りや毎フレームのTexture生成は行わない。通常・ホバー・主操作・無効の状態を色と既存ラベルで区別する。

検索欄、音量スライダー、スクロールバーも画像スキンを使用。文字・数値・説明は日本語フォントによる描画を保つ。HPバー、線、モーダルの暗幕、透明なクリック領域は用途に合った軽量描画を維持する。

保存、費用、編成、抽選、スキル、属性と状態異常のロジックと操作領域は変更しない。720p・1080pの隔離プロファイルで実際のプレイヤー画像を確認し、通常セーブが変わらないことを検証する。実操作・音声聴取・性能測定は今回の対象に含めない。
