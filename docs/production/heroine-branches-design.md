# 神器の枝と周辺画面の改訂

2026-10-05、0.9.2-rc.1。神器の取得ID・親ノード・強化費用は維持し、効果を再調整する。旧装備も次回出撃から新しい定義を使う。

| 系統 | 主能力 | 最終神器の特性 |
| --- | --- | --- |
| α | 攻撃、会心率、通常攻撃倍率 | 攻撃＋10% |
| β | 物理防御、魔法防御、控えめな攻撃 | 物理・魔法防御＋12% |
| γ | 速度、会心率、会心威力、攻撃 | 速度＋8% |

各枝は4段階、各神器はLv1〜7。既存の根を含み1人13ノード。最終特性は花翼・理砕・森命・紅蓮・月祈を人物別の名前に持つ。装備中の1神器の加算能力に対して、特性倍率を1回適用する。会心率の合計は100%を上限とする。今回は能力アップ特性を採用し、属性・状態異常特性は導入していない。

スキル名の文字サイズを27から24へ変更。ガチャ・交換・チケット・提供割合に人物肖像と5種の紋章、石の表示枠を追加。星の恵み、詩・章、オーパーツ画面には共通の紋章入り背景と装飾枠を追加した。確認・費用・抽選確率・保存の仕様は維持する。

自動機能検証7223項目・Unityビルド1970項目成功。[26画面の検証記録](heroine-branches-validation.json)を保存し、すべて個別目視確認した。1080pの9画面は[配布exeからの確認](heroine-branches-package-smoke-validation.json)。[配布162ファイル](heroine-branches-package-validation.json)はSHA256照合済み。隔離データを使い、通常セーブは不変。人による実操作・聴取・性能測定は未実施。
