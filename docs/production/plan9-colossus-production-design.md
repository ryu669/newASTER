# 9-5：15巨神の個別制作対応

固定した15IDと解放順を維持する。下表は制作仕様であり、実装済み・正式採用数ではない。各行の4部位はgauge／attack／armor／drainに対応する。体色だけを変えた同一敵を作らず、シルエット、素材、部位配置、行動周期、環境背景を個別に制作する。

| 巨神 | 本体の美術 | 角冠・攻撃・装甲・資源の4部位 | 周期の特徴 |
| --- | --- | --- | --- |
| 緑還竜 | 緑の生命竜 | 結晶角冠／左翼根／右翼装甲／蔓尾 | 既存翼撃・角冠依存の緑晶大技 |
| 赤晶暴竜 | 黒曜の地上暴竜 | 赤晶角冠／掘削爪／黒曜胸甲／鉱脈尾 | 単体顎→全体爪→高資源狙い・2ゲージ |
| 記晶機竜 | 青白い記録機械竜 | 記録核／結晶砲／鏡面装甲／記憶アンテナ | 魔法砲撃→資源走査→高速照射 |
| 天塔機神 | 空中の環状機械塔 | 天球環／気圧砲／浮遊障壁／風力翼 | 圧力を溜める低速行動と全体放出 |
| 水晶薔薇姫 | 薔薇鉱晶の女王像 | 花冠／荊鞭／花弁盾／根の宝珠 | 低HP狙い→花弁全体→根の吸収 |
| 銀海鯨 | 銀の空泳鯨 | 潮核／左胸鰭／銀背甲／尾鰭 | 緩やかな全体波→潜航単体→高資源潮流 |
| 天樹八岐 | 木と蛇の巨木 | 天樹芽／攻撃蛇枝／樹皮枝／吸水根 | 蛇枝の掃射→根の吸収→葉の魔法 |
| 再演巨人ユミル | 四季の石巨人 | 季節冠／石腕／桜胸甲／記録輪 | 重い単体→四季全体→記録走査 |
| 翠星アスタル | 翡翠の星獣 | 星輪／彗星爪／翠晶盾／衛星尾 | 高速単体・魔法全体・星資源吸収 |
| 琥珀王蛇 | 砂漠の琥珀大蛇 | 琥珀冠／砂牙／黄金腹甲／砂時計尾 | 低HP狙い→遅い全体砂嵐→吸収 |
| 白神竜母 | 白金の守護竜 | 生命冠／白翼／母竜胸甲／生命尾 | 単体羽撃→魔法全体→生命走査 |
| 黒煙城塞 | 脚を持つ金属城 | 煙突核／大砲／城門装甲／排熱塔 | 高威力砲撃・低速全体・熱吸収 |
| 死人王メガデス | 夜森の鎧王 | 王冠／夜剣／王の鎧／魂灯 | 低HP狙い→魂灯吸収→夜の全体 |
| 終焔氷凰 | 炎氷の大鳥 | 氷焔冠／炎翼／氷翼盾／氷焔尾 | 炎の単体と氷の全体を交互に蓄積 |
| 新生獣アステリア | 世界を結ぶ星の獣 | 世界環／星爪／統合胸甲／世界尾 | 物理・魔法・高資源狙いの複合周期 |

各敵は本体1＋独立部位4＋大技1を最低単位とする。破壊時は対応する層だけを消す。独立部位の効果が残っている場合は大技の全身絵で失われた部位を復活表示しない。各素材の原画と指示、manifest配置、画像hash、両解像度の通常／個別破壊／全破壊／大技とLv44／45／49／50を照合する。

出撃接続は専用戦闘定義と美術が揃った敵から順次行う。未制作の敵はページを開けても出撃できない。解放・環境報酬・詩取得・再挑戦・保存は共通処理のまま各IDで検証する。正式採用と配布の判定は計画9の完了ゲートで行う。
