# 天塔機神：個別仕様

対象ID colossus.sky-tower-machine。雲海高原に浮く象牙と金の塔。青い縦結晶窓と逆さの石台を本体とし、天球環・気圧砲・浮遊障壁・風力翼を独立画像で合成する。緑還竜や記晶機竜の画像を使い回さない。

HP2100＋165×Lv、速度88、ゲージ6。気圧弾は単体物理110%、圧力蓄積は高資源対象へ魔法55%・資源2減少・ゲージ3、暴風放出は全体魔法80%・ゲージ2。塔影の衝撃は単体物理85%の依存しない代替行動。気圧砲破壊で砲撃と放出、風力翼破壊で蓄積を代替する。

天球環はゲージ部位、浮遊障壁は装甲部位。HP45%以下で暴風圏、与ダメ135%。攻撃部位破壊後は65%。大技は魔法の天圧解放、Lv45から天空崩流。大技後の待機180%、各通常行動は100／125／140／105%。固有周期とゲージ境界、部位依存、勝利・敗北・撤退後の保存を検証対象とする。

素材と数値は制作候補。正式採用、全敵の通し調整、物語と収集への最終統合は後続ゲート。
