# 庭：必要な時に開くメニュー

更新：2026-10-03。ユーザーの参考画像4枚から、閉じたメニュー・補助操作の展開・右側詳細パネルの操作順を適用した。参考画像のゲーム素材は転用していない。装飾や他の画面の完成品質を合格扱いにしない。

庭は1600×900基準のうち、景色を1600×730で表示する。通常状態では人物名簿・家具リスト・交流ボタンを隠す。下部の移動先と「操作を開く」から、家具／人物／交流・物語／庭の切替／保存を表示する。詳細パネルは一つだけ開き、「×」で閉じられる。Escapeは確認取消、配置取消、パネルを閉じる、操作列を畳むの順で戻る。保存失敗の保留中は取り消しや別操作へ抜けない。

家具を選んだだけでは配置を始めない。「配置・移動」でプレビューへ入り、庭の接地位置を指定して確認する。人物パネルからは選択中の配置済み家具を利用できる。利用可能な庭に配置されていない家具は利用ボタンを無効にする。作成・移動・撤去・交流・利用は従来のHome操作と保存確認を使い、画面上では家具名と人物名を表示する。通常保存と隔離検証保存の境界を維持し、切替時は選択・開閉状態を初期化する。

開閉状態は保存しない。パネルの表示や切替だけで費用・所持品・好感度・既読・庭配置を変更しない。パネル内のクリック・スクロールを背後へ通さず、配置中はパネルと下部操作列を除いた庭でのみ位置指定を受け付ける。確認モーダルが出た後は背後のボタンを無効にし、確定／取消／保存再試行だけを受け付ける。

`GardenMenuExperience.cs` が表示と開閉を担当する。既存の家具とSDの接地／輪郭合成は `DrawGardenScene` で共用する。720p／1080pで閉じた状態、操作列、家具、人物、交流、庭切替、配置、確認を撮影する `tools/validate-garden-menu-player.ps1` を追加した。共有ハンドラの排他的なパネル切替とEscape順序、開閉による保存内容の不変、配置／確認中のナビゲーション制限を隔離保存で検査する。人によるクリック試遊とは区別する。

最終検証・ビルド識別・実画面は以下へ追記する。今回のUI変更後の負荷測定は実施せず、以前の静的見本の性能値を新しい庭画面の性能値へ読み替えない。
