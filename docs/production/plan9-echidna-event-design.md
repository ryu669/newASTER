# エキドナ：人物制作・交流設計

更新：2026-10-04。人物ID heroine.echidna／ブラスターを維持する。人物は成人として描く。ローカル資料は銀白色の短髪、片目を覆う前髪、青い目、小さな巻角、白い花弁状の衣装、金の縁と青石、背面の濃紫の大きな花弁状付属肢を観察するために使う。資料のUI・ポーズ・背景を転写しない。
