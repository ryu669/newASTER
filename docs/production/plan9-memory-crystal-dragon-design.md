# 9-5 記晶機竜：個別制作仕様

対象ID colossus.memory-crystal-dragon。W02の鉱床・結晶地帯を戻す第3巨神。青白い銀と象牙の機械装甲、四脚、青い回路の低いシルエットを採る。赤晶暴竜や緑還竜の画像を使用しない。

| 部位ID | 名称 | 役割 | 破壊後 |
| --- | --- | --- | --- |
| memory.core | 記録核 | gauge | 現在ゲージを1減らし蓄積を止める |
| memory.cannon | 結晶砲 | attack | 砲撃／高速照射を踏撃へ変更し、威力も低下 |
| memory.shield | 鏡面装甲 | armor | 本体の軽減を解除 |
| memory.antenna | 記憶アンテナ | drain | 資源走査を踏撃へ変更し、資源吸収も停止 |

通常周期は低HPの味方を狙う魔法砲撃→高資源の味方を狙う走査→全体の高速照射→単体の踏撃。走査はゲージ0・資源3減少、高速照射はゲージ2。部位破壊／スタン時の代替は踏撃。HP55%以下で記憶過負荷。大技は記晶降星、Lv45以上は万象再記録。極大技も魔法。

本体には記録核・結晶砲・鏡面装甲・アンテナを焼き込まない。本体と4部位を同一の正方形キャンバスで独立合成し、破壊層だけ消す。大技は全身の別見本で、破壊済み部位がある場合は通常合成を使う。アンテナ初稿の縦長キャンバスと大技初稿の光切れは取り込み前に編集修正する。

専用の結晶地帯背景、固有行動、部位配置、Lv44／45／49／50、勝利／敗北／撤退と保存失敗・再読込・重複防止を検証する。正式採用と全敵の経済・戦闘バランスは後続工程。
