# Plan11-7 日常交流・交流特性：初回実装

2026-10-09。[日常交流仕様](../requirements/plan11-7-daily-interactions-v1-user.txt)を実装する。ジョブ特性2・キャラ特性3・交流特性3の計8個を標準とする。第1・第2枠のジョブ特性は[別添仕様](../requirements/combat-common-traits-v1-user.txt)を正とする。

## 日常側の実装

- 正式ID・表示名で交流特性27種を登録。形態のinteractionTraitIdsと日常専用のprofileTraitIdsを分離。交流特性は数値効果・Rankを持たない。
- 未定義ID・表示枠の重複・8枠超過は拒否。髪色と衣装の複数指定はWarningsから警告を取得でき、例外を許す。
- 本作の人物資料・物語・美術に基づき15形態へ交流特性を各3個登録。水着・聖夜・学園は各形態だけに衣装タグを持つ。再生成はtools/author-plan11-7-traits.mjs。
- 日常では表示タグとプロフィールを参照。戦闘のtrait-equippedは有効な表示特性の開始時スナップショットだけを参照し、プロフィールと未解放の熟達を除く。
- 反応スタイル8種。既存12人物（15形態）にメイン・サブを定義し、70:30で抽選。形態別上書き・明示した条件別Weight変更に対応。好感度による暗黙の変更はしない。
- 共通20、単独特性20、特性ペア20の交流パーツ。各5〜20秒、人物台詞なしの身振り・状況説明を持つ。AND/OR、主体・相手の区別、対称ペア、好感度・環境・Terraform・家具・参加人物／人数条件を評価する。
- 一致した全候補を100/60/35/20で抽選。直近5件は0.2倍、前回と共通話題なら0.5倍。候補が1件でも再利用できる。
- 人物専用→スタイル専用→共通→簡易表示へ演出を解決。専用台詞を生成しない。連続パーツ間の位置・向き・表情・家具・距離を保ち、不一致時は1秒の移動待ちを挟む。
- 散歩・食事・星見・お茶・水辺の5デート。Lv10以上、開始20秒→異なる交流パーツ1〜2件→終了20秒。通常は1〜3分。何度でも利用でき、途中キャンセルは報酬なし。
- 庭の「話す」「一緒に過ごす」を共通交流へ接続し、「デートに誘う」を追加。自律Socialにも抽選した状況説明を接続。
- Sessionは対象人物の生活AIだけを停止し、家具Slotを排他確保。終了・取消で解放。庭変更・戦闘・ADV・Terraformによる生活Runtime停止時は安全終了。Session・履歴・演出状態はセーブしない。
- 完了通知を11-3のAffectionRequestへ渡す。EXP・逓減・保存は既存の好感度サービスが担当。生活催事は既存の完了経路を維持し、自律Socialと回想はEXPを変更しない。
- 人物専用パーツ・演出・デートの登録先をHomeExperienceCatalog.dailyInteractions / dailyPresentations / dailyDatesへ追加。件数上限は設けず、デート一覧はスクロールする。

## 戦闘側の実装

- 正式入口はbattle-plan11-7.json。既存15形態へ13ジョブ固定マスタリーと、ジョブ候補内の第2特性を明示登録。キャラごとの初期選択と数値は暫定調整値。再生成はtools/author-plan11-7-combat-traits.mjs。
- CombatTraitCatalogに13マスタリー＋汎用10＋専用7の30定義。効果ごとのRank1～5テーブルを持つ。第1枠はジョブから取得し、第2枠の未指定・候補外・未定義ID・重複・8枠超過は拒否。
- 既存duplicateRank 0 / 1 / 2 / 3 / 4 / 5を特性Rank 1 / 2 / 3 / 4 / 5 / 5へ対応。セーブ形式と既存の能力育成式は変更しない。Rankと効果量は出撃時に固定し、交流特性は成長させない。
  - 2026-10-10の[Plan11-10最終調整](plan11-10-final-balance.md)では、特性Rankとは別の重複5段階目のHP・攻撃・両防御補正だけを合計10→15%へ変更した。特性Rank対応と効果表は維持。
- 標準は共通2＋既存固有3＋交流最大3。uniqueTraitIdsで既存固有カードの採用数を減らし、固有1＋交流5等も制作可能。既存の基本能力特性は残す。省略した固有カードの効果も適用しない。人物固有3件の既存成長・解放条件を維持し、追加の独自Rank調整は人物制作側で行う。
- 共通ダメージ補正は既存のオーパーツ・固有能力と同じ加算点へ1回だけ適用。支援射撃と資源消費の両条件が成立しても同じ効果を二重に数えない。詠唱開始時に資源消費の有無を予約する。
- HP80%境界、開幕300クロック後の速度切替、対象の状態異常種類数、本体／部位、既存12属性、スタン蓄積耐性へ接続。属性耐性貫通は正の耐性だけを軽減し、弱点を変更しない。
- ブーストファイターは資源獲得時の追加1獲得率。ガンナーは攻撃後の追加装填率。ヒーラーは追加ハートとHP25%以下の緊急行動。初回と以後の確率を分け、行動後は通常の待機時間へ戻す。
- 捕食は上昇量と上限を成長。アルケミストは初期・毎100クロック資源と消費効果。ギャンブラーは7の重みを増やし777成立率を上げる。
- アーティストは資源バフを強化、整数のスキル消費は小数点以下切捨て。歌唱維持費は端数を持ち越し、20ターンの合計でRank1の5%軽減を反映する。
- ジェネラルの通常・強化は各5枠の独立データ。マスタリー・指導者は両陣形に加算し、自身のスキルバフだけを強化。強化状態を通常バフとして登録せず、パンツァー・オーパーツの延長対象から外す。複数指揮官の既存選択を維持。
- パンツァーのHP補正と再生は装甲のみ。工具追加は戦闘開始時だけで再召喚補充なし。破損後の防御制限は既存処理を維持。
- 古い戦闘カタログはジョブ特性未指定を旧挙動として扱い、回帰試験と旧撮影モードを維持する。新カタログのcombatTraitVersion=1では省略を許さない。
