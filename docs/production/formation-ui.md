# 編成・入れ替え画面

編成を誓女の育成画面から独立したしおりへ移動した。5枚の誓女カードの直下にオーパーツ枠を配置し、それぞれの画像から入れ替え画面を開く。編成保存と3つのプリセット、各枠の戦闘設定を維持する。

## 入れ替え

誓女・オーパーツとも左に選択対象の詳細、右に4列×2段の候補カードを表示する。現在の編成一覧を再表示しない。名前検索、名前順／Lv順、ページ送りを共通化し、開始時は選択対象を含むページを表示する。

候補クリックでは保存しない。「決定」で既存の原子的保存処理へ渡し、成功後に編成へ戻る。取消に相当する戻る操作では編成を変更しない。保存失敗時は同じ要求で再試行する。誓女の入れ替えでオーパーツは枠に保持され、装備済み品の重複装備を禁止する。

誓女の詳細にはLv・ジョブ・実能力・3スキル、オーパーツにはLv・5能力の合計・最大2効果と条件を表示する。説明文は右上の「？」へ移し、編成・各入れ替え・戦闘設定・強化・好感度・育成などの文脈で内容を変更する。ヘルプは他の詳細パネルより手前に表示し、背面操作を停止する。

## 検証

- 回帰自動検証9,413項目、Unity C#225ソースのコンパイルを通過。
- Windows Playerビルドを通過。
- 最大解像度1920×1080で、編成・両入れ替え・最終ページ・両保存完了・各ヘルプ、および既存の戦闘設定・神器・戦闘・アイテム・スキルの14画面を隔離保存で確認。
- 両入れ替えは実際の保存処理を通し、編成への復帰、誓女変更時の装備保持、Unity JSONによる保存後の再読込を確認。
- 物理マウスによる実操作確認はユーザー指定により省略。
