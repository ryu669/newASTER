## 実装した一周

敵の行動完了で歌唱を記録し、勝利・敗北・撤退時に、聞いた巨神獣詩と開始編成の人物詩・章を一括保存する。取得済みの巨神獣詩を再び聞いても人物詩の対応判定を行い、戦闘不能者を開始編成から除外しない。演出を捨てても歌唱記録は失わない。固定4詩の勝利配布を通常ゲームから撤去した。

勝利だけが素材・ネクタル・石・覚醒結晶・討伐・世界復元・レリックハントを付与する。保存拒否／例外時は世界・育成・装備を公開せず、同じ候補を保持する。再試行では世界処理・抽選を再実行しない。結果の保存が終わるまで本・再戦・育成へ移動できない。既存の計画4 receipt は再処理しない。

## 保存契約

`formal-campaign-v1.json` の既存 version=1 を維持し、任意の `collection` 台帳を追加した。台帳なしの正式保存は残高・人物・世界・receiptをそのまま保持し、新しい戦闘で台帳を作る。過去の詩を削除したり、歌唱履歴を捏造したり、旧試遊保存を読み込んだりしない。

台帳には終了理由、開始編成、聞いた詩、新規詩・章、全遺物抽選結果、素材の獲得元、遺物と装備を保存する。既知版・ID参照を検査する。安定した collection header を先に読むため、将来版で payload の型が変わっても古いバックアップへ自動的に隠さず停止する。既存の確認付き保全・復旧機能とバックアップを維持する。

## 検証用の初期値

以下は `collection-fixture-2026-10-03`／`colossus-trial-2026-10-03` の検証用定義であり、元作品の確認値・正式ストーリー・正式バランスではない。

- 巨神獣の成功した敵行動は毎回1詩を24候補から均等抽選する。スタンで阻止された行動や継続ダメージで戦闘が終了した行動は歌唱を完了しない。歌唱乱数は戦闘乱数と別の seed 系列を使う。
- 緑還竜の最初の18詩を、現在5人の18詩に明示対応させたテスト定義。他の敵の対応は自動補完しない。人物の章・対応IDは計画3の参照IDと一致する。本文は空のまま読書を停止する。
- 遺物はHPと攻撃の2項目。Lv1の固定値はHP50・攻撃10、1LvごとHP+5・攻撃+2。抽選上限はHP1000・攻撃100。装備は一人1枠・同一品の同時装備なし。装備ステータスに加えて攻撃+5%を適用し、チェイン率は変えない。
- Lv強化は対応巨神獣素材 `10×現在Lv`。直接強化は項目別80%以上から、素材1000で攻撃+1またはHP+10、各上限まで。素材は勝利ごと `10＋召喚Lv`。80%未満はUIを無効にして理由を表示する。
- レリックハントはLv1〜9／10〜19／20〜29／30〜39／40〜50の5帯、1／2／3／4／5回。1回75%で遺物、25%で空。抽選値も保存し、同名の低値で下がらない。歌唱・戦闘・遺物の乱数は分離する。
