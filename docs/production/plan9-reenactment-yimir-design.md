# 再演巨人ユミル：個別仕様

対象ID colossus.reenactment-yimir。春夏秋冬の意匠を持つ石巨人。季節冠・石腕・桜胸甲・記録輪を独立部位とし、桜の平地背景へ接続する。

HP2800＋195×Lv、速度74、ゲージ5。石腕の再演は単体物理135%・待機140%、四季の波紋は全体魔法65%・ゲージ2・待機130%、記録輪走査は高資源対象へ魔法70%・資源3減少・ゲージ増加0・待機100%。石腕または記録輪破壊で依存する行動を四季の波紋へ代替する。走査から波紋への切替でゲージ増加が0から2へ変わるため、大技予告も再評価する。

HP45%以下で季節重奏、与ダメ140%。攻撃部位破壊後60%。季節冠破壊でゲージ低下と蓄積停止、桜胸甲破壊で装甲解除。大技は物理の四季再演、Lv45以上は時環の終幕。大技後待機200%。素材・数値は候補、正式採用と最終難度は後続工程。
