# スレイヤー：既存美術の再審査と交流CG

更新：2026-10-04。人物ID heroine.slayer／ファイターを維持。基準12用途を再確認し、追加CG4と育成用肖像を制作・接続。最終採用前。

既存の立ち・戦闘・SD・表情の原画をgame/art-source/plan9/slayerへ保存。初回の指示・参照・生成元は[計画7指示記録](plan7-art-prompts.md)を維持する。戦闘カットインはmanifestで指定するv3を対象にし、旧v1を採用数へ重複計上しない。CG0は既存庭園CGの別名で、1イベントだけへ対応させる。CG1〜4と肖像は内蔵imagegenで制作し、それぞれ正確な指示と出力を保存した。

[PNG検査](plan9-slayer-asset-validation.json)は9透過画像の原本一致・RGBA・可視輪郭、[CG検査](plan9-slayer-cg-assets.json)は5枚の独立した不透明横長画像を確認。CG0の腰から膝の画角は元の制作仕様による。CG1の初稿は足先が切れたため画角を広げた。寸法目安・手指・透過縁・制作元の権利情報は最終採用審査に残る。

表情は顔領域435,178,111,98／1024×1536だけを元の立ちへ合成。[画面比較](plan9-slayer-expression-render-validation.json)で720p・1080pの3表情とも顔以外の変化0。ADVは顔から腰の画角に拡大し、輪になった髪が切れた初回画像は採用せず上端を0に修正する。育成用の旧肖像は装飾が異なるため、立ち絵と同じ意匠の新肖像へ変更した。

[戦闘8画面](plan9-slayer-battle-validation.json)、[表情と庭園20画面](plan9-slayer-home-validation.json)、[CG10画面](plan9-slayer-cg-validation.json)は同じビルドで記録。初回育成診断の再選択例外を修正した。通常保存前後不変、追加性能測定・実入力・聴取なし。ADV修正後の記録は別ビルドとして追記する。

[5交流の設計](plan9-slayer-event-design.md)とCGは一対一に対応。正式本文・条件・回想への接続は9-6。既存美術と追加候補の制作を、正式採用や計画9全体の完了に読み替えない。
