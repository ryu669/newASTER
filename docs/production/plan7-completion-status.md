# 計画7：完了条件の実ファイル監査

更新：2026-10-04。計画7は未完了。承認待ちは設けず、未達の制作成果物を検証済み機能と区別する。[実ファイルの監査結果](plan7-completion-audit.json)を保持する。

`tools/validate-plan7-completion.ps1` は台帳と実ファイルを読み取り、PNGのIHDR寸法・SHA-256、WAVのSHA-256を照合する。画像や保存を変更せず、プレイヤーや負荷測定も起動しない。未達があれば通常実行は非ゼロで終了し、`-ReportOnly`は同じ不合格の報告を書いて終了する。報告の`complete`はこの素材検査の結果で、Q1〜Q5の全受入れを自動認定する値ではない。

| 条件 | 現在の結果 | 完了に必要な成果物 |
| --- | --- | --- |
| 素材整合 | 合格：画像24、音6、台帳と一致 | 現行の整合を維持 |
| 納品寸法 | 未達5画像 | 背景3層・CGの1920×1080以上、立ち絵の1600×2400目安。実寸は1672×941／1024×1536 |
| 描画レイヤー | 24画像で未納品 | 絵そのものを編集できる制作元。原本PNG・プロンプト・合成SVG8点は保持済み |
| 美術品質 | 24画像の採用状態がcandidate | 顔・手・武器・衣装・透過縁・差分整合の確認。寸法やハッシュでは判定しない |
| 聴感 | 6音源の記録なし | ループ境界・各効果の明瞭さの確認。PCMと再生停止復帰の合格は別記録 |
| Q6実工数 | 1人・1敵・1正式イベントの記録なし | 全制作単位の実作業・生成／ビルド待機を区別した記録と量産見積り |

納品寸法はPNGの実ヘッダーから読む。台帳の立ち絵幅だけを1600に変えた隔離fixtureでは、不一致を検出し、寸法未達も実際の1024×1536を使って維持した。テスト結果は `tmp/plan7-completion-tests`。実台帳・素材・既存設定を変更していない。

実工数を今後検査する場合は台帳の`productionTimeEvidencePath`からJSONを参照する。`units`へperson／enemy／formalEvent各1件、status=complete、coverage=complete-unit-production、activitiesのstartedUtc／endedUtc／kind／actorを記録する。正の、順序付き・重複しない区間を要求し、kind=active-work（actor=humanまたはagent）を待機と区別する。人とエージェントの時間を同一の人時に読み替えない。この形式を用意しても過去の欠落時間を復元したことにはならず、実績の計算やH/E/V見積りを検証済みとは扱わない。

現在の内蔵画像生成は指定した納品寸法を返さず、PNG内部の原画描画レイヤーも返していない。拡大した書き出し、PNGを参照するSVGや単一レイヤーの元ファイルを作るだけでは、この未達を解消したとは扱わない。生成・ビルドの所要時間やコミット間隔から実制作工数を捏造しない。承認を求めないという指示は、未達の合格記録を作る許可とは解釈しない。

機能・描画の最新の証拠は[角冠と配置](plan7-crown.md)、[全戦闘の描画](plan7-full-combat.md)、[Windows等の検証記録](plan7-validation.md)。Core5,583・Unity1,178、角冠版のWindows17起動、1080p通し戦闘97.53%が16.7ms以内という範囲を維持する。今回の素材監査でその機能試験を再実施したとは記録しない。
