## 人物ロットの完了条件

[追加方法](heroine-addition-guide.md)に従い、観察と創作の区別、人物／形態ID、3スキルとジョブ、成長、共通構成の神器、専用20画像、3章30ページ・18詩・5交流、加入・編成・庭・ADV、保存互換と失敗再試行を揃える。画像比率と増員した一覧の最後の人物まで検証し、台帳をavailableへ変更する。家具姿勢は単体の画像に加え、実際の家具との接地と手の重なりを確認する。

Core/DataとUnity C#、Windowsビルド、隔離したPlayer画面、原本と採用画像のSHA-256、本文・参照・ドキュメントリンクを確認する。別形態は人物関係を共有しても、成長・神器・読書進行を混同しない。基準値の最終バランスや物理操作の確認範囲は、結果と分けて記録する。

## 検証方針とGit運用

主要検証は `tools/validate-automatic-chain.ps1`、`tools/compile-unity-scripts.ps1`、追加形態のビルドとPlayer検証スクリプト。画面確認はデフォルト起動1920×1080のみ。自動操作と物理入力を区別し、完了済み人物の画像を繰り返し確認しない。共通描画への追加が対象人物に限定される場合は、既存描画が不変であることを差分で証明する。起動・保存・大量画像の性能調査は後続のユーザー依頼に基づき行ったもので、計画8当時の測定省略を恒久的な禁止として扱わない。

新規作業ブランチはfetchした最新mainから作成し、PRの宛先はmain。計画間のブランチへマージを積み重ねない。継続中のブランチはその差分とmainとの関係を確認する。既存の無関係なUnity設定変更は含めない。元動画、調査画像、ビルド、保存データはGitへ同梱しない。
