## ローカル実装の順序

1. 使用するUnity版と依存、現在のセーブ版を記録する。
2. チェインと終了／演出の契約をコア・テストへ対応づける。既存と差がある箇所を変更前に記録する。
3. 定義JSON／manifestを型付きデータへ変換し、不正ID・画像・座標を拒否する検証を作る。
4. 1敵の本体＋4部位と5人の仮表示でイベント順・破壊・停止／短縮を確認する。
5. 人物1人・敵1体・背景1セットのオリジナル2D品質を確認する。
6. 箱庭1区画・家具3種・人物3枠、ADV線形命令・回想を接続する。
7. 必要な保存版変更と変換表を作り、正常バックアップ・失敗・再試行を検証する。
8. Windowsビルド・オフライン起動・保存復旧・1080p／720pを確認する。
9. 一周のプレイ時間・詩収集・素材量・工数を測り、正式値と量産へ進む。

## 完了条件

### 2026-10-02 ローカル実装：独立自動チェイン

Unityの速度順モードに、編成順の候補走査・独立固定行動・起点の戻り判定・追加一周を接続した。通常コマンドを追加受付せず、チェイン中は資源と論理時刻を変更しない。詠唱の起点補正を予約へ保持し、発動成功後だけ開始する。50%基本率、スキル+10%、最大2人の累積+5%を初期値として実装した。表示には補正とフルチェインの追加進捗を渡す。

人物行動はHeroineChainActionを明示注入する境界を追加した。ただし現在の5人はplaceholder定義（本体へ攻撃倍率0.6）で、正式なHeroineDef JSON読込・任意効果／自動対象ルール・正式人物の行動制作は未完了。回復・支援からのチェイン可否は未確定のため今回起動しない。行動不能は現行コアの戦闘不能のみで、スタン等の状態は未実装。旧非速度順モードは既存検証用に隔離し、正式仕様として採用しない。

tools/validate-automatic-chain.ps1で新規契約を検証し、tools/compile-unity-scripts.ps1で全C#を検査する。既存tools/validate-unity-core.ps1はEditor専用関数を含めて抽出する問題により利用不可だったため、これを全回帰合格とは記録しない。2D表示・覚醒／重複の新数値・ガチャ経済・保存移行は未着手。既存実行ファイルに自動で反映されたとはしない。

今回の実行結果：独立チェイン744 assertions、全C#41ファイルのコンパイル成功。UnityのPlayableBuild.ValidateAndBuildは既存検証967 assertionsとWindowsビルドに成功し、game/Builds/playable/newASTER.exeを更新した。これらは2D移行・正式人物・全状態異常・手動通し試遊の完了を意味しない。
