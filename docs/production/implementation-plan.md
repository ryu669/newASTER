### 現状と修正対象

`WorldCatalog`には15体のID・記憶元・環境があり、`ColossusUnlockState`は1体目初期解放、2〜14体目は直前討伐、15体目は前14体全討伐を処理する。`CampaignState`には初回討伐・環境・庭の基盤がある。計画4の統合保存と失敗再試行を再利用し、保存を分割し直さない。

ただし現行`FormalVictoryView.BuildVictoryWorld`は緑還竜の未取得詩を固定で最大4個付与する。戦闘中の歌唱記録に基づかず、他の敵は空集合。`FinishCheck`の敗北は報酬なし、`DrawRetreat`は詩収集なしで本へ戻る。`StartBattle`は敵IDを選んでも共通の`PlayableBattle`を生成しており、15体固有戦闘の完成ではない。これらを最新版要求へ置換する。
