# 神器の木の武器名

2026-10-11。ノード名にキャラ特性名・マスタリー名を使わない。各ルートで別の武器派生名を持ち、段階はⅠ・Ⅱ・Ⅲ・Ⅳで統一する。

命名は「武器名・ルート別の派生名＋段階」。ユーザー指定の例は「聖剣オーロラ・イスィリオⅠ〜Ⅳ」「聖剣オーロラ・ユースティⅠ〜Ⅳ」「聖剣オーロラ・セリスィⅠ〜Ⅳ」。この例を理由に未実装のオーロラをカタログへ追加しない。

アイアンメイデンは以下を採用した。

| ルート | 武器名 |
| --- | --- |
| 攻撃 | サラマンドラ・イグニスⅠ〜Ⅳ |
| 守護 | サラマンドラ・アルクスⅠ〜Ⅳ |
| 技巧 | サラマンドラ・ウェントゥスⅠ〜Ⅳ |

`WeaponNodeNames` を命名の定義元とし、`ProductionEconomyCatalog` が全20形態・240個の根以外のノードへ適用する。最終段の追加能力名もその武器名にし、人物の特性名を再掲しない。ルートの派生名は本作の創作であり、原作動画で確認した正式名と混同しない。現在の公開15形態にも同じ命名処理が適用される。

根は「武器名の根」。既存ノードID、親子関係、所持・解放・装備・Lv、効果と費用は変更しない。保存は安定IDを用いるため名前の変更で旧装備を失わせない。

検証は `Plan12FirstBatchTests` に追加した。全240名の一意性、キャラ特性名との非重複、3ルート×Ⅰ〜Ⅳ、ユーザーのオーロラ例を確認し、全体12,023 assertionとUnity用270ソースのコンパイルが通過した。証跡は `tmp/plan12-batch/weapon-names-validation.log` と `weapon-names-compile.log`。新しい実行版の画面確認は未実施。
