# 新生獣アステリア：個別制作仕様

世界を結ぶ白い星獣。本体・世界環・星爪・統合胸甲・世界尾・大技・世界統合の戦場の独立7素材。環はゲージ抑制、爪は攻撃抑制、胸甲は防御解除、尾は資源吸収停止。

最低HP比の相手へ物理140%とゲージ1、全体魔法85%とゲージ2、高資源魔法90%と資源4吸収・ゲージ0、単体物理110%とゲージ1の四段循環。爪／尾破壊時は全体共鳴へ置換。ゲージ6、HP50%以下145%激化、魔法大技・待機200%。Lv44／45とLv49／50の境界を維持。先行14体の討伐と世界解放を要求する既存統合条件を保持。

正式採用は原画・合成・部位破壊・結果保存・全体調整後の審査で判断する。
