# 計画9：対象固定と量産不足

更新：2026-10-05。初期5人RC1が完成。現在の実在IDと数量は[配布内容台帳](plan9-release-content-inventory.json)、受入れは[完了記録](plan9-completion-status.md)。以下の着手時の不足は履歴。[旧機械台帳](plan9-content-inventory.json)は着手時の照合結果を保管する。

## 固定した数量

初期人物5、巨神獣15、世界7、章60（巨神獣45＋人物15）、詩450（360＋90）。交流は仕様ですでに各人3本＋恋人後2本と決まっており、計25本。計画文書の「数量未確定」をこの仕様へ照合した。着手時はイベント試験定義だけだったが、RC1では25本の正式本文と個別CGを通常入口へ接続・検証済み。

制作基準案は各イベントCG1点、計25点。既存1点の採用先は正式台本と照合して決める。背景は7世界各3層の21層を基準にし、15戦場へ世界IDで対応させ、個体ごとの色・前景・大技演出を制作する。家具は既存3種＋世界別1種の計10種を最初の制作範囲とする。これらは計画9の制作判断であり、従来の要求に由来する確定数量と区別する。正式台本で追加絵が必要なら量産台帳を更新する。

音はタイトル／書、戦闘、箱庭、ADVの4用途にBGMを配置。既存6音を採用審査し、場面別BGMとUIの決定／取消／ページ／解放SEを追加する。全編音声・歌唱は追加しない。ループの詳細曲数と音の最終採用は9-7までに確定する。

## 着手時に確認した不足（履歴）

- Combat/battle-formal.jsonは5人物・5ジョブの固有戦闘を持つ。残り8ジョブはこの正式戦闘定義に存在しない。Lv基準値の存在と固有ルールの実装を区別する。スレイヤーの実装IDはjob.fighterである。
- 15敵の世界ID・解放順はあるが、出撃できる固有戦闘は緑還竜のみ。残り14体は同じ戦闘の名称変更で埋めない。
- 通常のCollectionContractFixture／HomeExperienceFixtureと、専用試遊のPlan8本文を区別する。既存の取得・既読を保護する正式内容パックへの切替が9-6の課題。
- Illustrations/battle-formal.jsonはplaceholder=true。スレイヤーの候補絵は接続済みだが、残り4人の絵は未接続。素材40ファイルは旧候補版を含む実在ファイル数で、採用数ではない。
- 通常開始は欠落時に初期保存を作り、存在時は読込する方式。安全な入口として「万物の書をひらく」を維持し、上書きする新規開始を追加しない。破損・未知版は既存の停止／復旧に接続する。
- 保存はformal-campaign-v1.jsonの統合envelope。ファイル名のv1をpayloadの版と混同せず、移行判断は実際の各版と内容版で行う。
