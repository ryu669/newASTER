## 取得済みの性能記録

以前は他ゲームと録画アプリの負荷で延期した。最初の有効1080p測定は3485フレームの78.97%が16.7ms以内で未達だった。新しい測定ログを加えた最新ビルドでは3426フレーム、平均16.792ms・p95 16.697ms・p99 16.703ms・最大100.108ms、16.7ms以内98.83%で95%目標を達成した。最大値の停滞も隠さず保持する。コード計測追加と測定環境の差があり、結果改善を最適化の効果と断定しない。

i7-13700F／RTX4070、通常同期1・再生速度1、調整後の専用敵内容版を使用し、ビルド／素材hash・同じrunの175イベント・外部ピーク317050880 bytesを結合した。大技66フレームのp95 16.696ms・100%以内、部位破壊192フレームのp95 16.697ms・97.40%以内。GUI RepaintのみのCPU p95は0.278ms・最大2.783msで、他のCPU処理とGPU・同期待ちは含まない。エンジン起動基準の最初のRepaintは3.470秒、splash終了後。720pの続行時に負荷が変化したためバッチを止め、後の確認も不適合だった。

続行時の720pは3449フレーム、平均16.680ms・p95 16.697ms・最大16.698ms、100%が16.7ms以内で合格。外部ピーク312205312 bytes、同一run175イベント・描画／報酬・通常保存不変を確認した。箱庭・ADV・CGの6場面は各600フレームで、ロード区間と全プロセスの外部ピークを[測定表](plan8-performance-results.md)に記録する。6回の1標本確認を通常確認のhashへ結合して再利用を検証。バックログ開始前にCPU23%、整理後の通常確認も28／19／17%となり、未実施の測定を止めた。バックログ表示は負荷測定を伴わない2起動・画像確認に合格したが、性能合格には代入しない。

終了した測定の再現コマンドは`tools/validate-plan8-telemetry-player.ps1 -AdjustedPerformance -Height 1080`等。今後は実行しない。負荷確認はバッチ開始の3標本と、連続測定中の1標本による変化確認に整理した。直近から2分以上空く、バッチ開始から10分経過する、不適合を検出する場合は通常確認に戻す。不適合時の自動3回リトライは廃止し、そのバッチを止める。ユーザーの他アプリを終了しない。

長い通し再生で自動診断のアクティブ計時が比較用保存を変える問題を検出し、自動captureの計時だけを止めた。通常試遊の計時と明示60秒の保存失敗診断を維持する。最初の失敗診断は性能値として採用しない。

場面別の既存測定コマンドは`tools/validate-plan6-home-player.ps1 -Cases Garden,Adv,Cg,Backlog -SaveForms New -Measure`。今後は実行しない。記録は既存の隔離正式home診断、素材事前検証後の描画、250ms間隔の外部ピーク、最初のRepaintログ観測までの時間を区別する。GUIのCPU値はUpdate・GPU・同期待ちを含まない。`startupSeconds`はcapture時刻で、起動遅延ではない。OSキャッシュは未制御で、プロセス再起動をOSキャッシュ未使用の冷起動と呼ばない。

## 通し試遊の手順

1. タイトルの「計画8 ／ オリジナル試遊」から専用保存を開始する。通常保存へ試遊状態を上書きしない。
2. 緑還竜Lv1で完了した歌を聞く。詩の所有と章進捗・対応条件を必要時に開き、8章を読む。
3. 誓女を育て、装備を開く。庭の操作を必要時に展開し、素材で家具を製作・配置・利用、交流からスレイヤーのイベントを読む。
4. 召喚Lvを順に解放し、不足した育成費を既討伐Lvの再戦で集める。上位Lvとハント遺物を試す。
5. ログイン／時間報酬、抽選・提供割合・100pt交換・チケットの費用を確認する。全費用・成果は保存確定で一度だけ反映する。
6. 保存して終了し、再起動で残高・装備・家具位置・人物利用・詩・章・既読・receiptを比較する。回想を読んでも変更しない。
7. 現行の受入れは最大5操作と15秒以内のBGM一箇所・効果音一つ。上記の全導線を人間が繰り返すことや、時間計測・全音源比較を要求しない。
