# 計画10：4形態の追加とUI整理

2026-10-07。スレイヤー水着、アルケイン、アルケイン学園、シャングリラの順で追加した。現在は15形態・12人・13ジョブ。各形態を加入、人物詳細、育成、神器、編成、戦闘、庭、ADVへ接続している。

|形態|ジョブ|追加機能|人物・口調の資料|
|---|---|---|---|
|スレイヤー水着|ジェネラル|隊長の編成補正、MAX強化、隊長選択の保存|[人物資料](../references/characters/slayer-swim.md)|
|アルケイン|ガンナー|弾倉、再装填、MAX一斉射撃|[人物資料](../references/characters/arcane.md)|
|アルケイン学園|ギャンブラー|3×3 SLOT、5ライン判定、777、外れの扱い|[人物資料](../references/characters/arcane-academy.md)|
|シャングリラ|スナイパー|支援対象の保存、通常支援、MAX詠唱射撃と中断|[人物資料](../references/characters/shangrila.md)|

同一人物の衣装違いは親愛・恋人状態を共有し、育成・神器・読書進行は形態別に保持する。編成・庭に同一人物を重複配置しない。アルケインの通常衣装で映像から確認できたスキルは1つで、残る2つは独自仕様として出典を明記した。学園衣装は27歳の卒業生という本作設定で扱う。

天使の羽・光輪と、衣装、髪、武器、書物などの元の意匠を反映した専用画像を各18点、合計72点用意した。生成物は無加工で採用し、原本とUnity ResourcesのSHA-256を照合する。各形態に3章30ページ・18詩・5イベント40段落を追加し、累計は90章・630詩・75イベント。物語は本作独自の創作で、性格と口調の資料を参照している。

編成画面は「全体 → 選択メンバー → 入れ替え候補」の3階層。メンバーごとに神器1つと、将来のオーパーツ1つの枠を表示する。オーパーツの実装は後日で、現在の枠は予約表示。隊長・支援対象は確認操作を経て保存される。

13ジョブのリソース画像は、弾倉、装甲、照準、スロット、旗など形状自体を変えた。全画面の基準を1600×900の論理座標に統一し、異なる画面比率でも画像の縦横比を維持する。背景、肖像、表情、神器、CG、カメラ表示を見直し、神器の枝とクリック領域、CGと台詞領域の重なりを修正。人物鑑賞画面が空になるカメラ設定と、人物画面でヘルプが隠れる条件も修正した。庭の人物・交流一覧はスクロール領域へ収め、追加人物を選択できるようにした。人数が増えても庭への移動位置が範囲外にならない。

Core検証8,546項目とUnity C#コンパイル185ソースが合格。全体UIは65種類・76画面を確認し、1600×900、1024×768、1720×720を検証した。人物別の検証では1280×720も使用する。Windowsビルド、実行画面と画像検証は各受入れJSONと[UI検証記録](plan10-ui-validation.json)に保存する。UI採取は隔離した保存データを使う自動シナリオで、物理マウス操作による試験とは区別する。

実行ファイルは `game/Builds/plan10-shangrila/newASTER.exe`。ビルドはGitへ同梱しない。再検証は `tools/validate-plan10-expanded-roster.ps1`、`Plan10ShangrilaBuild.ValidateAndBuild`、各人物のplayer検証スクリプト、`tools/validate-plan10-ui-player.ps1` を使用する。

追加手順は[ヒロイン追加方法](heroine-addition-guide.md)。個別実装記録は[スレイヤー水着](plan10-slayer-swim-implementation.md)、[アルケイン](plan10-arcane-implementation.md)、[アルケイン学園](plan10-arcane-academy-implementation.md)、[シャングリラ](plan10-shangrila-implementation.md)。
