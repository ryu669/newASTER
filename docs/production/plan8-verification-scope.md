# 計画8：検証範囲の変更

更新：2026-10-04。ユーザーの直接指示「今後は性能測定は不要。実操作・聴取も最小限にして」を適用する。

今後の性能測定と、そのための負荷確認を行わない。バックログ・家具移動・庭遷移・冷起動の追加ベンチマークを計画8の必須条件から外す。既存の1080p／720p、箱庭・ADV・CGの実測、失敗・延期記録は保存する。未測定の性能やOSキャッシュ条件を合格・保証へ変更しない。

明示的な再開指示があるまで、後続の計画でも性能測定を実行しない。

実操作は最大5操作の基本確認に絞る。対象プレイヤーの画面を確認して、メニューを一つ開く／閉じる、短い本文1行を確認する。全導線、解像度ごとの全操作、連打・取消の全組合せ、実AltTabの全場面確認は要求しない。既存の自動診断は保持する。操作回数は実入力だけを数え、状態指定の診断を実マウス操作と呼ばない。

聴取は合計15秒以内のBGM一箇所と効果音一つで、無音や明らかな音割れの有無を確認する。全BGMループ、5効果、音量差、速度別読書の評価は要求しない。PCM検査や再生要求ログを実聴取へ読み替えない。

人間による初見／周回の時間目標、収集時間の中央値／p90、実30分の操作、Lv120の実到達時間、全77行の人間による読書は必須条件から外す。機能・保存・難度曲線・戦数分布・経済の自動根拠を採用する。量産の体験品質や実時間を保証するものではない。

改訂条件で技術・体験ゲートと計画8全体が完了。実操作5操作と、音声受信部品修正後のユーザーによるBGM・ヒット音確認が合格。[最小確認の証拠](plan8-minimal-smoke.json)へ、修正前の無音報告と修正後の回答を両方記録する。必須から外した未実施は not-run のまま保持する。

Windows操作の経路はcomputer-useの @oai/sky に存在する。従来の「ブラウザ操作しか利用できない」という記載を訂正する。直前の操作は対象画面を確認できず、物理Escapeによって停止されたため、実操作の合格記録には使わない。その後の「計画8完了させて」の指示で対象アプリの実操作を再開し、5操作の最小確認が合格した。
