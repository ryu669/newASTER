# 縦切りプレイテスト手順

更新：2026-10-04。状態：現行仕様。版はGit履歴で管理し、ファイル名に版番号を付けません。仕様整理のみで実装完了を意味しません。

計画8の対象、基準、調整順序と測定の詳細は[詳細実装計画](plan8-implementation-plan.md)、合否の定義は[受入試験](acceptance.md#計画8縦切り通し試遊と調整)を参照する。以下は操作と体験観察の手順で、診断が直接状態を設定した結果を実プレイの記録に数えない。通常プレイヤー保存と隔離試遊の保存先を区別する。

## 目的

万物の書からの出撃、部位選択、スレイヤー操作、歌収集、章解放、環境・箱庭解放、保存・復元が、一つの循環として理解できるかを確認する。

## 手順

1. 万物の書の巨神獣しおりで緑還竜を選び、表・裏の情報が対象を変えずに切り替わることを確認する。
2. Lv1で出撃し、本体と水晶角冠を切り替えて攻撃する。
3. スレイヤーの通常／捨て身、ブースト球、ラストリゾート表示を確認する。
4. 緑還竜の大技予告後、水晶角冠を破壊して中断表示を確認する。
5. 討伐結果で素材、テラフォーミング、新しい歌、環境、箱庭を確認する。
6. 同じ章の異なる詩8件で第一章が解放されることを確認する。戦闘8回・歌唱8回とは同一視せず、重複と未収集を記録する。
7. 保存後に再起動し、歌、章、環境、ページ解放、重複報酬防止が維持されることを確認する。

## 収集する計測値

- 討伐までの秒数、勝率、受理操作数、部位破壊数。
- 大技予告を見て角冠を選んだ割合。
- 「歌を集めると章が開く」「環境が箱庭を開く」を説明できたか。
- 操作迷い、誤操作、理解しづらい表示の自由記述。

## 合格条件

- すべての機械状態がセーブ／ロード後に一貫する。
- 同じ`battleId`の報酬を二重に得られない。
- 部位破壊、大技中断、歌、章、環境、箱庭の各結果が一度だけ表示される。
- 人による操作感・UI理解度の評価は、テスターの実プレイ記録が揃ってから確定する。
