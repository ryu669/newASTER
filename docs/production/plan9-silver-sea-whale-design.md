# 銀海鯨：個別仕様

対象ID colossus.silver-sea-whale。真珠銀と紺の波紋を持つ空泳鯨。本体から潮核・左胸鰭・銀背甲・尾鰭を外せる。銀海の白い石舞台を専用背景とする。

HP2500＋180×Lv、速度76、ゲージ5。銀潮の波は全体魔法60%・待機135%、潜航突進は単体物理130%・待機110%、潮流吸収は高資源対象へ魔法75%・資源2減少・ゲージ2・待機150%。胸鰭または尾鰭破壊で依存する行動を銀潮の波へ切り替える。

HP40%以下で荒潮浮上、与ダメ140%。攻撃部位破壊後は65%。潮核破壊はゲージ低下と蓄積停止、銀背甲破壊は装甲効果解除。大技は銀海奔流、Lv45以上は大海の再誕。大技後待機190%。素材・数値は制作候補で、正式採用と全体調整は後続。
