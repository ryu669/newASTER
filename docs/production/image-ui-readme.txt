newASTER 0.9.5-rc.2 / Windows x64 編成・希少素材・列車ガチャ改修版

このフォルダー内の newASTER.exe を実行してください。
newASTER_Data、UnityPlayer.dll、MonoBleedingEdge、同梱DLLを一緒に保持してください。
Unityエディタや開発用ランタイムのインストールは不要です。

初期5人・5ジョブ、15巨神獣、7世界、60章450詩、25交流、9庭10家具を収録。
人物は名前と顔のカード一覧から選択。名前検索、ジョブ絞り込み、12人ごとのページがあります。
選択後は左に人物と能力・特性、右に育成とスキルを表示します。
Lv欄をクリックして育成、スキル行をクリックして説明全文とLv強化を確認してください。
3スキルはそれぞれLv1～7。強化はネクタルを使い、現在と次の効果を比較できます。
特性アイコンをクリックすると説明を表示。全3スキルLv7で人物固有の熟達特性が解放されます。
神器の木は各人13ノード。枝をクリックして選び、解放・Lv1～7強化・装備を操作できます。
神器は1人1つ装備。旧版の取得済み神器と装備を保持して移行します。
保存失敗時は同じ候補を再保存してください。未保存の強化費用を二重消費しません。

保存先：Windows LocalLow/newASTERLocal/newASTER。更新前に同フォルダーをバックアップしてください。
更新で保存先を削除しないでください。未知の将来版や破損は停止／確認して復旧します。

既知の範囲：
・提供人数は初期5人。200人超の管理準備はありますが、未登場8ジョブと追加人物は継続制作です。
・検索とページ分割は256件の機能検査、画面は初期5人の720p/1080p描画で確認します。
・今回のヒロイン画面は自動描画と機能検査です。人による通し攻略や新規の物理入力試験ではありません。
・聴取と追加性能測定は行っていません。FPSや聴感の保証値は未確定です。
・フルボイス、歌唱音声、Live2D/Spineは収録していません。

配布内容・権利表記：CREDITS.txt、ThirdPartyNotices、ASSET-ADOPTION.json。
配布ファイル照合：PACKAGE-MANIFEST.json。参考ゲームの画像・音・映像は同梱していません。

神器の枝：αは攻撃・会心、βは物理防御・魔法防御、γは速度・会心威力。
最終神器には攻撃＋10%、両防御＋12%、速度＋8%の固有特性があります。
ガチャ・交換・チケット・提供割合・星の恵み・収集画面を装飾刷新しました。

追加操作：誓女一覧下部の「編成」で5枠を選び、顔カードから入れ替えます。編成中の人物同士は位置を交換。保存後、次の出撃から適用します。
巨神獣ごとにN・R・SR・SSRの4素材。記憶とオーパーツの「素材図鑑」で所持数・入手条件を確認。Rは敵Lv5、SRはLv15、SSRはLv30以上の勝利で入手します。
神器の枝IIは2体のR、枝IIIは3体のSR、最終枝は2体のSSRと別の1体のSRを要求します。取得済み神器と所持素材は保持します。
ガチャでは列車が到着して扉が開き、確定済みの人物・素材がホームへ降ります。スキップ／Escで結果へ。設定の動き軽減・短縮に対応します。
