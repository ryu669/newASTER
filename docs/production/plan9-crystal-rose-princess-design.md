# 水晶薔薇姫：個別仕様

対象ID colossus.crystal-rose-princess。象牙の大理石と薔薇鉱晶でできた巨大な女王像。花冠・荊鞭・花弁盾・根の宝珠を独立した部位とし、薔薇庭園の戦場へ接続する。

HP2200＋170×Lv、速度92、ゲージ5。荊の指名は低HP比率の単体へ物理105%、花弁の輪舞は全体魔法65%、根脈吸収は高資源対象へ魔法80%・資源3減少・ゲージ2。荊鞭または根の宝珠破壊で対応行動を、部位に依存しない花弁の輪舞へ切り替える。

HP50%以下で紅晶開花、与ダメ135%。攻撃部位破壊後は60%。花冠破壊でゲージを下げ、蓄積を止める。大技は水晶花嵐、Lv45以上は永遠の薔薇園。大技待機165%、通常待機100／115／125%。候補素材・数値であり、正式採用と全体調整は後続工程。
