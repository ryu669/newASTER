# 計画10 Rの実装

更新：2026-10-06。

R（アアル）を6人目の正式ヒロインとして追加。ジョブはアーティスト。初期編成は従来の5人で、ヒロイン一覧の「Rを迎える」から無料で加入し、編成画面で入れ替える。既存セーブへの追加も同じ操作を使う。加入は保存成功時に確定し、同じ加入要求の再試行でも重複しない。従来の5人向けガチャ確率は維持し、今回はRをその抽選に追加していない。

## 戦闘・育成

3スキル「星音のプリズム」「大空のハーモニー」「未来へ響く翼」、光属性の固定チェイン、13ノードの装備の樹、Lv・スキル強化・覚醒・特性・遺物・報酬を接続した。単体魔法140%、全体攻撃力20%・会心10%の5Battle Turn支援、全体魔法240%・会心15%は参考表示をもとに本作用に定義。スキル名・文章・台本・絵は新規制作。

歌唱ゲージは上限10、通常コマンド成功で2増加。3以上で本人READYから歌唱開始、開始時は消費せず待機100%。100クロックのBattle Turn境界ごと2消費し、歌唱段階は1から最大5へ成長。段階ごと味方の攻撃力5%、会心1%を付与。歌唱中はスキル・パスを禁止し、本人READYで続行または解除。解除は時間を進めず、同じREADYからスキルを選べる。ゲージ不足・戦闘不能等で停止し、歌唱効果だけを解除する。スキルの持続支援と歌唱は別の効果として合算する。

Lv1基礎値はHP320・攻撃42・物理防御130・魔法防御200・速度115・会心12%。既存5人との混成出撃に合わせた本作独自の暫定調整であり、原作Lv90表示や未実装ジョブの概算表をそのまま移していない。

## 人物・物語

性格・口調・観察根拠は [人物資料](../references/characters/r.md) に保存。本作では一人称「ボク」、主人公の呼称「きみ」。才能への自信、理解されない苛立ち、相手の異なる音を聴く成長を軸にした。本作の呼称と恋愛関係は独自設定で、動画で未確認の箇所を原作の確定設定とは扱わない。

[全文](../story-text/Rの物語と交流.txt) は3章30ページ、18詩、交流5本。章は緑還竜・銀海鯨・天塔機の詩に結びつき、既存ヒロインとも接続。好感度1・5・10・15・20の交流、恋人化、回想、既読と保存を既存の仕組みに接続した。一般住民は追加していない。

## 検証と配布

`tools/validate-automatic-chain.ps1` に `NEWASTER_PLAN10_R=1` を指定して実行。既存5人の回帰を含む7,970項目で、6人台帳・混成5人編成・加入保存失敗と再試行・歌唱・全体支援・旧セーブ・物語数量を検証した。

`Plan10RBuild.ValidateAndBuild` はUnity JSONの30ページ保持、全18点のTexture2D取り込み、採用ハッシュ、正式カタログを確認してWindows版を出力する。実機の画面・進行は `tools/validate-plan10-r-player.ps1` で通常セーブとは別の検証用保存を使って確認する。

実行ファイル：`game/Builds/plan10-r/newASTER.exe`。残り7ジョブは未選定で、Rの実装を次の人物の追加基盤として使う。

実機受入れ：1280×720で加入前一覧・能力・装備の樹・編成・戦闘・歌唱・全体支援・箱庭・5交流CG・章回想・全章全交流の読了と再読込の15ケースを通過。1600×900でも能力・歌唱・編成・装備・章・交流CG・全読了を確認。画面画像は `tmp/plan10-r/player-1280/` と `player-1600/` に保存。音声の新録と負荷計測は今回の受入れ項目に含めていない。
