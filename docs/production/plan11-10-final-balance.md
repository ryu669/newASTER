# Plan11-10 数値バランス最終確定（2026-10-10）

現行15形態・12人物・13ジョブの数値調整を完了した。最大装備、支援操作、報酬を使った実育成、最後の重複段階を確認済み。これは現行範囲の数値判定であり、今後追加する人物の数値を保証するものではない。

## 確定した変更

- 成長する時計：論理100ごとに攻撃+10%、上限60%。減衰品の説明も実値60%に整合。
- ジョブ職印13種：全能力30%→20%。マスタリーとは別の装備効果。
- 巨神獣由来15遺物：攻撃型・HP型・複合型の用途に合わせて補正を引き上げた。詳細は[第2回記録](plan11-10-arsenal-and-duplicate-balance.md)。
- 重複5段階目：HP・攻撃・物防・魔防の合計補正10%→15%。重複4段階目の8%から、最後の1枚で7ポイント増える。速度は変更しない。強化画面にも最後の恩恵を記載。
- 新生アステリア：レベル当たり攻撃増加5→10、状態異常の蓄積耐性を最低50%にした。完全無効にはせず、既存の強い耐性を維持。ほか14体の敵数値と、人物のスキル・状態異常の基本仕様は変更しない。

マスタリーは**キャラ重複のみで強化**する仕様を維持した。重複0/1/2/3/4/5に対して特性Rankは1/2/3/4/5/5。マスタリーと第2特性の効果表、重複費用、召喚率、交換保証は据置き。最後の重複では既に上限のマスタリーを拡張せず、永久ステータスで恩恵を補った。重複なしで通常攻略できる基準も維持している。

武器3分岐の数値、成長・覚醒・スキル・オーパーツの費用、ドロップ率、指輪価格は据置き。入手難度の算定は[重複・費用測定](plan11-10-progression.json)を参照。5重複は対象チケット交換だけでも500召喚・150,000石、通常当選を含む2,000シードの平均は425.86召喚。高額な長期育成を攻略の前提にしない。

## 最終戦闘確認

[最終16,320戦](plan11-10-final-matrix.json)。15形態それぞれ1,088戦、15体の敵、武器3分岐、全42オーパーツを対象にした。人物本人を候補枠に置き、同一人物の衣装違いを除いた初期メンバーから残る4人を選ぶ。編成全体の結果であり、本人単独の強さではない。

| 条件 | 勝利 / 戦闘数 | 判定 |
| --- | ---: | --- |
| Lv1・無装備対最初の敵Lv1 | 240 / 240 | 合格 |
| Lv1・無装備対アステリアLv50 | 2 / 240 | 各条件2/8以下で合格 |
| Lv50・スキル7・重複なし・無装備、支援操作あり | 900 / 900 | 各条件3/4以上で合格 |
| 同条件、攻撃・回復中心の比較方策 | 890 / 900 | 比較用。下記の弱点を保持 |
| Lv50・スキル1・無装備、強敵3体 | 341 / 360 | 比較用 |
| Lv10・スキル1・無装備、強敵3体 | 487 / 720 | 格上への比較用 |
| 候補1枠に最終武器Lv7＋全42品Lv120、最低20%/上限100%ロール | 7,560 / 7,560 | 全勝 |
| 5枠最大装備・Lv120・重複0/5、全15体 | 5,400 / 5,400 | 全勝 |

全条件で4,000操作打切り0。最大装備は合成した比較条件で、実際の入手経路とは分離した。Lv120最大装備を難易度基準にはしていない。

攻撃・回復中心の方策では、アステリアLv50に対しR・アルケイン・シャングリラ・シェルが各2/4勝。歌唱・全弾発射・支援・装甲操作を使う方策では同じ条件が各4/4勝になった。固有操作を使わない方策にも一律3/4勝を要求する初期判定は採用せず、比較群として損失を残した。[初期判定の生データ](plan11-10-final-matrix.raw.json)も保存しており、全戦全勝と扱っていない。

支援方策で歌唱開始594回・継続2,285回、指揮570回、錬成3,570回、全弾発射911回、ニトロ101回、蘇生11回、装甲修復60回・防御42回などを実行した。基礎方策にもジョブ資源操作が含まれる。支援方策は自動比較用の一つの戦略で、最適操作の証明ではない。個別の生命操作・装甲ツール・状態延長等は既存の回帰試験でも確認している。

## 報酬を使った育成経路

[実育成1,015戦](plan11-10-earned-journey.json)。初期5人Lv1、初期配布ネクタル2,940・覚醒結晶20、石・素材なしから開始。実戦結果と正式な報酬・育成・武器・オーパーツ・テラフォーム・指輪取引を通し、途中の保存・読込も確認した。後から素材・Lv・装備・領域を注入していない。日次・滞在報酬・召喚収入も使わない保守的な1シード測定。

1,015勝・敗北0・操作打切り0。全期間を通して重複0。指輪の使用後も職業マスタリーは上がらない。指輪は好感度上限を解放するもので、直接戦闘能力を上げる品ではない。好感度99までの反復周回は行っていない。

装備完成後の周回にはネクタル・結晶が余る。素材と石が同時に増えるため、育成・武器・オーパーツ・指輪の必要勝利数を単純加算して総工数にはしない。最大装備は長期目標であり、無装備・重複0のLv50/スキル7でも全15体を突破できる。

終了時の残高はネクタル457,840・結晶4,580・石118,500。1シードで実行可能な経路を確認したもので、全ドロップ乱数や全プレイヤー操作の到達を保証するものではない。時間集計は論理時刻・操作数であり、人のプレイ時間ではない。入手のばらつきは第2回の2,000シード費用分布と狙い品の期待値・95%点を併用する。
