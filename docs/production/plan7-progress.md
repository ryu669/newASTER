# 計画7：最初の美術完成見本

更新：2026-10-03。状態：候補一式を制作・接続し、Windows実画面検証中。計画6の機能完了を引き継ぐ。正式品質ゲートは未通過。[候補見本と残り](plan7-candidate-review.md)、[素材台帳](plan7-candidate-assets.json)を参照。

## 順序と完了条件

1. 素材接続：背景、本体、独立4部位、破壊差分を同一キャンバスで描画する。ゲーム状態を変更しない。
2. 人物1人：全身、通常／喜び／困惑／決意、待機／攻撃／被弾、カットインの候補を制作し、同じ衣装・顔・基準点を確認する。
3. 敵1体：本体に独立部位を焼き込まず、4部位と破壊差分を制作する。各部位の単独破壊を実画面で確認する。
4. 背景1セット：遠景／中景／前景、箱庭・ADVへの適用を制作する。家具3種と人物利用差分の確認を含む。
5. 音・効果：ヒット、防壁、回復、破壊、撃破、基本BGM／SEを制作し、休止・音量・演出短縮を検証する。
6. Windows実画面：720p／1080pで読める操作領域、切替、透過、欠落、レイヤー順、性能を記録する。
7. 完成見本の品質確認：候補の出典・制作記録と比較画面をまとめる。ユーザーの品質確認を得るまで正式採用・5人への量産完了を記録しない。

## 今回の実装

戦闘マニフェストv1に任意の `backgroundResourcePath`、`bodyResourcePath` と、各部位の `resourcePath`、`destroyedResourcePath`、`hideWhenDestroyed`、`drawOrder` を追加した。既存の未制作マニフェストは互換を維持する。

敵の画像は部位選択矩形で切り伸ばさず、同じキャンバスへ描画する。負の描画順は本体背面、0以上は本体前面、同順位は部位ID順。破壊時は確定イベントのHPを使用する。明示消失を指定しない場合、破壊差分欠落時には通常絵と破壊済みボタンを維持する。ファイル欠落・部位と本体の画像寸法不一致は警告付きの仮表示へ戻る。正式マニフェストは背景・本体・部位画像・破壊表現を必須とする。

検証：`validate-automatic-chain.ps1` 5,544 assertions、`compile-unity-scripts.ps1` 86ファイル成功。画像を投入したWindowsの見た目・透過・性能検証は未実施。現在の候補絵は引き続き候補であり、素材制作・完成見本の品質確認は未完了。

## 全身候補の接続

内蔵imagegenでスレイヤー全身候補v1を制作し、正式人物IDの戦闘マニフェストに候補として接続した。[制作・出典・プロンプト記録](plan7-standing-candidate.md)。目標解像度と基準点、差分群、正式採用は未完了。旧候補は保持する。

`fullCanvas` を追加して旧バスト切り抜きと区別し、全身の比率と透過を保持する。ラベル帯の上に画像領域を制限し、足先を帯で隠さない。`-inspectPlan7Standing` は描画だけの確認オプションであり、画面に素材確認と明記する。戦闘の行動者・入力対象を変更しない。

検証用 `tools/validate-plan7-standing-player.ps1` は720p／1080pの実行ファイル撮影と欠落警告・例外チェックを行う。これは候補の接続検証であり、敵素材・背景・差分・音・完成品質の合格を意味しない。

## 表情候補の接続

通常に加えて喜び／困惑／決意の候補を制作し、同人物・同衣装の表情IDでADVへ接続した。[制作・最終プロンプト](plan7-expression-candidates.md)。Resourcesパスを素材IDから解決するため、未制作人物に他人物画像を当てない。全身型と重ね合わせ型を区別し、画像サイズ不一致は通常立ち絵へ戻す。

読み取り専用の比較sceneと隔離セーブで全4種を撮影するツールを追加した。コア5,549 assertions、Unityスクリプト86ファイルのコンパイル、実Unity1,174 assertionsとWindows build成功。正式本文・採用品質・目標解像度・顔以外の厳密一致は未完了。

## 候補一式の接続と実画面

攻撃／被弾／人物カットイン、緑還竜の本体＋独立4部位＋大技、遠中前景、家具3種、スレイヤーSD4種、箱庭CG、BGM／SE6音を追加した。合計24画像・6音源。正式IDとResourceパス、実寸、透過端、ハッシュを台帳へ記録し、生成原本と最終プロンプトを保持する。

実戦の被弾ポーズは、敵行動で実際にHPが減った人物IDから選ぶ。演出イベントの行動者は敵の−1を維持し、描画には「被弾対象」と表示する。敵カットインで破壊済み部位を戻さない。部位が重なる領域の入力優先順位を明示し、破壊済み部位を除外する。文字帯を前景より後へ描画し、背景上の名称と本文が重なる表示を修正した。

家具の同人物再利用は自分の利用スロットを占有判定から除外する。スレイヤー候補の座る／作業／眺めるだけを対応として宣言し、他人物の未制作動作を流用しない。追加検証は3動作、未対応人物、同スロット再利用、未知／重複対応ID、部位入力、敵の実ダメージと対象。コア5,572 assertions、Unityスクリプト87ファイル成功。

タイトルに読み取り専用の美術見本画面を追加した。見本閲覧をアクティブ時間報酬へ数えない。BGM／SE音量、揺れ／フラッシュ軽減、演出短縮、本文・見本文字サイズ、画面モードを保存する。音の停止・再開を画面と同期し、撃破音の重複と、見本を停止して閉じた後に実戦音まで停止する問題を修正した。

Windows検証と性能の最終記録は [検証記録](plan7-validation.md) を参照。納品寸法・編集元・完成品質を解決したとは記録しない。
