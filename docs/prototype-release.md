# newASTER 試作 v0.2 完成範囲

2026-09-20。A案の操作と1周の遊びを確認する、ローカルブラウザ向けの小規模試作。

## 到達点

味方3人を編成し、遺物を装備して巨大ボス1体を討伐。報酬で強化し、短い記憶を読む。強化3段階で「試作クリア」を表示し、その後も再挑戦できる。

- 防御・支援・攻撃の順番を変える編成と、無料で選べる遺物3種。
- 自動通常攻撃、時間停止中の発動／託す、最大3人連携。
- 誓いの蓄積・温存・解放、支援役の1回限りの緊急救援。
- 翼破壊、大技の予告・中断、次の通常攻撃の対象と時刻。
- 味方HPを戦闘画面内に表示。戦績に発動・託す・解放・生存数を表示。
- 遊び方、離席時の一時停止、撤退確認、敗北からの再挑戦。
- 勝利報酬、強化3段階、記憶1ページ、既存セーブ引き継ぎ。

## ブラウザ・起動の検証

既存データとは別のローカルポートで、星片0・強化0から実操作。遊び方の開閉、撤退して星片0のまま戻ること、おまかせでの初討伐（01:20、全員生存、救援1回）、星片4→強化1、記憶帳、再読み込み後の保持を確認。

2周目は3人連携で誓い2を解放後、おまかせに変更。01:03で討伐し、強化2へ進行。390pxと1280pxの両幅で横方向のはみ出しがなく、狭い画面でも結果と再挑戦ボタンが収まることを目視確認。ブラウザのerror/warnなし。

3周目は強化2・翼優先・おまかせで01:09に討伐。報酬で強化3に到達し「試作クリア」を表示。再読み込み後も強化3とクリア表示が保持されることを確認。3周を通してブラウザのerror/warnはなし。

新しいサーバープロセスでHTML・CSS・2つのゲームモジュールが200を返すことを確認。README、Git設定、不正なURLは404。Node.js標準機能のみで起動する。

## 完成範囲の境界

入門難度のため最大連携が強い。防御を先に使う必要がある境界条件はテスト済みだが、普段のプレイで毎回異なる判断を求める難度までは作り込まない。初期翼優先ルートは約1分〜1分20秒、本体集中や育成後は短くなる。

図形・Canvasによる独自の仮ビジュアルを使用。3D、音声、ガチャ、追加ボス、作戦マップ、装備育成は次段階の範囲。戦闘途中の保存と複数タブの同時プレイは非対応。原作のゲーム素材は使用・同梱しない。

## 起動

`start-game.cmd`を実行し、表示されたアドレスをブラウザで開く。Node.jsが必要。このPCではCodex同梱の実行環境を検出する。別環境ではNode.js 20以上をPATHに用意する。追加パッケージのインストールと外部通信は不要。
