# UI・3D・演出の制作状況

2026-10-01。実装とビルド確認を、最終アート品質の確認と区別して記録する。

## 今回の実装

- 戦闘画面は3D舞台と次の敵行動を別の領域に表示し、文字がモデルに重ならないよう配置。
- 本体HP・大技ゲージ・味方HPをバー表示。味方HPは3分の1未満で赤へ変更。
- 敵反撃は5人へ光跡を表示し、大技では幅・色・表示時間を変更。
- Windowsプレイヤーの1600×900画面を保存して確認。既存のデフォルト材質が紫色になる不具合を検出し、Resourcesに格納する独自材質へ置換した。修正後の人物・巨神獣の色、HP表示、支援の効果量を画面で確認済み。

- 物語は段落をページとして前後にめくる。最終ページの読了ボタンだけが既読を保存する。途中閉じ・Escでは既読を変更しない。
- 選択した本体・部位を発光表示。破壊部位は非表示となる。
- 攻撃は選択対象へ光跡を出す。支援は行動者の上へ緑の光跡を出す。描画からダメージ判定を発生させない。
- 一時停止・撤退確認・ヘルプ・結果表示中は舞台の演出時計を停止する。
- 庭は解放状態を反映し、家具の配置枠・種類を3D表示へ接続する。
- 人物の頭・髪・衣装・手足・翼・武器、巨神獣の頭・目・口・爪を独自の仮形状として追加。

- 戦闘結果を発生順に再生し、HP・資源・詠唱・部位破壊をイベント時点の状態に同期。一時停止と演出スキップを追加。演出は戦闘計算を再実行しない。
- 詠唱中の魔法陣、発動時に選択対象へ飛ぶ弾、剣撃の弧、着弾時の拡がる輪を追加。再生キューと共通の仮時間を使い、停止中は動かさない。正式モーションとヒット時点の最終同期は今後の調整対象。
- スレイヤーを正式3D制作の最初の対象として着手。ボブ髪・ピンク系衣装・白い翼・剣の参照方向を用いた新規モデル初版を作成。参照作品のモデル・画像・リグ・動作データを取り込んでいない。
- 共通ボディと30ボーン、ローズ／訓練の別衣装メッシュ、待機・攻撃・詠唱・被弾・勝利の5動作をFBXへ出力。編成1人目の仮形状をこの制作初版へ差し替えた。勝利動作はアセットを用意した段階で、結果画面への接続は未実装。
- 育成ページの1人目の裏面から、2衣装を確認用に切り替えられる。能力・資源・ジョブ状態を変更せず、現在はセーブ対象外。残り4人と巨神獣は仮モデルのまま。

追加後は1030項目の自動検証とWindowsビルドが成功。5動作の取込み・ポーズの有限値、ボディの骨格、別衣装の存在、エフェクトの移動／着弾時点を検証した。1280×720のWindows実行画面でローズ衣装、訓練衣装、詠唱の魔法陣を目視した。これは全ポーズの変形検査、手動の衣装切替から討伐までの通し試遊、性能測定の代替ではない。

## 完成までの残作業

### 2026-10-01 近接表示向けの再制作

初版の粗さへの指摘を受け、スレイヤーを `slayer-beauty-v2.fbx` へ差し替えた。連続した顔面、顔に沿ったアーモンド形の白目、頂点色による虹彩・頬、上下まつ毛、曲線状の髪束とボブ内側、分離した指、薄い羽根、衣装の縫い目・花飾りを再制作。肌・髪・金属の表示を専用シェーダーへ分離し、取込み倍率で輪郭が太くなる問題を実寸基準の処理で修正した。瞬きと軽い微笑みを接続。

育成の1人目の裏面に「スレイヤーを全画面で見る」を追加。顔／全身、正面／斜め／横顔、回転、拡大縮小、2衣装の切替に対応する。鑑賞中は舞台・他の人物を隠し、背景と撮影位置を切り替える。Escまたは「本へ戻る」で復帰する。衣装は引き続き確認用で保存対象外。

生成した品質目標画は `Assets/Game/Art/Concepts/slayer-quality-target-v2.png`。これは造形の参考画であり、実機映像・納品済み3D品質の証拠ではない。制作元とプロンプトは `game/art-source/slayer/slayer-quality-target-v2.prompt.txt` に記録する。

自動検証1036項目とWindowsビルドが成功。白目・虹彩・瞼の両眼分のBlink、口のSmile、骨格、5動作、専用シェーダーを検証した。1920×1080のプレイヤーから2倍解像度で3840×2160の確認画像を出力し、顔・全身・横顔・閉眼を目視した。通常描画で瞬きが待機動作に上書きされる問題と、閉じた瞼が暗く描かれる問題を発見して修正した。これは4Kモニターでの通し試遊や4K負荷測定ではない。

造形の美しさ、全ポーズの変形品質、目標画や参照作品と同水準の品質は、この検証だけでは保証しない。近接版も正式アートの最終受入れ前である。
