# Plan11-1 テラフォーミング

万物の書 → オーパーツと素材を確認 → 新天地。新天地内の「可能世界」で図鑑・星名・世界現象を操作する。

7領域、Lv0～7、共通TP、15巨神獣の主副領域、通常記述Tier I～V、7深層記述、28極相を追加。Lv4以降は異なる2体以上の対応記述が必要。深層記述は各世界の全巨神獣Lv50討伐・対応3章読了で取得する。使用可能な領域はその世界の巨神獣が担当する領域の和集合とする。

TPは仕様の帯別基本値と初回到達ボーナス。Lvを飛び越した場合、初めて越えた全閾値のボーナスをまとめて支給。既存戦闘結果の保存トランザクション内で付与し、同一battleIdの再送は追加付与しない。既存保存済み討伐receiptから最高Lvと記述Tierを復元し、過去戦闘への新TPの遡及付与はしない。

アステリアのページ解放条件は14体初討伐のまま。出撃時は全7領域の現在Lv3以上を必要とし、不足領域をページに表示する。初討伐で新天地成立、Lv50討伐で極相解禁。全7領域最大到達Lv7で七極創世、変更可能な星名と10世界現象を解放する。

Lv6は深層選択と警告確認を必要とする。安定化と到達済みLvへの再設定は無料。初回Lv7は8,000 TP、別の未発見極相のみ1,000 TP。図鑑は実時間を使わず発見順を保存する。発見済み極相は融合ボタンで候補を選び無料再設定できる。

旧terraformingExperienceを初回のみTPへ1:1変換し、migration.plan11TerraformCompletedを保存する。旧庭・家具・マイルストーンを保持し、従来XPは保存互換用として残す。新データの未知IDも保持する。新天地・極相タグを参照APIとして提供し、ヒロイン固有反応は追加していない。

景観は領域色・極相融合形状・深層Modifierの独立した簡易描画。既存庭へ深層Modifierと選択世界現象を重ねる。専用背景画像の制作は含まない。世界現象は解放後に無料で選択・解除でき、能力値には影響しない。

検証: tools/compile-unity-scripts.ps1、tools/validate-automatic-chain.ps1（Plan11TerraformTestsを含む）。実機Playerの操作・描画確認は未実施。
