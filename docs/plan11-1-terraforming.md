# Plan11-1 テラフォーミング

万物の書の「新天地」「可能世界」しおりから直接開く。旧オーパーツ画面の「新天地」入口も利用できる。

## 進行・保存

7領域、Lv0～7、共通TP、15巨神獣の主副領域、通常記述Tier I～V、7深層記述、28極相を実装。Lv4以降は異なる2体以上の対応記述が必要。深層記述は各世界の全巨神獣Lv50討伐・対応3章読了で取得。討伐と章読了の保存処理で永久取得を判定し、画面を開く必要はない。使用可能な領域はその世界の巨神獣が担当する領域の和集合とする。

TPは仕様の帯別基本値と初回到達ボーナス。Lvを飛び越した場合、初めて越えた全閾値のボーナスをまとめて支給する。既存討伐receiptから最高Lvと記述Tierを復元し、過去戦闘への新TPの遡及付与はしない。実際に付与したTPを戦闘receiptに保存し、報酬画面にも表示する。

アステリアのページ解放条件は14体初討伐のまま。出撃時は全7領域の現在Lv3以上を必要とし、不足領域を表示する。戦闘結果の保存側でもこの条件を検証する。初討伐で新天地成立、Lv50討伐で極相解禁。全7領域最大到達Lv7で七極創世、変更可能な星名と10世界現象を解放する。

Lv5→6は深層選択と警告確認が必須。到達済みLv0～7はLv選択で再設定できる。初回Lv7は8,000 TP、別の未発見極相のみ1,000 TP。発見済み極相への切替は無料。図鑑は実時間を使わず発見順を保存する。

テラフォーミング操作は専用のrevision付きトランザクション。失敗時は以前のTP・景観・解放状態を維持し、同じ候補だけを再保存できる。操作IDを永続化し、再起動後も同じ操作への二重消費を防ぐ。保存待ち中の別操作・画面移動を停止する。

旧terraformingExperienceは初回のみTPへ1:1変換し、migration.plan11TerraformCompletedを保存する。旧庭・家具・マイルストーンと未知IDを保持する。前版で利用可能だった家具レシピも維持し、migration.plan11ContentUnlocksCompletedで解放状態の移行を記録する。環境タグ・極相タグ・深層効果タグの参照APIを提供する。ヒロイン固有反応は実装対象外。

全7領域Lv3と世界統合で世界を結ぶ庭も解放する。新規セーブの追加家具は領域条件を満たしてから素材で製作する。既に所持する家具は保持する。

## 景観・図鑑

中央景観の周囲に7領域を配置し、現在Lv・最大Lv・設定Lv・TPコスト・必要記述・解放内容・景観予測を表示する。図鑑には極相28種、深層7世界の討伐/読了進捗、使用済み深層、最大到達Lv、現象、星名を掲載する。

既存背景を主領域と融合先で組み合わせ、領域モチーフと7深層Modifierを別レイヤーで描画する。世界を結ぶ庭の景観にも反映する。196枚の背景を追加する構造にはしていない。雨・雪・花吹雪・蛍・流星群・オーロラ・雷雲・海上花火・光晶雨・ネオン祭は、それぞれ異なる描画でホーム/箱庭に重ねる。選択・解除は無料で、能力値には影響しない。

## 検証

- tools/compile-unity-scripts.ps1: Unity APIとCore分離のコンパイル
- tools/validate-automatic-chain.ps1: 全体回帰とPlan11TerraformTests
- Plan11Build.Build: Windows Playerをgame/Builds/plan11-1へビルド
- tools/validate-plan11-player.ps1 -Visible: 新天地・警告・不足領域・図鑑・星名の画面と専用検証セーブを確認。非表示ウィンドウのフレームバッファは黒くなるため、描画確認にはVisibleを指定する。

Playerのjourney検証は物理ファイルへの保存失敗/再試行・再読込・二重操作抑止・28極相収集・星名保存を確認する。実際の通常セーブを読み書きしない。
