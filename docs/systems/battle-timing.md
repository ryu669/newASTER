# 速度順・スキル待機・詠唱

更新：2026-10-02。状態：現行仕様。版はGit履歴で管理し、ファイル名に版番号を付けません。仕様整理のみで実装完了を意味しません。

通常の速度順・待機・詠唱の定義元です。チェインは通常予定列から独立するため、[戦闘仕様](battle.md)を参照してください。

## 戦闘時間と行動イベント

戦闘には整数の論理時刻を持ち、味方5人と巨神獣の次イベントを時刻順に処理する。論理時刻は動画の秒数や現実の待ち時間ではない。コマンド選択中に時計は進まないため、プレイヤーは予測を見て考えられる。

各味方は、生存／戦闘不能、次コマンド待機／コマンド受付／詠唱中の状態を持つ。画面で他の味方を選ぶことは情報参照だけであり、行動者の順番を入れ替えない。パスは現在の行動者だけを標準待機へ送り、敵の番を直接強制しない。

生存者の次コマンド、詠唱発動、巨神獣行動を統合して一番早いイベントを解決する。同時刻は本作の暫定規則として詠唱発動、巨神獣、味方コマンドの順。味方同士の同時刻は編成インデックス順で固定し、再現可能にする。勝利・全滅・撤退後は発動予約と入力を止める。

## スキルごとの時間定義

全5人の固有3スキルそれぞれに、使用後待機係数と詠唱係数を独立に持たせる。データの配列をコピーして戦闘開始時に固定し、未定義枠や不正な係数は拒否する。速度は戦闘ステータスとして保持する。今回の初期速度110／95／80／105／100と巨神獣速度90は試遊用の仮値であり、原作値ではない。

2026-10-02ユーザー確認：上記の旧試遊値は数値のトライであり、正式人物のステータス生成規則ではない。[育成仕様](progression.md)のジョブ別基準とキャラ別補正は速度を含むステータスの決め方であり、試遊値との併存は矛盾ではない。通常戦闘の予定時刻は、その戦闘に渡された解決済み速度から計算する。試験用の直接指定値とジョブ基準から生成した値を区別し、正式人物の速度を旧5人の試遊配列で上書きしない。

暫定計算式は `ceil(10000 × 時間係数 / (速度 × 100))`。待機は最低1、詠唱係数0は即時発動とする。時間係数は短い50、標準または普通100、やや長い125、長い150を検証用に使用する。この数式・係数・速度と詠唱の相互作用は正式バランスTBDであり、原作の逆算結果ではない。

| 段階 | 予定時刻 | 実装での扱い |
| --- | --- | --- |
| 初回コマンド | 開始時刻＋標準待機 | 速度が高い者から受付 |
| 即時スキル | 現在時刻 | 対象・資源を検証して効果を解決 |
| 即時スキル後の次コマンド | 使用時刻＋使用後待機 | 使用したスキルの係数を適用 |
| 詠唱開始 | 使用時刻 | コストを1回支払い、スキルと対象を予約。まだダメージを与えない |
| 詠唱発動 | 開始時刻＋詠唱時間 | 他者の行動と同じ予定列で処理 |
| 詠唱後の次コマンド | 発動時刻＋使用後待機 | 詠唱時間をもう一度加算しない |

## ブラスター検証の実装範囲

星の術師の強撃枠を、ブラスター検証用の長い詠唱攻撃とした。他の2枠は即時スキルのままで、原作ブラスター全スキル実装を意味しない。短い詠唱・長い使用後待機なども、スキル別データを変えて独立に設定できる。

詠唱中は本人にコマンドを受け付けない。他の味方と巨神獣は予定時刻に行動できる。攻撃の基礎威力は詠唱開始時に固定する暫定仕様。詠唱者が戦闘不能なら予約を削除する。対象部位が発動前に破壊済みなら、不発として予約だけ消化し、黙って本体へ変更しない。予約時に支払った資源は返還しない。この対象消失と返還の扱いは原作確認値ではなく本作の仮仕様であり正式判断はTBD。

現在の遅延効果は攻撃のみ。回復／防御等の詠唱設定は未実装なので、データ検証で拒否し、消費だけ行って無効になる状態を作らない。通常被弾による詠唱中断、スタン／沈黙、詠唱キャンセル、短縮／延長、禁呪、連続発動、範囲盤は今後の実装項目。

## 回復と資源とチェイン

回復人数は引き続きスキル別。行動者だけがスキルを選び、対象確認中は時刻を進めない。予測と確定は同じ時点のHPを使用する。現在の共通検証資源は初期3、本人の次コマンド受付ごとに3増加。正式なジョブ別の取得規則は別途定義する。

チェインの候補・固定行動・補正の寿命は戦闘仕様へ参照し、この予定列の規則で接続を決めません。

防御支援は次の巨神獣行動まで維持して、その敵行動の後に解除する。巨神獣は味方の全員行動を待たず予定時刻に動く。通常と大技で使用後待機を変える仮設定も持つ。

## 画面と検証

行動者の速度、スキルの詠唱時間と使用後待機を表示する。予定列には各生存者の次の確定済みイベントと巨神獣を示し、詠唱は発動と明記する。未選択の将来スキルを勝手に推測して長い行動列に埋めない。味方カードには待機予定時刻または詠唱中と発動予定を表示する。順番でない味方は参照のみで、行動者へ戻るボタンを用意する。

自動検証は初回の速度順、順番外入力の無消費、通常と長い待機の違い、速度と時間の単調性、詠唱開始時の無ダメージ、詠唱中の他者行動、発動後の待機、対象消失・詠唱者戦闘不能、不正対象、短い詠唱と長い待機の独立設定、初期編成の討伐を含む。正式画面は速度順を使用する。旧ブラウザ／固定ターン互換モードの復元を要求しない。

今回の検証は正式な13ジョブや全状態異常の完成を示さない。詠唱専用モーション・音声、速度バフ、状態効果の持続単位、同時刻規則の最終判断、各スキルの正式時間はTBD。

## 対象破壊と詠唱予約

開始時にコストを一度払い、威力の基礎値・対象ID・スキルID・発動tickを予約する。術者戦闘不能は中断、発動前に対象部位が破壊済みなら不発。消費資源は返還しない。本体へ自動転送しない。発動／不発tickから使用後待機を一度加える。これは既存速度仕様の暫定規則を一本化したもので、正式判断はTBD。

一方、プレイヤーの新規選択対象が破壊されていた場合は次コマンドのUIを本体へ戻す。既存の詠唱予約を本体へ変える操作ではない。

## チェインとの非干渉

詠唱予約には起点コマンドのchainContextIdを保持する。castResolveで通常効果を発動した後、一度だけチェイン判定へ渡す。castStart／castCanceled／対象消失による不発はチェインを起動しない。詠唱中の人物が他のチェインへ参加しても予約・威力基礎値・対象・発動tick・資源は不変。チェイン終了後は元の通常予定列へ戻り、チェイン演出時間をtickへ加えない。
