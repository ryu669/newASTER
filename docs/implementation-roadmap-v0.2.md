## 直近の実装順

1. 実プレイで戦闘時間、部位選択、チェイン、UI理解度を記録する。
2. 1体目の5人を正式な人物・ジョブ・個別スキルデータへ置換する（人物の物語詳細はTBD）。
3. 翠還竜の独自3Dモデル、リグ、待機・攻撃・被弾アニメーションをブロックアウトと差し替える。
4. 2体目以降をデータ駆動で増やせる召喚・部位・報酬の制作パイプラインを確立する。

## 実装済み基盤

- 15巨神獣の初回討伐による次ページ解放、No.15の全初回討伐条件、無制限の再召喚。
- 本体・部位・大技ゲージ・Lv45最強技・ランダムなターン限定チェイン補正。
- `battleId`単位の勝利確定、詩・章・テラフォーミング・環境・箱庭区画の連携。
- 家具クラフト／配置／撤去、ヒロイン箱庭配置、好感度イベント、恋人後イベント、物語本の既読処理。
- ★6ヒロインのLv50／80／120、重複、装備の樹、オーパーツ、キンダーガーデンの均等3%・100回任意交換。
- 13ジョブ、ヒロイン固有スキル3つ、巨神獣15体・4〜6部位・24詩、チェイン率強化禁止のデータ検証。

3Dモデルは段階4で独自制作する。参考作品のモデルを流用せず、シルエット・翼／飛行補助装備・戦闘可読性という高レベルの方向性だけを活かす。
