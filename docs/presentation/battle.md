# 2D戦闘の画面・レイヤー・差分・演出

更新：2026-10-02。状態：現行仕様。版はGit履歴で管理し、ファイル名に版番号を付けません。仕様整理のみで実装完了を意味しません。

## 描画層と画面領域

16:9・1920×1080を基準、1280×720で操作可読性を確認する。配置座標は完成見本で確定するためTBD。主要領域は次の責任を持つ。

| 領域 | 表示 | 操作・制約 |
| --- | --- | --- |
| 上部 | 敵名・Lv・本体HP・大技ゲージ・次行動 | Lv45以上の最強技警告は実際の行動候補と一致 |
| 中央 | 基本は行動中のヒロイン一人・巨神獣・部位・ヒット・詩通知 | 敵の全体像と対象部位が見える。文字通知を顔へ重ねない。味方5人の立ち絵の常時同時表示は要求しない |
| 部位選択 | 本体＋4〜6部位・HP・破壊・固有効果 | 絵の直接選択とボタンを併用。破壊済み部位を新規選択しない |
| 右側 | 行動者・3スキル・資源・詠唱／待機・予測 | 可否と理由を示す。カットイン閉鎖を入力確定条件にしない |
| 下部 | 5人のHP・状態・資源・行動順・チェイン補正 | 同一人物のカードと絵を同じIDで解決 |
| 最前面 | 一時停止・撤退・ヘルプ・結果 | 戦闘入力を遮断し、勝敗後の行動入力を拒否 |

描画順は遠景→中景→巨神獣背面部位→本体→前面部位→味方→効果→通常UI→カットイン→必須通知／休止・結果UI。個体内の重なりは定義データで指定する。カットイン中に必須操作が隠れる場合は演出短縮・スキップ入口を別表示する。

背景の視差と敵の緩い拡縮／上下移動を使い、飛行と巨大さを示す。実寸、自由3Dカメラ、リグを必要としない。

## 行動者一人の主表示

2026-10-02ユーザー確認：基本は行動中の一人だけを主表示する。5人編成・全員の戦闘状態を減らす意味ではなく、人物を大きく見せる画面構成の方針である。

- 主表示の人物IDは、コアが確定した現在の行動・演出イベントの行動者IDに合わせる。下部カードの情報参照だけで行動者や主表示を入れ替えない。
- 通常行動・回復・支援では行動者を表示し、対象の一人／複数／全員は下部カードの強調・HP・状態・数値で識別する。複数対象のために味方全員の立ち絵を同時表示する必要はない。
- チェインと追加一周は確定イベント順に主表示を次の行動者へ切り替える。回復対象の強調と行動者の切替を混同しない。
- 詠唱中の状態・発動予定は下部カードで維持する。他者が行動すればその行動者へ主表示を切り替え、詠唱発動時は術者へ戻す。
- 敵行動では巨神獣を行動者として示し、被弾対象は下部カードで確認できるようにする。敵行動中・入力待機中の人物絵の保持／非表示、技固有の例外構図、切替尺は完成見本で調整する。

この方針は旧「中央に味方5人を置く」表示要求を置き換える。演出の違いで対象数・行動順・戦闘結果を変えない。

## データ契約

`partId`は戦闘定義の部位IDと一対一。本体は部位数へ含めない。名前・絵の矩形・配列の見た目から対象を推測しない。破壊差分は消失を明示する場合にのみ省略できる。演出専用の非選択装飾レイヤーは戦闘部位と別管理する。

`sequence`は一戦内で単調増加し、重複／逆順を拒否する。描画層は既に確定したイベントと状態を受け取り、HP減算、乱数抽選、詩付与、報酬付与を行わない。既存イベント形式へ直接追加するか、アダプターでこの契約を満たすかはローカル実装時の判断とする。

## 選択と破壊

直接選択はレイアウト基準の独立した矩形領域。多角形は初回未対応。透明画素を命中判定へ流用しない。重なりは`inputPriority`、同順位は安定ID順で解決する。カーソル／選択枠／部位ボタンの強調を同期する。

破壊イベントは通常絵→破壊差分または明示消失へ切替え、破壊通知と固有効果を表示する。新規選択を禁止する一方、破壊済み状態は図鑑と戦闘ボタンで確認できる。選択対象の破壊後は戦闘・速度仕様の新規対象と予約対象の規則に従い、絵と予測値を同期する。予約済み攻撃の再対象ルールは戦闘層の規則に従い、表示側で変更しない。

結果再生・スキップ・撤退の境界は[戦闘仕様](../systems/battle.md)に従う。破壊差分欠落は通常絵＋破壊表示等の明確な代替と警告にし、欠落を正常な消失と扱わない。

## 演出種別

| 種別 | 2D表現 | 必須情報 |
| --- | --- | --- |
| 通常攻撃 | 攻撃ポーズ、小移動、ヒット、数値 | 行動者、対象、確定ダメージ |
| スキル | 専用ポーズまたはカットイン、効果、音 | スキル名、資源、対象、結果 |
| 詠唱開始 | 詠唱差分、詠唱表示 | 発動予定時刻。ダメージ済み表示にしない |
| 詠唱発動／中断 | 発動絵または中断通知 | コアが確定した発動／不発 |
| 回復・防御・支援 | 対象強調、回復色、盾など | 対象本人、回復量／状態。HP満タン・戦闘不能を誤表示しない |
| チェイン | 行動者順の強調、カットイン連続 | 次参加者、回数、公開済み補正。接続後は固有固定行動を自動再生 |
| 敵大技／最強技 | 全体絵／部位強調、予告、効果 | 対象・中断結果。Lv条件をコアと一致 |
| 詩 | 台詞帯／短い通知 | 同一IDの詩本文、取得済み／新規。描画時間で取得を決めない |
| 撃破 | 敵の崩壊差分／フェード、結果移行 | 一度の勝利確定。表示側で追加報酬を生成しない |

尺・移動量・揺れ幅・各技のヒット位置はTBD。最初の縦切りで調整し、演出尺と戦闘時計の詠唱／待機を別データにする。

## 演出時計と復帰

表示キューは待機→再生中→休止／短縮→完了で遷移する。休止は演出時計を止め、音の停止／復帰も同じイベントに紐付ける。スキップは未再生の装飾を省略し、確定済みの最新状態を表示する。イベントを再計算しない。低フレームレートで通知を見逃してもログから確認できる。

非アクティブ、ヘルプ、撤退確認では新コマンドを受け付けず、手動再開を要求する。撤退確認を閉じただけで新攻撃を進めない。実装が戦闘途中保存を提供しない場合、再起動は万物の書へ戻り、未確定の勝利報酬を追加しない。

設定は揺れ軽減、フラッシュ軽減、演出短縮、BGM／SE音量を独立させる。演出短縮を選んでも部位・HP・詩・行動順・報酬が変わらない。

## 独立チェインの表示

接続判定→成功した人物の固定行動→次接続判定を順次表示し、スキル・対象選択を開かない。通常予定列とチェイン参加者を別表示する。候補順・補正寿命・終了条件は[戦闘仕様](../systems/battle.md)へ参照する。

## フルチェイン表示

起点への戻り接続成功で「フルチェイン」を表示し、起点から編成順に追加一周の固有行動を自動再生する。通常参加人数と追加一周の進捗を別表示し、6人目という表示にしない。追加一周に接続判定や入力待ちの表示を挟まない。勝敗で打ち切られた残りを絵だけ攻撃済みにしない。通常／短縮／スキップは同じイベント列へ同期する。
