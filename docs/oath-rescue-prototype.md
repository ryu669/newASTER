# 誓いの温存・解放と緊急救援

2026-09-20 実装。A案の自動戦闘と「発動／託す」を維持した追加試作。

ANGELICA ASTER本体で観察した、資源を保持する利点と消費する判断、支援職の自動回復を参考にした。以下はnewASTER独自の仮仕様であり、原作の数値やジョブ仕様の再現ではない。

## 誓い

- 「託す」成功ごとに1蓄積、最大3。連携後も持ち越す。出撃時は0。
- 2以上を保持すると全員の通常攻撃が10%上昇。技には適用しない。
- 指示待ちに「誓いをすべて解放して発動」を選ぶと、現在の蓄積をすべて消費し、その連携だけ強化する。
- 1消費につき、攻撃技と回復量は20%増加、防壁の有効時間は2秒延長。防壁は引き続き次の1撃のみ半減。敵への崩し・支援の次技強化・遺物の時間は延長しない。
- 3解放なら攻撃技1.6倍、回復は最大HPの32%、防壁は12秒。連携順・対象による既存の補正も適用する。
- おまかせは即発動し、託す・解放を行わない。手動で蓄積した誓いは保持する。

## リネの緊急救援

リネ生存中、実際にダメージを受けてHPが最大値の25%以下になった生存者を、最大HPの30%回復する。本人も対象。戦闘全体で1回限り、誓いは消費しない。致死ダメージからの復活や、吸収で被害0になった場合の発動はない。全体攻撃は編成順に被害・救援を処理する。

## 確認

`node --test tests/battle.test.mjs`：27件成功。蓄積上限、持ち越し、自動操作での温存、解放効果、次連携への効果持ち越し防止、救援の回数・生存条件・並べ替え、討伐までの進行を検証。

ブラウザでも出撃→2回託す→誓い2の解放を操作。保持効果、解放前の防壁10秒・回復28%・攻撃技40%増の予告、解放後の残数0と戦闘記録を確認した。

ゲーム内の効果予告と残数で選択を確認できる。強化値や装備によって温存と解放の優劣は変わり、現時点の数値はバランス調整前の仮設定。
