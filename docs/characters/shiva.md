# シヴァの人物設定と物語

2026-10-11。人物・形態IDは `heroine.shiva`。本名は柴まりか。人物設定・本文・専用画像・ジョブ操作・表示の確認を完了し、通常プレイへ追加済み。

## 概要・性格

明るい声と行動で周囲を励ます天使。本名は柴まりか。本作では休む人の返事を待つことや、誰かに元気を分ける自分も休むことを覚えていく。助けられるだけの人物にせず、何を望むかを自分の言葉で伝える。

## 口調

一人称は「あたし」。率直で明るい口調。励ましを連呼するだけにせず、迷いを認め、休む提案や相手の意思を聞く台詞も持たせる。

## 葛藤・関係の進め方

尾頭懐音との救助・救済と深い親愛を保つ。1周年の物語で描かれた過干渉への抗議と謝罪も関係の一部として扱う。まりかを死亡扱いにせず、主人公へ懐音の役割を置き換えない。

[動画の時刻付き関係記録](../production/heroine-relationships.md)を原典の根拠とし、下記の章・交流は本作オリジナルとして分離する。成人として描き、原典から現在年齢を推測しない。

## 戦闘と成長

ジョブは `job.healer`。固有特性は「みんなでがんばろう！」、能力は「ポジティブ思考」（毎ターン、自身の最大HPの2%を回復。）。神器名は「フリスビーテ」。ジョブのマスタリー強化はキャラ重複のみ。装備の木は13ノード、3ルート4段階＋初期の根。ノード名は特性名と重複させず、武器名とルート名に段階Ⅰ〜Ⅳを付ける。

特性フレーバー：元気な声は、隣で休む人にも届く。手を伸ばす強さと、返事を待つ優しさを忘れない。

- 第2章「懐音先輩への便り」：10ページ。記憶晶竜の謳を整理する机で、まりかは便箋を広げた。懐音先輩へ何から書こうか迷っている。
