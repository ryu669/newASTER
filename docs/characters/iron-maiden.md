# アイアンメイデンの人物設定と物語

## 概要・性格

永遠教会の修道女。務めと信仰を大切にし、アイオーンへの敬愛を強く持つ。相手を守ろうとする責任感が、戸を閉めてすべてを引き受ける行動に偏りやすい。本作では鍵を預けること、食事の席へ戻ること、役目ではなく名前で呼ばれることを通して、隣に人を迎える。

## 口調

一人称は「私」。落ち着いた丁寧な言葉を使い、親しい場面では短い冗談や照れを見せる。信仰を他人への説教や無条件の正しさへ置き換えない。

## 葛藤・関係の進め方

アイオーンとの関係は、一方向の敬愛に加えて本人からの信頼を保つ。ヴァイパーとは不仲でも共闘できる。主人公との恋愛で教会の関係を消さない。
