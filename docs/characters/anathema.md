# アナテマの人物設定と物語

2026-10-11。人物・形態IDは `heroine.anathema`。本名はアナスタシア・テンプル。人物設定・本文・専用画像・ジョブ操作・表示の確認を完了し、通常プレイへ追加済み。

## 概要・性格

誇り高く華やかな振る舞いと、菓子や食事を楽しむ素直さを持つ天使。本作では失った席へのこだわりを、今の暮らしと自分で交わす約束へ結び直す。強さを誇示するだけでなく、隣の人の疲れに気づいて剣を置く行動を描く。

## 口調

一人称は「私」。令嬢らしい整った言葉を基本に、驚きや食事の場面では感情が先に出る。高慢さだけで固定せず、約束を守る誠実さを具体的な行動で示す。

## 葛藤・関係の進め方

アイコノクラストとの異世界の同行は、アナテマの夢に現れる時点を区別する。デウスとの菓子作りの一件を恋愛関係へ広げない。

[動画の時刻付き関係記録](../production/heroine-relationships.md)を原典の根拠とし、下記の章・交流は本作オリジナルとして分離する。成人として描き、原典から現在年齢を推測しない。

## 戦闘と成長

ジョブは `job.fighter`。固有特性は「令嬢の極悪覇気」、能力は「騎士の誓い」（HPが50%以下のとき、受ける攻撃ダメージを15%軽減。）。神器名は「青薔薇の夜想曲」。ジョブのマスタリー強化はキャラ重複のみ。装備の木は13ノード、3ルート4段階＋初期の根。ノード名は特性名と重複させず、武器名とルート名に段階Ⅰ〜Ⅳを付ける。
