# アヴァランチの人物設定と物語

## 概要・性格

借りと返礼を忘れない、機転の利く天使。軽口を交えながら状況を見極め、勝つ側を選ぶ器用さを持つ。本作では帳面で恩を精算する癖から、食事や次の約束を楽しむ関係へ進む。仲間を置いて先に着くより、一緒に帰る判断を自分で選ぶ。

## 口調

一人称は「私」。くだけた短い言葉と軽口を使う。恩返しの話を取引だけにせず、反応を確かめる間や照れを残す。
