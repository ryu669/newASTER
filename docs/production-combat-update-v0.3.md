# 正式版制作：戦闘更新 v0.3

覚醒（50→80→120）・一括育成・ガチャ報酬・重複強化の実装を継承する。重複・育成でチェイン確率は変化しない。

## 個別支援

5人の役割用仮キャラクターに、自己回復、大技ゲージ減少、全体軽減、全体回復、他の生存者への資源補給を割り当てた。歌い手は強撃枠に単体回復も持つ。支援は資源3を消費して行動済みとなり、攻撃チェインを終了する。回復人数はスキル定義で決まり、戦闘不能者を蘇生しない。資源補給は自身を対象に含めない。最新の操作・対象規則は[5人戦闘の動画検討と修正仕様](five-hero-battle-review.md)を参照。

育成ページ裏面と戦闘ボタンは同じコアから支援名・効果量を取得する。正式人物と13ジョブの割当・資源ルール・固有3スキルは別途確定が必要であり、この仮5役を正式ジョブとして扱わない。

## 巨神獣の段階変化

現在の共通仮戦闘は本体HPが50%以下になると怒り状態になり、敵ダメージを1.25倍する。大技ゲージ条件を満たす場合、大技を優先する。部位破壊と防御による軽減は段階補正後に適用する。画面予測と実際の反撃は同じ計算を使用する。

翼撃・緑晶の嵐・星還の奔流は仮称。15体の固有行動表・閾値・倍率・技名はTBD。正式個別ストーリーは本更新で確定しない。
