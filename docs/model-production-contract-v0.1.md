# ヒロイン着せ替えモデル制作契約 v0.1

## 目的

縦切りのヒロイン1人を、戦闘、箱庭、会話、衣装差分で同一のリグへ差し替え可能にする。既存作品のモデル、リグ、テクスチャ、モーションを参照素材としても流用しない。

## 必須構成

- 共通ボディ：衣装に隠れる領域も、衣装の開口部・物理揺れ・ポーズで破綻しない範囲まで連続したゲーム用メッシュにする。
- 共通スケルトン：全衣装でボーン名、向き、基準ポーズを一致させる。
- 衣装別メッシュ：上衣、下衣、靴、装飾、飛行補助装備を独立して差し替える。衣装はジョブ性能を変えない。
- マテリアル：肌、布、金属、結晶を分け、衣装側だけを差し替えられるようにする。
- LOD：戦闘用、箱庭用、遠景用を用意する。数値は制作時に性能測定で確定する。

## 変形試験

- 腕上げ、前屈、走行、着地、攻撃、被弾、座り、家具利用で交差・穴・極端な伸びがない。
- 衣装の端、ケープ、飛行補助装備はボディを貫通しない。
- 衣装を切り替えても、顔、手、関節、共通装備ソケットがずれない。

## データ接続

Unityでは`HeroineOutfitDefinition`で衣装ID、メッシュID、覆う部位を管理し、`HeroineOutfitState`だけが現在の衣装を切り替える。衣装に戦闘能力、チェイン率、好感度、物語進行を持たせない。
