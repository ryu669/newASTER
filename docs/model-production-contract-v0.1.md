# ヒロイン着せ替えモデル制作契約 v0.1

## 目的

縦切りのヒロイン1人を、戦闘、箱庭、会話、衣装差分で同一のリグへ差し替え可能にする。既存作品のモデル、リグ、テクスチャ、モーションを参照素材としても流用しない。

## 必須構成

- 共通ボディ：衣装に隠れる領域も、衣装の開口部・物理揺れ・ポーズで破綻しない範囲まで連続したゲーム用メッシュにする。
- 共通スケルトン：全衣装でボーン名、向き、基準ポーズを一致させる。
- 衣装別メッシュ：上衣、下衣、靴、装飾、飛行補助装備を独立して差し替える。衣装はジョブ性能を変えない。
- マテリアル：肌、布、金属、結晶を分け、衣装側だけを差し替えられるようにする。
- LOD：戦闘用、箱庭用、遠景用を用意する。数値は制作時に性能測定で確定する。

## 変形試験

- 腕上げ、前屈、走行、着地、攻撃、被弾、座り、家具利用で交差・穴・極端な伸びがない。
- 衣装の端、ケープ、飛行補助装備はボディを貫通しない。
- 衣装を切り替えても、顔、手、関節、共通装備ソケットがずれない。

## データ接続

Unityでは`HeroineOutfitDefinition`で衣装ID、メッシュID、覆う部位を管理し、`HeroineOutfitState`だけが現在の衣装を切り替える。衣装に戦闘能力、チェイン率、好感度、物語進行を持たせない。

## スレイヤー制作初版

2026年10月1日、正式モデル制作の対象をスレイヤーとし、最初の制作データをUnityへ接続した。これは上記の変形試験をすべて通過した正式完成品ではない。動画の明るいボブ髪、ピンク系衣装、白い翼、剣を参考にした独自形状であり、原作アセットは使用しない。

編集元は `game/art-source/slayer/slayer-production-v1.blend`、Unity用は `game/unity/Assets/Game/Resources/Characters/Slayer/slayer-production-v1.fbx`。`tools/build-slayer-model.py` をBlender 4.3で実行すると両方を再生成する。再生成はその2ファイルを置き換えるため、手作業で仕上げた後は変更を退避してから実行する。レビュー画像はローカルのBuilds内へ出力し、参照動画・抽出画像をGitHubへ登録しない。

共通ボディは衣装下の胴体・手足・足先を含む連結メッシュ。初版のボディは18,849頂点、共通骨格は30ボーン。指ボーンはあるが指先の分離・変形と細かな皮膚表現は未完成。衣装は別メッシュでローズと訓練を切り替え、ボディ自体を削除しない。顔、髪、翼、剣は共通とする。衣装確認は育成ページの1人目の裏面から行い、確認中の衣装はまだ保存しない。

現在のウェイトは距離に基づく初期値、体表はボクセル結合後の三角形が中心。肩・肘・股関節などの変形品質を保証する手作業のトポロジーとウェイト調整は未完了。衣装端の厚み、肌との間隔、腕上げ・前屈・走行・座り・家具利用の各試験、表情と瞬き、テクスチャ、LOD、メッシュと材質の統合は正式受入れ前の残作業。
