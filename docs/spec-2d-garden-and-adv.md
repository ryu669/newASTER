# 詳細仕様：2D箱庭・交流・ADV v0.1

更新：2026-10-02。[現行要求](game-requirements-v2.md)と[2D要件](2d-illustration-spec.md)を優先する。配置と演出を詳細化するが、実装変更・セーブ変換は今回行わない。

## 1. 箱庭の構成

背景を最背面とし、家具・人物を独立配置する。人物方式はSDまたは立ち絵でTBD。まず1区画、家具3種、人物3枠以上で検証する。戦闘編成とは別保存し、家具や人物の入替えに待機時間・スタミナを要求しない。

```text
GardenArtDef { gardenId, backgroundAssetId, layoutId, placementZones[], occlusionMasks[] }
FurnitureArtDef { furnitureDefId, spriteAssetId, footprint, drawAnchor,
                  interactionSlots[], interactionArtByActionId }
Placement { instanceId, defId, gardenId, zoneId, x, y, orientationId }
Occupant { heroineId, gardenId, slotId, furnitureInstanceId?, actionId? }
```

位置はレイアウト基準の正規化座標を用いる。範囲は0〜1、非有限値を拒否する。家具サイズ・接地位置は絵の外周とは別の`footprint`と`drawAnchor`で持つ。家具向きの対応画像がないときは、人物・左右非対称の絵を安易に反転させない。向き変更可否は家具定義で明示する。

描画順はゾーン→接地Y→安定instanceIdとし、前後へ手動配置する機能の有無はTBD。柱、屋根、樹木で隠れる部分は前景マスクにする。画面外や人物の顔を常時覆う配置はプレビューで通知する。初回は自由座標・グリッドなし・同一ゾーンのfootprint重なり禁止。辺接触は許可。詳細は[実装契約](spec-implementation-contracts.md)7章を適用する。

## 2. 配置操作

閲覧→家具選択→配置プレビュー→確定／取消。プレビューは未保存の一時状態。範囲外・在庫なし・同一instanceの二重配置・不正な向きを拒否し、確定時だけ保存対象を更新する。取消・画面閉鎖で元の配置を保つ。

設置済み家具は選択→移動／撤去。移動では同じinstanceIdを保持し二重に増やさない。撤去は配置だけを解除し、所持を削除しない。素材返却・再クラフトの数値は従来TBDを維持する。人物の同一庭内／複数庭への重複配置を拒否し、移動前に利用中の演出だけを終了する。

クリックは家具の選択領域と人物の会話領域を分離し、重なり時は選択候補を表示する。家具で人物が隠れても名簿／配置枠から交流へ入れる。

## 3. 家具利用と交流

待機→利用可能スロット選択→利用差分／小移動→交流→待機。スロット不足や未対応差分では通常待機に戻す。家具利用の失敗で好感度、物語、恋人イベントを永久に阻害しない。

同じ人物を座り差分へ替える場合は顔・衣装の同一性を維持する。専用絵がない家具は利用不可の理由を示し、汎用ポーズで対応可能な定義だけを再利用する。利用演出の反復で好感度や報酬を付与しない。

交流は対象heroineId・イベントIDを明示して開始する。配置・利用状態とイベント解放条件は別管理。好感度3本、恋人後2本、解放／読了／回想の境界は既存仕様を維持する。具体内容、条件、専用CG枚数はTBD。

## 4. ADV・個別イベント・回想

```text
AdvSceneDef { sceneId, scriptId, backgroundAssetId, cast[], cgAssetIds[], audioCueIds[] }
ActorDisplay { heroineId, positionSlotId, outfitId, expressionId, poseId }
AdvCommand { lineId, kind, speakerId?, textId?, assetId?, transitionId? }
```

基本表示は背景→人物→CG／効果→台詞枠→操作／バックログ。人物とCGを併用するかCG表示中の立ち絵を隠すかはscene定義に明記する。人物位置は画面スロットを持ち、左右2人以上の顔と台詞枠が干渉しない。演出で文字を焼き込まない。

背景・表情・衣装の切替は同じanchorとpivotで行う。画像遷移は即時／フェードを用意し、時間はTBD。欠落表情は同じ人物・同じ衣装の通常表情へ戻す。別人物へ代替しない。必須CG欠落は仮表示と警告とし、正式素材受入れでは不合格にする。

文章速度、クリック進行、オート、既読スキップ、バックログ、途中終了、回想を提供する。初回の読了確定点はシナリオの終端。画像ロード完了、最後の画像表示、閉じる操作だけで読了にしない。バックログへ戻って同じ行を見ても報酬を再発火しない。

回想は表示専用セッションとし、好感度・交流権・恋人状態・素材・初回報酬を変えない。未解放シーンは条件だけ表示し本文／CGを先出ししない。回想の途中終了は通常の箱庭／書へ戻る。

## 5. 保存と移行の境界

保存は家具instance、配置座標／ゾーン、人物配置、イベント解放／読了、人物ごとの好感度を別項目にする。利用中の瞬間的ポーズやフェード進行は必須保存対象にしない。ロード時は利用可能性を検証して通常待機へ復帰する。

既存の家具スロットを自由座標へ移す場合は移行表を用意する。未知の家具／人物IDは元データを保持し安全な未配置状態として通知する。3D座標を無条件に2D座標として読み込まない。保存版番号・既存データの形式確認・移行方式はローカル実装修正時に確定する。今回は既存セーブに触れない。

## 7. 初回方式の具体化

[実装契約](spec-implementation-contracts.md)7〜9章を適用する。座標は左上原点、yが大きいほど手前。配置プレビューは未保存、確定時に再検証。ADVは線形命令列、lineId単位既読、endでscene読了、途中再開は未対応で再入場は冒頭から。初回に選択肢・分岐は入れない。回想は既読追加も含め進行を変えない。既存セーブの変更は後続ローカル作業で版管理・移行と併せて行う。
