# 正式版に向けた戦闘判断UI・確率修正 v0.1

更新：2026-09-30。Unity縦切りへの実装記録。正式版全体の完成を意味しない。

## 仕様と実装

- 攻撃ボタンに、現在の対象へ与える実ダメージ予測と次の攻撃への接続率を表示する。残りHPを超える予測や実ダメージは表示しない。
- 接続率は検証用に基本65%＋ターン補正。補正は接続抽選にのみ加算し、ダメージ倍率への直接加算を廃止する。正式版の基本確率はTBD。
- 攻撃の接続成功時は次の手動選択攻撃が同じチェインを継続し、2人目以降は段階的に威力が上がる。失敗後の攻撃は1チェインから再開する。各人の行動は1ターン1回なので最大5人。
- 回復・防御は攻撃チェインに数えず、接続状態を終了する。行動順は自由。攻撃ボタンの予測は接続状態に追従する。
- 人物・装備・好感度の成長で接続確率を変更しない。
- 次の敵行動と5人それぞれへの被ダメージ予測を表示する。角冠・翼の破壊や防御を即座に予測へ反映する。
- Lv1～44はゲージ満タンで通常の大技、Lv45～50は極大技を発動してゲージを消費する。角冠破壊による上昇停止・ゲージ低下で予告を取り消す。
- 検証用の通常大技加算は20、極大技加算は既存の45。個体別の正式行動・数値はTBD。現状は全巨神獣に共通戦闘を使用する。
- 出撃ごとに乱数シードを生成し、戦闘ID・シード・LvをUnityログへ記録。同じシードと行動で接続抽選を再現できる。予測表示や拒否された操作は乱数を消費しない。
- 勝利による召喚Lv解放・ガチャ石付与は、報酬の初回確定に成功した場合のみ実行する。保存形式の変更はない。

## 自動検証

`tools/validate-unity-core.ps1`はUnity同梱の.NET SDKでCoreとDataをコンパイルし、`PlayableBuild`の戦闘判断テストを実行する。NuGetや外部パッケージは不要。生成物は`tmp/core-validation/`へ置く。

2026-09-30の結果：**612アサーション成功**。

- 100シードで接続の成功・失敗、最大5人チェイン、同一入力の再現を確認。
- 接続補正を変えても初撃のダメージが変わらないことを確認。
- 味方攻撃と敵攻撃の予測値・実際のHP減少が一致。
- 不正対象は資源・行動権を消費しない。
- 支援によるチェイン終了と全体防御、角冠破壊による大技中断。
- 低Lvの大技発動・ゲージ消費、Lv45の極大技。
- 初期編成・部位破壊戦略でLv1に勝利できる。

Unity参照アセンブリと.NET Standard 2.1を使い、UI・Editorを含む全C#ソースのコンパイルも成功。これはUnityでのインポート・実行・Windowsビルド成功とは区別する。

Windows再ビルドは`LicenseClient-nishi`への接続拒否・タイムアウトにより完了できなかった。旧ビルドに今回の変更は含まれていない。保存ラウンドトリップを含むUnity内の全検証と画面確認は未完了。
