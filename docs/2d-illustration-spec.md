## 2. 戦闘画面と演出

16:9・1920×1080を着手基準にする。味方5人は左〜下側、巨神獣は中央〜右上側を基準に、敵の全体像と対象部位を大きく見せる。右側3スキルと下部5人カードは現行UIを出発点とし、人物絵・敵絵・部位・予告・資源・詩表示が干渉しないよう配置する。最終座標はTBD。

通常攻撃は戦闘ポーズの短い接近／復帰または小移動、ヒット効果、ダメージ数値、軽い揺れ。スキルは専用ポーズまたはカットインと効果。必殺技は人物または敵の一枚絵／複数レイヤーと効果を使う。技の尺は完成見本で決め、実際の速度・詠唱・使用後待機と混同しない。

背景は遠景・中景・前景を分け、視差、パン、拡縮で飛行と奥行きを表す。3D空間を模倣する自由カメラ操作は加えない。録画はテンポ・予告・ヒットタイミング・必殺技の尺を2Dへ翻訳する参考とする。指定ローカル録画は今回の環境から未閲覧で、観察値を追加確定しない。

## 3. 巨神獣の部位表示契約

本体画像＋4〜6部位レイヤーを個体単位で用意する。部位は安定ID、通常画像、破壊画像、消失の明示指定、位置、pivot、描画順、選択領域を持つ。部位HP・大技中断・行動変化は既存戦闘コアで判定し、絵を見て計算しない。

対象選択領域は画像の透明領域や矩形とは別データ。重なる部位は優先順位を固定する。部位選択ボタンも維持し、小さい部位を画面上で直接押せなくても選べるようにする。破壊後は再選択を禁止し、対象の切替方針は既存の戦闘設計に従う。

差分は同じキャンバス・pivotで描く。破壊差分の欠落を正常な消失として扱わない。欠落は警告と明確な仮表示にし、進行やIDを壊さない。再出撃・ロードで全表示状態をコアから復元する。

## 4. 人物・箱庭・ADV

人物は同じ顔・衣装・配色を立ち絵、顔アイコン、戦闘ポーズ、表情、CGで維持する。衣装切替は人物IDと性能を変えず絵を差し替える。表情や衣装の位置が切替で飛ばないこと。既存の比較用2D絵は品質検討資料であり、人物採用・権利・品質を確認せず正式採用しない。

箱庭は1背景に家具をレイヤー配置する。配置座標、前後関係、クリック領域は2Dデータとして定義する。人物SD／立ち絵と家具利用ポーズで、待機・交流・利用を表す。配置状態は戦闘編成と独立して保存する。既存の3D座標から変換が必要なら、保存形式・移行とバックアップをローカル実装修正時に同時設計する。今回はセーブを変更しない。

ADVは背景＋立ち絵＋表情差分、重要な場面はイベントCG。文章速度、オート、既読スキップ、バックログ、回想の受入条件を維持する。CG数と内容、人物別の追加差分はTBD。

素材はsRGB PNGを基本とし、人物・部位・効果はRGBA透過、背景は不透明。立ち絵1600×2400、戦闘絵1024〜2048角、背景・CG1920×1080以上を着手目安とする。最終解像度・圧縮・アトラス・メモリ予算はTBD。編集元はレイヤーを保持し、ゲームへは編集元に依存しない書き出し画像を渡す。

取り込み先案は`game/unity/Assets/Game/Art/Illustrations/`、編集元は`game/art-source/2d/`。Resources／Addressables等の読み込み方式はローカル実装時に決める。量産前にGit LFS等の大きい素材の保管方式を確定する。台帳は素材ID、作者、制作日、編集元、用途、利用条件、採用状態を持つ。

## 6. 受入れ・後続作業の条件

1. 今回：現行要求と2D表示・素材要件のみを改訂する。古いブラウザゲームは廃棄方針だけを要件へ記載する。
2. ローカル：既存Unityコアとセーブを維持し、3D表示・モデル鑑賞・必須モデル検証を2D表示へ置換する。
3. オリジナル人物1人・巨神獣1体・背景1セットで2D品質を検証する。
4. 味方5人、部位差分、通常／必殺／短縮、万物の書、箱庭、ADV、回想を縦切りへ接続する。
5. Unityコンパイル・Windowsビルド・オフライン起動・既存セーブ復元・性能を確認し、工数測定後に量産する。

受入れは1080p実画面で顔・武器・敵の巨体・部位・予告の可読性、差分位置、透明縁、5人同時表示、箱庭前後関係、ADV表情を確認する。1280×720でも操作と文字が読めること。通常／短縮／スキップ、停止復帰、対象破壊、再出撃、欠落素材で同じ入力・乱数の結果と報酬が一致すること。

揺れ軽減、フラッシュ軽減、演出短縮を独立に用意する。正式受入れは画像と実行ファイルを見て判断し、仕様書だけで品質合格にしない。

今回のコミットにUnityコード・シーン・素材・保存形式の変更は含めない。既存3D実装と制作元はローカル移行まで現状のまま残す。Unityビルド・2D画面検証は後続作業であり、今回実施済みとはしない。
