# 速度とスキル待機と詠唱による行動順

ユーザーの確認により、5人戦闘は速度と直前の使用スキルで行動順が変動する。ブラスターの詠唱は発動前の時間であり、スキル使用後の待機とは分離する。これを最新版として、従来の自由順で味方全員が1回ずつ行動した後に敵が動く方式を置き換えた。

更新：2026-10-02。時系列と暫定チェインの現行契約は[実装契約](../data/contracts.md)2〜3章。下記の3D表示・旧互換モード・過去検証結果は履歴であり、2D版の受入れや旧ブラウザ復元要求ではありません。

## 根拠と確認範囲

ユーザーが明示した確定要件は、速度が行動順に影響すること、やや長い／長い待機のスキルは次行動を遅らせること、ブラスターに短い〜長い詠唱が存在すること。

参照動画は `D:\M02_gamemovie\ANGELICAASTER\天使戦闘\023戦闘_エキドナ.mkv`。40〜100秒、100〜150秒から静止フレームを抽出して確認した。全編視聴・音声解析ではない。エキドナのBLASTER表示、スキルの詠唱マーク、行動列に現れる発動枠、範囲選択盤を確認した。「コンセクティブテンタクル」の説明に待機時間が短い、詠唱が普通と表示され、使用後待機と詠唱の区分が同じスキル内で異なることを確認した。原作の範囲攻撃300%／375%、禁呪、3連続行動、状態異常付与値は本作の確定データへ転用しない。

## 戦闘時間と行動イベント

戦闘には整数の論理時刻を持ち、味方5人と巨神獣の次イベントを時刻順に処理する。論理時刻は動画の秒数や現実の待ち時間ではない。コマンド選択中に時計は進まないため、プレイヤーは予測を見て考えられる。

各味方は、生存／戦闘不能、次コマンド待機／コマンド受付／詠唱中の状態を持つ。画面で他の味方を選ぶことは情報参照だけであり、行動者の順番を入れ替えない。パスは現在の行動者だけを標準待機へ送り、敵の番を直接強制しない。

生存者の次コマンド、詠唱発動、巨神獣行動を統合して一番早いイベントを解決する。同時刻は本作の暫定規則として詠唱発動、巨神獣、味方コマンドの順。味方同士の同時刻は編成インデックス順で固定し、再現可能にする。勝利・全滅・撤退後は発動予約と入力を止める。

## スキルごとの時間定義

全5人の固有3スキルそれぞれに、使用後待機係数と詠唱係数を独立に持たせる。データの配列をコピーして戦闘開始時に固定し、未定義枠や不正な係数は拒否する。速度は戦闘ステータスとして保持する。今回の初期速度110／95／80／105／100と巨神獣速度90は試遊用の仮値であり、原作値ではない。

暫定計算式は `ceil(10000 × 時間係数 / (速度 × 100))`。待機は最低1、詠唱係数0は即時発動とする。時間係数は短い50、標準または普通100、やや長い125、長い150を検証用に使用する。この数式・係数・速度と詠唱の相互作用は正式バランスTBDであり、原作の逆算結果ではない。

| 段階 | 予定時刻 | 実装での扱い |
| --- | --- | --- |
| 初回コマンド | 開始時刻＋標準待機 | 速度が高い者から受付 |
| 即時スキル | 現在時刻 | 対象・資源を検証して効果を解決 |
| 即時スキル後の次コマンド | 使用時刻＋使用後待機 | 使用したスキルの係数を適用 |
| 詠唱開始 | 使用時刻 | コストを1回支払い、スキルと対象を予約。まだダメージを与えない |
| 詠唱発動 | 開始時刻＋詠唱時間 | 他者の行動と同じ予定列で処理 |
| 詠唱後の次コマンド | 発動時刻＋使用後待機 | 詠唱時間をもう一度加算しない |

## ブラスター検証の実装範囲

星の術師の強撃枠を、ブラスター検証用の長い詠唱攻撃とした。他の2枠は即時スキルのままで、原作ブラスター全スキル実装を意味しない。短い詠唱・長い使用後待機なども、スキル別データを変えて独立に設定できる。

詠唱中は本人にコマンドを受け付けない。他の味方と巨神獣は予定時刻に行動できる。攻撃の基礎威力は詠唱開始時に固定する暫定仕様。詠唱者が戦闘不能なら予約を削除する。対象部位が発動前に破壊済みなら、不発として予約だけ消化し、黙って本体へ変更しない。予約時に支払った資源は返還しない。この対象消失と返還の扱いは原作確認値ではなく本作の仮仕様であり正式判断はTBD。

現在の遅延効果は攻撃のみ。回復／防御等の詠唱設定は未実装なので、データ検証で拒否し、消費だけ行って無効になる状態を作らない。通常被弾による詠唱中断、スタン／沈黙、詠唱キャンセル、短縮／延長、禁呪、連続発動、範囲盤は今後の実装項目。

## 回復と資源とチェイン

回復人数は引き続きスキル別。行動者だけがスキルを選び、対象確認中は時刻を進めない。予測と確定は同じ時点のHPを使用する。現在の共通検証資源は初期3、本人の次コマンド受付ごとに3増加。正式なジョブ別の取得規則は別途定義する。

最大5人・個別ヒロインによるチェイン率強化禁止を維持する。チェインは通常の行動順から独立した一連の処理。接続成功後に参加人物の固定チェイン行動を入力なしで実行し、2人目以降も同様に次の接続判定へ進む。速度順で次の攻撃が来ることを条件にしない。旧時系列接続方式は廃止。候補順・資源・通常待機への影響は[実装契約](../data/contracts.md)2章のTBDとして別管理する。

防御支援は次の巨神獣行動まで維持して、その敵行動の後に解除する。巨神獣は味方の全員行動を待たず予定時刻に動く。通常と大技で使用後待機を変える仮設定も持つ。

## 画面と検証

行動者の速度、スキルの詠唱時間と使用後待機を表示する。予定列には各生存者の次の確定済みイベントと巨神獣を示し、詠唱は発動と明記する。未選択の将来スキルを勝手に推測して長い行動列に埋めない。味方カードには待機予定時刻または詠唱中と発動予定を表示する。順番でない味方は参照のみで、行動者へ戻るボタンを用意する。

自動検証は初回の速度順、順番外入力の無消費、通常と長い待機の違い、速度と時間の単調性、詠唱開始時の無ダメージ、詠唱中の他者行動、発動後の待機、対象消失・詠唱者戦闘不能、不正対象、短い詠唱と長い待機の独立設定、初期編成の討伐を含む。旧ターン制のテストは明示的な互換モードに分け、正式画面は常に速度順を使う。

今回の検証は正式な13ジョブや全状態異常の完成を示さない。詠唱専用モーション・音声、速度バフ、状態効果の持続単位、同時刻規則の最終判断、各スキルの正式時間はTBD。

## 戦闘結果の順次再生

戦闘計算と画面上の演出再生を分離した。コマンド確定時に、攻撃、回復、支援、パス、詠唱開始、詠唱発動、中断、巨神獣行動の結果を発生順のイベントへ保存する。計算は次のコマンド受付まで進むが、画面はイベントを一つずつ再生する。再生はダメージ計算や資源消費を再実行しない。

各イベントは論理時刻、行動者、対象、ダメージ、回復対象、大技区分、部位破壊と、その時点のHP・資源・部位HP・詠唱状態を保持する。表示中のHPバーと3D部位の表示はこの保存状態を使い、後続イベントの結果を先に見せない。詠唱発動は予約した術者と対象を使い、直前の通常攻撃の対象を流用しない。予定列は計算済みの次コマンド以降の予定を示すもので、再生中の過去状態の再計算ではない。

再生中はスキル実行、対象変更、パスを受け付けない。一時停止、ヘルプ、撤退確認中は再生時間を止める。部位破壊メッセージの表示時間も停止する。スキップは残る演出だけを破棄して計算済みの状態へ戻し、報酬や資源を重複付与しない。勝利・全滅の結果画面は最後の演出後に開く。撤退を確定した場合は未再生の演出を破棄し、討伐報酬を付与しない。

試遊用の表示時間は詠唱開始0.7秒、通常0.8秒、大技1.1秒。遅いフレームでも一度に複数イベントを飛ばさず、新しく開始したイベントは少なくとも一度表示する。正式モデルのモーション長、ヒット時点、カメラ、効果音との同期は未実装でTBD。現在の3D表示は仮モデルと簡易エフェクトであり、完成したキャラクター演出ではない。
