# 戦闘動画を参考にした画面改良

2026-10-01。`055戦闘_スレイヤー.mkv` の30〜55秒と110〜145秒を画像化し、プロフィール・編成・実戦・スキル発動・敵大技の画面を確認。抽出番号は動画の秒数と同一ではない。音声・連続した操作ログは確認していない。

## 観察

実戦画面では敵名とHPが上部、操作する人物のスキル群が右側、行動中の人物・対象・HPや行動順が下部に表示される。部位選択時は複数部位に名前とHPが表示される。スキル発動では人物の接写、敵大技では大きなエフェクトと技名表示がある。

## 実装

- 万物の書の紙面UIから戦闘専用画面へ切り替える。上部に敵名・HP・大技ゲージ、中央に大きい3D舞台、右に選択中の誓女・資源・3スキル・敵の行動予告、下部に5人のカード・HPを表示。
- 上部の本体／部位ボタンはHP・破壊状態を表示し、選択対象の破壊効果を説明する。
- 下部のカードで行動者を選ぶ。行動後は次の生存・未行動の人物を自動選択する。任意の順への切替を維持する。
- 攻撃威力・接続率・資源消費は行動前に表示。破壊対象への攻撃、行動済み・戦闘不能者のスキルは実行できない。
- 空中戦では地面を非表示にし、独自の星を背景へ配置する。

参考映像の画面設計から着想を得た配置変更。映像・画像・人物モデル・スキルアイコンをゲームへ取り込んでいない。人物接写・大技の本格エフェクト・顔カード用正式アートは今後の制作対象。

## 検証

Unityの既存戦闘・育成・保存検証703項目成功、Windowsビルド成功。1600×900と1280×720のWindows実行画面を画像保存して確認し、部位ボタン・3スキル・味方5人のHPが画面内に収まることを確認した。人物選択後の全操作を手動クリックで試遊した記録ではない。
