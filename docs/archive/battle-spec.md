## 遊びの中心

「今、技を出して立て直すか。敵の攻撃を受ける危険を承知で、仲間へ託して連携を伸ばすか」。この判断が編成によって変わる戦闘を作る。

通常攻撃は自動で続く。毎回の技を選ぶ代わりに、編成時に連携の順番を作り、戦闘中はその連携をどこまで伸ばすか決める。

## 1戦の構成

| 項目 | 試作の仮設定 |
| --- | --- |
| 編成 | 3人。将来の人数拡張を妨げないデータ構造にする |
| 敵 | 空に浮かぶ巨大ボス1体、本体と翼の2対象 |
| 通常攻撃 | 各味方が3戦闘秒ごと。初回は1秒ずつずらす |
| 初回の指示 | 戦闘開始から12戦闘秒後 |
| 次の指示 | 前の連携の終了から12戦闘秒後 |
| 託した後の待ち | 2戦闘秒。その間は敵味方の通常行動が進む |
| 1回で託せる数 | 最大2回。最大3人連携 |
| 戦闘の目標時間 | 判断待ち・演出を除く60～90秒。数値調整で検証する目標 |

「戦闘秒」はシミュレーション上の時間。選択中・連携演出中・一時停止中には進まない。実時間の制限は設けず、考える速さで不利にならないようにする。

## 発動と託す

指示可能になると戦闘時間を止め、現在の候補と2つのボタンを表示する。

- **発動**：これまで託して参加予約した味方、現在の候補の順で技を実行する。託していなければ候補1人だけ。
- **託す**：現在の候補を参加予約し、編成順の次の生存者へ候補を移す。戦闘を2秒進め、次の指示を開く。予約者はまだ技を使わない。

最初の候補は編成の先頭。発動後の次回候補は、今回最後に発動した味方の次の生存者とする。同じ連携へ同一人物を2回予約できない。全生存者が予約・候補に含まれたら「託す」は無効となる。

指示中は「今発動：防御 → 支援」「託した後：防御 → 支援 → 攻撃」「敵の大技まで残り1秒」のように、効果と待つ危険を表示する。選択中も残り時間を表示するが、カウントは止める。

### 例：防御 → 支援 → 攻撃の編成

1. 防御役が候補になる。今発動すれば即座に味方を守る。
2. 託すと、防御役の技を予約し、2秒の通常戦闘後に支援役へ。
3. もう一度託すと、さらに2秒後に攻撃役へ。
4. 発動で防御、支援、攻撃の3人が順に技を使う。

最大連携は強いが、防御や回復の発動も合計4秒遅れる。大技が迫っているときには途中で発動する理由が生まれる。敵の予告と候補順がこの判断を生んでいるかを、試作で検証する。

## ジョブの役割

以下の効果は仮設定。連携順が意味を持つよう、効果の適用順を明示する。

| 役割 | 通常攻撃 | 技 | 連携での意味 |
| --- | --- | --- | --- |
| 防御 | 小ダメージ | 味方全員に6戦闘秒の防壁。各人の次の被ダメージを50%軽減して消える。敵の被ダメージを6秒間20%増加 | 早く出せば守れる。先に出して後続の攻撃を強める |
| 支援 | 小ダメージ | 生存者全員の最大HPの20%を回復。次の味方のダメージ技1回を25%強化（6秒で失効） | 早く出せば立て直せる。攻撃役の直前に置く理由になる |
| 攻撃 | 中ダメージ | 選択部位へ通常攻撃の3倍のダメージ | 防御・支援の効果を受けて大きな一撃を出す |

倍率は乗算、防壁・強化は同種で累積せず更新。連携中は戦闘時間が止まるため、前の技の効果は後の技へ確実に適用される。最初の試作では連携確率、ランダム追撃、スキル抽選を導入せず、判断の効果を確認する。確率連携の追加は次段階の候補。

## 敵・部位・空中演出

- 通常攻撃は5戦闘秒間隔。生存している味方を編成順に1人ずつ狙う。
- 初回の大技は開始18秒に予告し、24秒に発動。以後24秒周期で繰り返す。全員が対象で、予告は6秒。
- 本体と翼は別HP。本体HPが0で勝利。翼を攻撃しても本体HPは減らない。
- 翼破壊で次に来る大技1回を取り消し、以後の大技ダメージを30%減らす。追加素材を1個獲得する。
- 翼破壊後は攻撃先を本体へ変更する。同じ連携の途中でも、次の技から本体を狙う。
- 部位の選択は指示UIが開いている間にできる。通常攻撃とダメージ技はその対象を使う。防御・回復の効果先は固定。
- 空中位置は最初は演出のみ。部位へ飛ぶ、技の後に戻る、ボスの翼が崩れる動きを付ける。

初期数値は本体HP1250、翼HP280。防御役はHP260・攻撃13、支援役はHP180・攻撃12、攻撃役はHP210・攻撃26。敵の通常攻撃は28、大技は65（翼破壊後は30%軽減して四捨五入）。現在は操作を学べる難度で、早期発動を必要とするバランスは引き続き調整する。

## 自動進行・例外

通常攻撃の自動進行と、指示の自動選択は別の機能とする。「おまかせ」ONでは指示時に常に即発動し、選択待ちを挟まない。通常のプレイヤーと同じルール・ダメージを使い、隠れた強化はしない。初期状態はOFF。

候補や予約者が「託す」の待ち時間に戦闘不能になった場合、その人物を予約から除く。候補不在なら次の未予約の生存者を選ぶ。全生存者が予約済みなら次の指示では発動のみを許可する。予約も候補もいない状態で全滅なら敗北。

同時刻の通常行動は味方を編成順に処理し、その後に敵を処理する。各行動の直後に勝敗を判定する。指示発生と通常行動が同時なら通常行動を先に処理する。勝敗が決まった後の連携・攻撃は実行しない。

画面を離れたら一時停止。復帰時に過ぎた実時間分の攻撃をまとめて処理しない。再挑戦ではHP、予約、効果、部位、タイマーを初期化する。

## 画面構成

中央は巨大ボスと小さな味方の戦闘。上に本体・翼HPと大技予告、下に味方3人のHPと編成順、右に必要なときだけ指示UIを出す。

右の指示UIには現在の候補、予約済みの味方、発動する効果、次に託す相手、2秒待つことを表示する。連携中は顔のカットインと「1 → 2 → 3 CHAIN」を使い、誰の効果が出たか短く示す。

敵の予告・味方HP・部位選択を演出で隠さない。1人の技の演出は約0.6秒、3人で約2秒を目標にする。巨大な敵の姿を見続けられる画面を保つ。

## 討伐後

勝利で素材3個、翼破壊で追加1個。初回勝利で記憶1ページを確定解放する。素材4個でチーム強化1段階、最大3段階、各段階で基礎HP・通常攻撃力を初期値の10%ずつ増加させる。敗北では素材を減らさず、編成変更と再挑戦へ戻れる。

画面は「編成 → 戦闘 → 結果 → 強化／記憶 → 編成」。勝利報酬は1戦につき1回のみ反映し、強化段階・素材・記憶解放をローカル保存する。

## 試作で確認すること

| 確認点 | 合格の目安 |
| --- | --- |
| 意思決定 | 最大連携まで託す場面と、途中で発動する場面の両方がある |
| 編成 | 同じ数値でも順番を変えると、防御・回復・攻撃の出しやすさが変わる |
| 操作量 | 60～90戦闘秒でおおむね4～7回の指示機会、1機会に1～3選択。実時間も計測する |
| 説明可能性 | 連携が何人になったか、待つ間に何が起きたか分かる |
| 部位 | 翼破壊で安全を取るか、本体集中で早く倒すかを選べる |
| 周回 | 報酬、強化、再挑戦、初回の物語解放まで一周できる |

数値を変えても毎回最大連携が最善なら、まず待ち時間・予告・回復量を見直す。判断が忙しすぎるなら指示間隔を延ばす。面白さの検証前に、キャラクター数や育成項目を増やさない。
