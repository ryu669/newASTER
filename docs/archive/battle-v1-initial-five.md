2026-10-02、動画で未確認の部分を本作独自として設計・調整する許可に基づく。実行用 `Combat/battle-formal.json` はv3/newaster-original。技名・Lv7攻撃倍率・状態値・持続・技の物理／魔法／対象／詠唱区分は資料の確認値を保持し、以下の算式・基礎値・資源・固定行動は元作品の再現確認値としない。当時の検証はLv1固定編成だった。現在は育成と所持5人編成を接続している。初期バランス値であり最終バランス合格ではない。

表はジョブLv1基準。人物のHP／攻撃／防御補正は各10000bp（許可範囲9000〜11000、合計30000）、速度は10000bp（9500〜10500）。HP・攻撃はジョブ×人物補正×特性を広い整数で計算し最後に切り捨て、物防・速度はジョブ×人物補正。魔防・会心率はジョブ値。例えばスレイヤーの実行攻撃は47、アンダーマインの実行HPは540。これらは装備込みの動画値から逆算した数値ではない。会心基準150%、持続会心威力はポイント加算、会心率はジョブ＋持続＋技の加算で上限100%。人物特性はチェイン確率を変更しない。

最初の行動可能時は開始量のみ。以降はパスを含む本人の次のコマンド受付で回復する。成功攻撃後の増加は対象数によらず一度、支援・パス・不発では得ない。被ダメージ増加は生存する本人が0より大きい敵ダメージを受けた場合のみ。詠唱は受付で費用を一度消費し、発動で再消費せず、不発で返却しない。独立チェインは資源を消費・獲得せず、チャージ・特殊兵器・コマンド固有WTを発動しない。翠還竜の尾が有効なら成功敵行動後に生存者の資源を各1減らし、破壊／スタンで妨害を停止する。

アンダーマイン技3は `n=min(9,現在チャージ)` を消費し、元倍率280%へ `(1+0.1×n)` を乗算する。0個でも発動可能、最大15保持、チェインにこの補正は適用しない。エクスカリパン技3は6弾丸の特殊兵器行動で、確認値240%に200ポイントを加えて440%とする（240%×300%ではない）。通常ガンナーの弾種・装填操作の全面継承を実装したという意味ではなく、本作の初期資源ルール。

### 待機・詠唱・WT

速度からの遅延は既存の `ceil(10000×区分%/(速度×100))` tick、最低1。待機の短い／標準／やや長い／長いは75／100／125／150%、詠唱のやや短い／普通／やや長いは75／100／125%。説明に追加待機なしは本作標準100%を採用する。動画の秒数をこの数値へ直接換算していない。

アイコノクラスト技1のWT+30は「巨神獣の次予定を30 tick遅らせる」、自身WT−50%は「今回の通常回復遅延を50%にする」と本作で決めた。命中対象が部位でも巨神獣の行動予定へ適用し、資源の支払成功と攻撃の発動成功を必要とする。別人物の予定は変えず、固有チェインから呼ばない。

### 複数対象とダメージ

単体は選択した本体／生存部位。全体は本体＋全生存部位。範囲は、本体選択なら本体＋最初の2部位、部位選択なら選択部位と配列上の前後隣接部位。破壊済みは除外し、離れた部位で補充しない。範囲の起点が破壊済みなら受付拒否、詠唱中に起点が消失したら不発で自動変更しない。全体は発動時の全生存部位を取り直す。本体への1ヒットと各部位への1ヒットは別HPへ入り、部位ダメージを本体へ重ねない。

一回の複数対象攻撃は費用1回・会心抽選1回（結果は全対象共通）・自己回復／反動／自己強化1回。全対象のダメージを先に計算し、それぞれの物理／魔法防御・防御無視・骨折・HP上限へ適用する。上限は各ヒットごと。UI予測と演出の合計量は実適用量の合計。技の標準上限は10000、確認された上限追加はスレイヤー技3＋100000、アンダーマイン技3＋40000。動画の装備込み上限を本作Lv1上限へ転用しない。

防御軽減は `1000/(1000+有効防御)`。骨折は防御×0.7、防御無視は防御×(10000−無視bp)/10000。会心・技倍率・防御・対象補正を計算して最後に切捨て、最低1、技上限、残HPへ制限する。翠還竜の右翼装甲が有効なとき、通常技の本体ダメージだけを×0.7とし部位へ波及させない。範囲／全体詠唱では発動時の右翼状態を使う。独立固定攻撃は自身の威力・攻撃型・防御無視だけを使い、通常技の部位倍率・右翼用コマンド補正・資源補正を継承しない。

### 状態異常6種と耐性

本体・各部位は独立した状態値を保持する。付与量は発症確率ではない。耐性は状態ごと0〜10000bpで、実蓄積=`floor(付与量×(10000−耐性)/10000)`。10000は完全無効。100以上で発症し、余りを100未満へ保持する。発症回数ぶん持続を加算せず、同じ状態の再発症は残り回数を更新する。初期翠還竜の耐性は全種0。本体・部位ごとの別耐性をCoreへ渡せるが、現行スライスJSONは同じ表を複製する。

| 状態 | 発症後の効果 | 寿命 |
| --- | --- | --- |
| 火傷 | 敵行動機会の前に対象の最大HP2%ダメージ | 3機会 |
| 出血 | 同、最大HP2% | 3機会 |
| 毒 | 同、最大HP3% | 3機会 |
| スタン | 本体は次の敵行動1回を阻止。部位は対応機能を一時停止 | 1機会 |
| 病気 | 本体または攻撃用左翼の発症中、敵の与ダメージ×0.8 | 3機会 |
| 骨折 | 対象の物理／魔法防御×0.7 | 3機会 |

継続ダメージ→勝敗確認→スタン判定→敵行動→残り回数消費。スタンで阻止した機会でも各状態の回数を消費する。本体DoTは本体HP、部位DoTは部位HPだけへ入り、部位破壊効果も通常どおり発生する。死亡対象へ新状態を付けない。部位スタンは角冠のゲージ増加、左翼の攻撃補正、右翼の本体防護、尾の資源妨害を対応部位だけ止める。味方へ付く状態異常や、初期15技にない種類の全面実装を主張しない。
