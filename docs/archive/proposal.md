# 資料分析からの組み合わせ提案

> 2026-09-22整理：正式版の範囲・受入条件は[要件定義](requirements.md)を参照。本書の旧人物・旧人数・仮数値は検討履歴／試作仕様であり、正式版の確定事項へ自動転用しない。

## 結論

採用する基本方針はA案「巨大な空中ボスを、ジョブ連携で討伐し、素材と記憶を集めるRPG」。通常攻撃は自動で進み、プレイヤーは連携の起点と防御のタイミングを指示する。

『巨神と誓女』の討伐・育成・物語収集を全体の骨組みにし、『ANGELICA ASTER』の空中戦とジョブ別の役割を戦闘へ組み込む。ユーザーの「基本はA案でよさそう」を受け、A案を基本方針として採用した。人数、時間、連携条件などの詳細は試作用の提案であり、確定事項と区別する。最新の具体案は[戦闘仕様](battle-spec.md)を参照。

## 資料から残したいもの

### 1. 巨大な敵を見上げる構図

ユミル戦の抜粋は、敵と味方の大きさの差だけで挑戦の大きさを伝えている。新作でも敵の全体像を毎回小さく収めず、画面からはみ出すほど大きく見せる。味方は敵の周囲を飛び、部位を攻撃するときだけカメラを寄せる案が合う。

空中戦とジョブ別コマンドは[ANGELICA ASTERの公式発表](https://dmmgames.co.jp/news/detail/id%3D2087)で確認した。手元のクライアントは起動していないため、具体的なカメラ挙動の比較は未実施。

### 2. 連携がつながる楽しさ

ユミル戦の抜粋では、連携数とキャラクターのカットインが目立つ。新作では「崩す → つなぐ → 決める」という役割をジョブに与え、編成と指示が連携の結果に影響するようにする。

例：防御役が敵の装甲を崩す → 支援役が連携を延長する → 攻撃役が翼へ集中攻撃する。この順番と効果は新作向けに考案したもの。

将来的には最初の数手を条件達成で確実に発生させ、追加連携だけに確率を使う案がある。初回試作では確率を入れず、託した人数分の確定連携で判断の手応えを先に検証する。

### 3. 敵を知るために戦う動機

騎士の巨神の録画では、物語を本の見開きで読む演出を確認した。新作にも敵ごとの記憶帳を設け、討伐実績で文章と挿絵を解放する。強化素材だけでなく、物語の続きも次の出撃の動機にする。

重要な物語は初回討伐などの確定条件で解放し、周回では補足の断片を集める案とする。物語の続きが低確率ドロップだけに左右されないようにする。

## 方式の比較

| 案 | 得られる体験 | 検証が必要な点 |
| --- | --- | --- |
| A：自動戦闘＋連携指示（基本方針として採用） | 巨大な敵と演出を眺めつつ、編成と要所の判断で介入できる | 放置だけで勝つ状態と、指示が忙しすぎる状態の中間を探る |
| B：ターン制＋ジョブ連携 | 毎回の行動順や役割をじっくり考える | 素材集めで同じコマンド入力が負担にならないか |
| C：直接操作の空中アクション | 飛ぶことと回避の感触を主役にできる | 操作、カメラ、敵の挙動まで開発範囲が広がり、今回確認した魅力からも離れやすい |

## 最初に作るなら

味方3人・ボス1体で、出撃、連携、翼の破壊、討伐、素材強化、記憶1ページの解放までを一周させる。2Dまたは2.5Dの仮素材で、まず判断と報酬の循環を検証する。空中移動は演出から始め、位置取りが必要かはプレイして決める。

この試作で「もう一度戦いたい」と感じるかを確かめてから、人数やボス、育成分岐、3D演出を増やす。エンジンや配信先はまだ決めない。

## 分析の限界と次の確認

初期提案はローカル2動画の静止画抜粋と公開情報に基づく。その後、戦闘2動画を時系列で追加分析し、[戦闘録画メモ](../references/battle-observations.md)に記録した。289本全体、音楽、キャラクターごとの物語、ANGELICA ASTERの実プレイは未分析。

追加分析ではリング表示から連携表示への流れを確認した。AUTOと手動入力は区別できず、操作頻度や託すの正確な挙動は未確定。ANGELICA ASTER側の実プレイ比較を残しつつ、A案の試作では操作量と連携判断を検証する。
