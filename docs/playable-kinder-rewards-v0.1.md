# キンダーガーデン報酬・重複強化 v0.1

更新：2026-10-01（日本時間）。Unity縦切りの報酬と育成を接続する。

## 修正した問題

素材系の抽選は石と回数だけを更新し、名前を表示しても素材を付与していなかった。表示と所持量が一致するよう、素材付与と抽選確定を一つの処理にする。結果文が保存メッセージで置換され、モーダルの背後に隠れる問題も修正した。

| 枠 | 確率 | 実際の報酬 |

| ★6誓女 | 合計3%・5人各0.6% | 重複強化用1個。本人が強化上限なら汎用強化素材1個 |
| 素材枠1 | 24.25% | 共通素材4 |
| 素材枠2 | 24.25% | 共通素材6 |
| 素材枠3 | 24.25% | 共通素材8 |
| 素材枠4 | 24.25% | 共通素材10 |

素材枠の内訳・数量は縦切り検証値。正式版の素材／オーパーツ混合プールはTBD。未接続の「オーパーツ結晶」「世界の記憶」を獲得したという表示を、実際に加算する共通素材の表示へ置換した。共通素材は育成・覚醒・武器の樹・家具制作の既存台帳へ加算する。

- 1回あたり石1個。100回ごとの任意交換は継続。
- 乱数は`0以上1未満`で抽選する。Unityの整数乱数で生成し、上端1を含む`Random.value`は使わない。
- 不正乱数、石不足、素材／変換先の所持数オーバーフローで拒否した場合は、石・抽選回数・交換回数を消費しない。
- 素材台帳がない呼び出しで素材報酬を引いた場合も拒否し、表示だけの未付与を防ぐ。
- 抽選結果、所持素材、所持石、交換可能回数をモーダル内へ表示する。保存失敗時のメッセージも同じ位置に表示する。

## 重複強化

- ヒロインしおりで所持重複を1個消費し、重複強化段階を1上げる。
- 縦切りでは上限5段階、1段階につき最大HP＋10・攻撃＋2。正式段数・数値・固有特性はTBD。
- 強化値は出撃時の戦闘ステータスへ反映し、詳細面にも表示。チェイン確率は変化しない。
- 上限到達後の新しい重複は抽選・任意交換の時点で汎用強化素材へ変換する。
- すでに所持していた余剰重複も、同じボタンで1個ずつ汎用素材へ変換できる。
- 汎用素材は上限未到達の任意のヒロインに使用できる。素材1個で同じ強化段階を1上げる。
- 未所持素材、最終上限、無効な人物指定で状態を変更しない。本人の所持状態・覚醒Lvは減らさない。

## 保存・互換性

保存契約v2へ`heroineTraitRanks`と`overflowEnhancementMaterials`を追加。既存セーブでは強化段階0・汎用素材0に補完し、所持重複数を保持する。自動で過去の重複を消費しない。

異常な交換済み回数は累計抽選から可能な回数までに制限し、交換残数が負にならないようにする。素材獲得履歴のない旧セーブは、既存の所持素材をそのまま保持する。
