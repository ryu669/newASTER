## 弱体化と難易度

本体「メイン作戦について」全7ページとB28-2の弱体化詳細を確認した。

- 通常作戦の評価はクリア時の生存天使数で変わる。最高評価でスキップが使えるようになり、難敵戦が解放される。
- 難敵戦クリアで血死戦が解放される。
- 弱体化作戦をクリアすると関連する作戦へ効果を与える。効果の例は敵パラメータ低下。発動／無効を切り替えられる。
- **B28-2の難敵戦選択時に、W28-2クリアによる「神獣の最大HPの基礎値が-30%」を確認。** すべての弱体化作戦が同じ効果とは扱わない。
- 天壊戦はエピソード進行で解放され、行動力を消費しない。専用のG付き特性、パラメータ・スキルの変化がある。

以前の「弱体化の対象と効果が不明」は、B28-2の上記条件について解消した。難易度をまたぐ適用差、クリア状態の期限については未確認。

## オーパーツの周回育成

イベント「RELICHUNTについて」全7ページを確認した。このイベントの条件を恒常作戦全体へ一般化しない。

- 作戦クリアでオーパーツが100%ドロップするとの説明。
- プラス値はパラメータを上げ、上位の値で上書きしていく仕組み。単純に取得値を加算するとは説明されていない。
- 挑める作戦は日替わりで、更新は5:00。カレンダーに対応するオーパーツが示される。
- 作戦クリアごとに専用ゲージが上昇。満タンでドーンブレイクが発生し、次の作戦で多くのオーパーツが落ちる。具体的な上昇量・倍率は未確認。
- 高難易度ほど大きなプラス値のオーパーツが出やすい。
- 対象のドロップUP天使を部隊に編成してクリアするとドロップ数が増える。サポート天使には適用されない。
- オルガノン注入では、好きなオーパーツのパラメータを選んで強化できる。最大レベルかつ一定のプラス値への到達が必要。利用はイベント開催・報酬受取期間中に限られる。
- 最大レベルは★3が55、★4が70、★5が80、★6が90と説明。
- **プラス値が最大になったステータスは、次回以降のプラス値抽選から除外される。** 残りの能力の抽選確率の具体的な配分までは不明。

## ファイターの未確認点を補足

T-FTR演習の案内と「ファイターその1」全3ページ、「その2」全2ページ、「その3」全3ページを確認。

- ブースト球は本人の行動順が来るたびに1個増える。最大蓄積・消費は5個。
- 通常モードと捨て身モードを切替可能。捨て身では攻撃力・速度が上がり、防御力・魔法防御力が大きく下がる。
- 通常球より効果の大きい赤いブースト球が時々出る。出現確率や厳密な解放条件は未確認。
- エイプリルの同一対象・同一スキル「開墾の導」の選択中に、通常モードの予測536から捨て身で669へ変化。そのまま球を1、2、3個と指定すると811、953、1236になった。3個目は赤い球で、スキル説明の攻撃力倍率は100%→120%→140%→180%。これは当該演習条件の例であり、全スキルの共通式ではない。
- モード切替と球指定の間に行動を確定せず、同じ対象選択画面で予測を比較できた。
- 覚醒段階2では、球を3個以上保持すると「ブーストマスター」によるパラメータ上昇が続く。赤い球が多いほど効果が高い。保持による継続強化と、消費による瞬間火力の選択になる。
- 球の消費でラストリゾートのゲージが増え、赤い球は増加量も多い。満タンで使用でき、効果は天使ごとに異なる。行動順を消費しない。
- 演習のスレイヤーではラストリゾートが速度+50%・クリティカル+50%、各3ターン。予告を見て再度押すと発動し、ゲージが空になった。演習では説明用にゲージを満タンにしており、自然蓄積の必要量を測定したものではない。

## AutoとFullAuto

戦闘のPause→Help→「Autoについて」全5ページを確認。実戦で全ジョブの自動挙動を再現検証したものではなく、本体ヘルプに記載された仕様。

- Autoはスキルを自動使用する。FullAutoでは、さらに指定されたジョブコマンドを自動使用する。
- **FullAutoでも全コマンドを使うわけではない。** パンツァー、ヒーラー、ギャンブラー、アーティストはジョブコマンドを使用しないとの記載。

| ジョブ | 記載されたFullAutoの条件・動作 |
|---|---|
| ファイター | ゲージ最大でラストリゾートを最優先。球5個以上で球を全消費 |
| ディフェンダー | ガーディアンズソウルゲージ最大で敵陣籠城を最優先 |
| スナイパー | ゲージ最大でエンドオブスカイを最優先 |
| チェイサー | スロットル最大でニトロを最優先 |
| バーサーカー | ゲージ最大で「あばれる」を優先。その後「あばれ散らかす」が使えれば最優先 |
| ブラスター | マジックゲージ最大で「禁呪：3連続行動」を最優先 |
| ガンナー | ゲージ最大でバレットタイムを優先。無差別バレットタイムは最優先と記載 |
| ジェネラル | ゲージ最大で大号令を最優先。激励が使用可能なら使用 |
| アルケミスト | 自動錬成が最大なら全使用。錬成残り回数が錬成枠最大数以上なら発動 |

ガンナーの通常／無差別の選択条件の詳細はこのページだけでは確定できない。

## ヒーラー：資源と行動のコスト

T-HLRの導入説明とラプチュアのアビリティ選択を操作した。

- 自分のターンになるとハートが1個増える。使えるハートアビリティは天使ごとに違う。
- 右端のハート数は必要個数、砂時計のアイコンはターンを消費することを示す。資源コストと行動コストは別に表示される。
- 演習のラプチュアはハート枠が3個。単体魔法攻撃の小・中・大がそれぞれ1・2・3個、毒・火傷・出血の消去が1個と表示。いずれも砂時計付きだった。全ヒーラーの共通メニューとは扱わない。
- 単体魔法攻撃・小を選ぶと、攻撃力80%の魔法攻撃、ターン消費ありと表示された。敵を選んだ状態で予測ダメージ134・クリティカル5%を確認して確定した。これらの数値はこの演習の条件に限る。
- 「ヒーラーその1」全6ページも確認。危機時の支援は自動発動し、効果は天使ごとに違う。演習のブラッドベリー「ピンチに回復」は、味方HPが1/4以下になると初回100%、以後低確率で発動し、攻撃力100%で味方1体を回復する説明。実際にラプチュアへの回復演出を確認した。FullAutoのジョブコマンド使用とは別の自動発動として区別する。
- 覚醒段階1でアビリティが追加される。「永続」は戦闘終了まで持続する意味。ブラッドベリーの「最大HP50%アップ（永続）」は、ハート2個、自身の最大HP基礎値+50%、使用可能回数1回、ターン消費なしと表示。演習で使用した。
- 使用後の最大HPは1082→1623になった。続く案内では「ワンモアハート」により一定確率で追加のハート1個を得ると説明された。具体的な確率は未確認。
- 「その2」全3ページ、「その3」全3ページまで確認。極まれに出るHa-toは1個でどのハートアビリティにも使え、通常のハートより優先消費される。出現率は未確認。
- 覚醒段階2では、攻撃などの行動によってハートを増やすアビリティが追加される。シヴァの画面に「攻撃でハート+1/2（永続）」「回復でハート+1/4（永続）」を確認。獲得経路への先行投資という構造になる。
- 禁忌ハートアビリティは高コストの強力な効果。シヴァでは回復限界突破、ハート上限突破、攻撃力30%アップ、スキル効果20%アップを確認した。内容は天使ごとに異なる。今回は禁忌の実行・上限増加量の測定はしていない。
- **ヘルプ内の例示画像と実際の選択画面には差があった。** 「その2」1/3の例示画像では最大HP50%アップに砂時計・ターン消費あり、実際のブラッドベリーの選択画面では砂時計なし・ターン消費なしだった。現行の演習条件の記録には実際の選択画面を採用し、ヘルプの例示数値やアイコンをそのまま現行共通仕様と扱わない。

## A案への示唆（独自提案）

1. ボス攻略前の寄り道は、どのボスの何を弱めるかと数値を明示する。クリア後も無効化して挑める仕組みは、育成が進んだ後の再挑戦にも使える。
2. 周回成長には、より良い値で更新する方式と、好きな能力を選んで伸ばす方式を組み合わせる候補がある。既存試作の素材によるレベル強化とは別方式として比較する。
3. 上限到達した能力を抽選対象から除く仕組みは、育成後半の無駄を減らす候補。抽選確率や必要周回数は新作向けに設計する。
4. A案の「発動／託す」には、資源を残す利益と使う利益を見える形にする。ファイターの保持強化は参考になるが、新作で同じ球・名称・数値を採用する必要はない。
5. 自動戦闘がどの技・資源を使うかを明示する。基本技を自動、連携の発動を手動とする現在のA案では、手動用の資源を勝手に消費させない方針が候補になる。
6. 技の予告には威力だけでなく、消費資源と次の行動までの遅れを並べる。支援役にも攻撃・回復・解除の選択を持たせる場合、操作を増やす前に「発動／託す」の判断へ集約できるかを試す。
