# シャングリラ — 物語作成用の人物記録

`heroine.shangrila`、スナイパー。参照名ダリア・サングリア。newASTERでは30歳の成人。

## 概要・性格

人物映像の紹介では、過酷な企業で働いていた過去、大きな感情の振れ、徹夜明けの大胆さと弱気な時の落ち込みが示される。温かい布団で眠ることが好きで、労働を嫌う。強がる言葉の下に疲れがあり、自分の自由を取り戻したい。本作では、働いた成果を否定せず、もう受け取らない命令や帰る時刻を自分で選ぶ人物として描く。主人公は彼女を仕事へ戻す役ではなく、断ることと休むことを話し合える相手。過去を捨てる速さを、回復や愛情の証にしない。

## 口調

一人称「私」、相手は「あんた」。短く率直で、苛立つと「ふざけんな」「うるさい」と強い言葉が出る。常に叫ばせず、信頼する相手には「それなら、少し付き合う」「あんたが好きだ」と落ち着いて言う。眠りや布団の話では気負いが落ちる。台詞例は創作。人物映像の紹介と表示台詞を参考にし、全音声の逐語書き起こしは実施していない。

## 外見・天使の要素

短い銀白髪と桃色の毛先、赤い瞳と細い赤の角型眼鏡、黒と紅の角。黒いスーツ、白いブラウス、赤いネクタイ、黒いパンツと大型の黒い銃を保つ。本作の新規美術ではブラウスを閉じ、腰も覆う。暗い羽根に紅色の機構と金の装飾を重ねた翼、割れた紅金の光輪を加える。疲れの見える成熟した顔と小さな皮肉の笑み。立ち絵・戦闘・SD・CGで髪、眼鏡、角、色を揃える。

## スキルの出典

`050戦闘_シャングリラ.mkv` の15秒、Lv7表示を本作のLv1基準へ採用する。HP・基礎攻撃・成長率・待機数値・ジョブ操作の数値は本作の設計。

- 「社畜にも五分の魂」：単体物理178%・銃弾。行動後に自身の最大HP20%の反動。
- 「ハードボイルドショット」：単体物理126%・銃弾、出血蓄積30。攻撃後、自身を基礎攻撃45%分回復。
- 「血意のクリティカ魔弾」：単体物理666%・銃弾。自身の攻撃35%低下・2ターン、行動後に最大HP40%の反動、長めの待機。スキル育成で自己攻撃低下の割合は悪化しない。

スナイパーは編成で支援対象を1人指定し、その人物の実際の攻撃へ非再帰の支援射撃を行う。支援は資源・通常WTを消費しない。自身の通常行動で狙撃+3、MAX15で狙撃モード。200%待機の詠唱中は他の味方全員を支援し、開始時の攻撃・会心を使う5倍弾を放つ。発射後は150%待機、通常の指定支援へ戻る。詠唱中の死亡・行動不能・対象消失で中断し、自動で別の対象へ撃ち直さない。

## 物語の扱い

3章30ページ・18詩・5イベント。黒煙城塞の命令と退出票、天塔機神の交代記録、死人王の門と帰還を接続。毛布、終電の記憶、互いの告白、雨の日の休息、二冊の予定帳を通じて、恋愛を働いた分の報酬にしない暮らしを描く。好感度10のイベントで相互の告白が成立する。
