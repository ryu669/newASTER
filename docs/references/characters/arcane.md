# アルケイン — 物語作成用の人物記録

`heroine.arcane`、ガンナー。newASTERでは27歳の成人。参照名イェニー・プレスタイン。学園衣装も同じ成人が思い出の衣装を着る形態であり、別人として扱わない。

## 概要・性格

冒険に憧れる名門貴族のお嬢様。オーパーツが好きで、自分のための博物館を作り、探索隊を率いて未知の遺物を得たいという夢を持つ（人物映像の紹介）。興味が湧くと準備より説明が先へ進む。物の由来と使った人を調べ、仲間の帰還を成果に含めるようになる点は本作の創作。財力や知識で仲間の意思まで決めない。展示札の空欄を認め、次の調査者へ手掛かりを渡す。

## 口調

一人称「わたくし」、相手は「あなた」。「ですわ」「ですの」「では、参りましょう」。胸を張って具体的に語り、知識を見せる場面でも相手の質問を待つ。気持ちを伝える時は勢いを落とし、短い言葉を使う。「あなたが好きですわ。相棒としてだけではなく」。例文は創作。声の音声解析・逐語書き起こしは実施していない。

## 外見・天使の要素

長いマゼンタの巻き髪、金色の瞳、白い帽子と桃色のリボン。灰色のコート、白い高襟のレースブラウス、黒い長いスカート、桃色の鞄。青緑と金の杖、時計機構・馬型遺物の意匠を保つ。白い羽の翼に金の機構と青緑の装飾、頭上の金の光輪。成熟した顔立ちを統一し、通常版と学園版で髪・目・顔を揃える。

## スキルの出典

戦闘映像15秒のLv7表示で確認できるのは「レッツアドベンチャーですわ！」（単体物理208%、銃弾、長めの待機）のみ。これを本作のLv1基準へ採用。「遺物の見取り図」（全員会心率15%・3ターン）と「博物館の守り手」（全体物理150%・銃弾/光・防御25%無視）はnewASTERの創作。データの `ruleOrigin=newaster-original`、観察Lv=0、出典ファイル空欄で区別する。通常攻撃は弾倉1発を使い、弾切れ時にRELOAD、ゲージMAXで選択弾倉の全弾射撃。

## 物語の扱い

3章30ページ、18詩、5イベント。博物館の空欄、探検隊の帰還、隣で好きなものを話す時間を描く。告白後は「夢のために相手を待たせる」前提にせず、連絡・帰還・相手の生活を話し合う。学園版の回想は通常版の記憶を消さず、同じ二人の関係として読む。
