# アルケイン（学園） — 物語作成用の人物記録

`heroine.arcane-academy`、ギャンブラー。人物IDは通常版と共通の `heroine.arcane`。newASTERでは27歳の成人で、卒業後に学園の資料と衣装を使い直す形態。好感度・恋人関係は共有し、育成・神器・読了は衣装ごとに管理する。同じ人物を同時に編成・同じ庭へ配置しない。

## 概要・性格・口調

好奇心の強い名門貴族の遺物収集家。夢は自分の博物館と探検隊。自信に満ちて先へ進みたがるが、学園版の物語では未確定の仮説や外れの記録も残すようになる。偶然の発見を喜び、発見後の保存・返却・検証も引き受ける。一人称「わたくし」、相手は「あなた」、「ですわ」「ですの」。通常版と人格を変えず、疑問を受け止める間を増やす。例「まだ正解とは言えませんわ。あなたの見方も、隣に書いてくださいませ」は本作の創作。音声の逐語書き起こしは未実施。

## 外見・天使の要素

通常版と同じマゼンタの巻き髪、金色の瞳、成熟した顔。赤と金の上着、高襟の白いブラウスと黒いリボン、白い裾飾りの濃色プリーツスカート、不透明な黒タイツ。帽子は被らず、小さな金の髪飾り。青緑に発光する大きな魔導書。白い羽と時計機構、書棚、青いガラスを組み合わせた翼、金の光輪を持つ。制服の意匠を成人の卒業生として描く。

## スキル・ジョブの出典

`013戦闘_アルケイン学園.mkv` の15秒、Lv7表示を参考に以下を本作のLv1基準へ採用する。成長率・待機数値・抽選分布・強化倍率は本作の設計。

- 「レッツ飽和攻撃ですわ！」：単体物理320%・斬撃/刺突、出血蓄積120、敵待機+60。発症中の毒・火傷・出血を2ターン延長。未発症の蓄積だけでは延長しない。
- 「ワールドイズマインですわ！」：敵全体物理240%・銃弾/火。本体にだけダメージ80%加算、味方の有効な正の効果を1ターン延長。

通常の3スキルボタンでは選ばず、SLOTを使う。6種の記号を9マスへ一様抽選し、3行と2対角の全5ラインを評価。同じスキル記号が左・中央に揃えば発動、3つ揃えば倍率1.5倍。777の各ラインで3スキルをそれぞれ2回。重複ラインも全発動する。果物だけの全外れは資源消費なし・WT0で再抽選できるが、状態異常の待機ペナルティは免除しない。
