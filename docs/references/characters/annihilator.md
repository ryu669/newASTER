# アナイアレイター：人物・口調・意匠資料

通常版と聖夜版は同じ一人の天使。人物IDは `heroine.annihilator`。衣装形態IDは通常版 `heroine.annihilator`、聖夜版 `heroine.annihilator-holy`。

## 映像で確認したこと

資料は指定された009／010の人物・戦闘動画4本。抽出時刻と長さは `tmp/plan10-annihilator/reference/sampling.json`。人物画面の冒頭と戦闘5秒付近を中心に照合した。全ボイス・全詩の逐語調査ではない。

通常版はFIGHTER、聖夜版はHEALER。黒髪の前髪、赤い目、黒い羽根と赤い縁取りが共通。通常版は鬼面、角、彼岸花、紅い蝶、黒・臙脂の和風衣装、白い毛皮、金の装飾、青緑の帯、三日月状の大きな鎌。聖夜版は赤白の毛皮衣装、緑のリボン、白い脚衣、鹿の角と面、鈴、贈り物と星の光。

通常版の概要には、人を寄せつけない雰囲気と、花や植物を世話するときの柔らかさがある。聖夜版の概要には、帝国への復讐心と仲間への愛の間の葛藤、嫌う文化にも美味しい香辛料の料理があるという矛盾が描かれている。

スキル名は通常版「撃滅の宣告」「紅き地獄蝶の誘い」「鬼面新境・曼珠沙華」。聖夜版「ひとひらの愛」「仲間たちへの贈り物」「破壊者より哀を込めて」。画面右端の切れたチャージ条件は未確定。画面に出た別名やCVの文字を人物の本名として採用していない。

## 本作向けの独自設定

概要：破壊の力で他者を遠ざけてきた黒翼の天使。新しい星で花を育て、力を使わず守る仕事と、人に任せることを覚える。聖夜では、過去を忘れずに仲間へ温もりを渡す。同じ恋人関係が衣装を越えて続く。

性格：用心深く、責任を自分に集めやすい。脅す外見と簡潔な返事で距離を作るが、植物の世話は細やか。失敗を認め、具体的な助言は受け取る。優しさを大げさな宣言にしない。憎しみが残ることと、いまの仲間を大切にすることを両立する。

口調：独自の執筆方針として一人称「私」、主人公へ「あなた」。落ち着いた丁寧語、短い文、質問に答えてから付け足す。苛立つ場面でも連続した罵倒は使わない。照れは話題を作業へ戻すことで表す。花の話では具体的な量や待つ時間が増える。聖夜でも陽気な別人格にはしない。

台詞例：「多ければよいものではありません」「思い出せたら、話します」「服が変わっただけです」「帰ったら、また花を見ましょう」。これらは本作の創作台詞であり、映像の引用ではない。

避ける描写：白翼への置換、鬼面と花の省略、聖夜版の別人化、主人公による過去の赦しの強要、回復力で心の傷まで即座に消す描写、衣装を替えるたびに恋人を作り直す描写。

## 物語の接続

通常版3章は「黒翼の下の花壇」「刃を置く場所」「帰るための曼珠沙華」。聖夜版3章は「黒翼の贈り物」「憎しみの傍らの灯り」「雪解けの祝福」。緑還竜・銀海鯨・天塔機神の記憶を、本作の庭と帰還の約束へ結ぶ。原作の帝国そのものを本作の国家として持ち込まない。

各形態に30ページ、18詩、交流5本。告白と恋人後の関係は同一人物の意思として記述する。好感度と恋人フラグは所持している同人物の形態間で共有。章・詩・交流の既読、Lv、覚醒、スキルLv、神器は形態ごとに別。
