## A案への具体的な組み込み方

以下の名称・効果・解放条件はnewASTER向けの独自案。

### 1. 連携の「人数」に「順番」の価値を加える

1人1枠の遺物を、常時の数値補正だけでなく、その人の技に付随する効果として扱う。

- 支援型：本人の技の後、次に発動する味方の技を強化する。
- 防護型：本人の技で味方に短時間の防壁を与える。
- 破砕型：部位を狙った本人の技を強める。

例えば「支援 → 射撃」なら部位破壊を狙いやすくなる。一方、大技が迫る場面では防護を単独で即発動する価値がある。発動前に予約順と追加効果を表示し、途中発動・託すの結果を読めるようにする。

これだけでは最大連携一択を解消できない。敵の予兆と短い攻撃機会を併せて検証し、即発動で味方を救えるケース、連携まで待って部位を壊せるケースの両方を作る。

### 2. 討伐報酬を装備の成長へつなぐ

最初はランダムな多項目厳選を導入せず、ボス素材で遺物を段階強化する。翼素材は破砕型、本体素材は防護型など、倒し方と用途を結び付ける。

強化画面では「現在 → 強化後」と追加効果を並べる。原作画面の比較しやすさを参考にする。重複装備の合成、ランダム能力、複数の強化通貨は、この小さな循環が成立してから検討する。

原作では、観察した入手時の合成画面とは別に、素材と通貨を使うレベル強化画面も確認できた。新作で両方を同時に導入すると説明と育成負担が増えるため、初期段階では強化経路を一本にする。

### 3. ボス1体の周囲に小さな作戦マップを置く

試作の次段階は、ボスへ直行する道と、準備戦を通る道の2本でよい。準備戦を終えると、その周回のボス大技を弱める案を比較する。報酬差は事前表示する。

ここでは「弱体化作戦」という原作のマップ上の存在を参考にするだけで、効果の再現ではない。準備戦を毎回必須にせず、育った編成なら直行できる選択を残す。ボス初勝利の先に記憶ノードを置き、『巨神と誓女』由来の断片収集とつなぐ。

### 4. 演出は連携の流れに合わせて短くつなぐ

通常時は敵と味方を見渡し、技で本人へ接近し、連携の終わりに敵全体へ戻す。強化演出は効果名を短く示して次の攻撃へ渡す。初回のボス登場には専用演出を用意し、再戦では短縮可能にする。

原作のCritical・Back Attack表示を参考に、新作ではまず「部位特効」「次の味方を強化」「大技まで何秒」といった確定情報を優先する。背面確率や位置ルールを、そのまま新しい管理項目として増やす必要はない。

## 前回案からの優先順位の更新

1. **遺物3種＋予約順の表示**：既存3人のまま、連携する順と即発動の価値を検証。
2. **射撃の準備状態＋敵の短い隙**：原作のリロードとは区別した独自ルールとして検証。
3. **部位素材による遺物強化**：討伐と編成改善をつなぐ。
4. **小さな作戦マップ＋記憶ノード**：直接挑戦と準備の選択を作る。
5. **接近・帰還演出、拠点会話**：戦っている人物と帰る場所を印象付ける。

多数のジョブを一度に追加するより、3人と3種の遺物で判断が変わることを最初の到達点にする。次に原作側で詳しく確認するなら、ジョブのヘルプ、オーパーツの発動条件、合成ルール、弱体化作戦の説明が優先。現時点の観察から未確認部分を断定しない。
