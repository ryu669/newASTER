### リング前後を1秒ごとに確認した区間

| 時刻 | 観察 |
| --- | --- |
| 1:28 | 通常の戦闘画面 |
| 1:29 | 右上に小さなリングが現れる途中の画面 |

| 1:33 | 大きなリングが消え、候補付近に光の演出 |
| 1:34～1:35 | 文字演出、顔のカットインへ移る |
| 1:36 | 3 Link表示 |
| 1:37～1:39 | 16 Link表示と複数の顔・技名・攻撃表現 |

この例ではリングの拡大表示を複数秒確認でき、消えた後に連携数が増える。しかし「ユーザーが何秒考えて押したか」「託すを選んだか」「AUTOが選んだか」は判別できない。リング周囲の色も、単なる残り時間なのか確率・別の指標なのか確定しない。

## 今回確定できないこと

- 手動で発動・託すを押した回数とタイミング。
- ゲーム速度の設定。録画秒をそのままゲーム内秒数に換算できない。
- 連携の正確な抽選・継続条件、同一人物の再参加条件。
- 1戦全体における指示機会の総数。
- 各カットインの技名・効果・発動順の完全な対応。
- ANGELICA ASTERの実際の操作間隔とカメラ挙動。

## 新作への反映

巨大な敵と小さな味方の構図、必要な場面だけ現れる指示UI、連携の人数と顔を重ねる演出、結果からリトライへ戻る流れを取り入れる。

原作の抽選式を推測して再現するより、試作では「託すと参加者が増える」という結果が説明しやすいルールで検証する。原作でリングが見えた35録画秒間隔は採用値にせず、新作の12戦闘秒という仮設定と明確に区別する。

抽出画像・抽出用スクリプトはローカルの`.reference-analysis/`に保存し、Gitの対象外としている。
