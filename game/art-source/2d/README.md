# 計画7の合成用編集元

SVGは元PNGを外部参照し、背景3層、敵の本体と4部位、通常立ち絵と表情の顔領域を独立レイヤーにする。InkscapeなどのSVG編集ソフトでレイヤーの表示、順序、位置、マスクを編集できる。画像の画素は変更していない。リポジトリ内の相対位置を保って開く。

合計8点。背景1点、敵1点、表情3点に加え、庭園の座る／作業／眺める3点を保持する。庭園は家具の背面、SDの背面、家具の前面、SDの手元をゲームと同じ順序で重ねる。前面が不要な動作はそのレイヤーを省く。SVG内の`defs`にある前後マスクの輪郭と、各レイヤーの`transform`で重なり・位置・倍率を編集できる。

`tools/export-plan7-composition-sources.ps1` でゲームの敵マニフェストから再生成する。敵の負のdrawOrderを本体の後ろ、それ以外を前へ並べ、同順位はpartId順とする。背景は遠景・中景・前景順。表情のクリップは実装と同じ左上基準 `(435,178,111,98)` px。

庭園は `tools/export-plan7-garden-sources.ps1` で `GardenArtComposition.cs` の接地基準・人物倍率・輪郭から再生成する。`garden-composition-records.json`に元コードのSHA-256と各動作の位置・倍率・輪郭数を記録する。人物と家具の元PNG全域が入るよう合成キャンバスを広げる（座る1504×1583、作業1254×1268、眺める1912×1254）。これは原画の画素数を増やす処理ではない。SVGの編集だけではゲームへ反映されず、再生成で上書きされるため、実装へ採用する変更は元コードの基準とマスクにも反映する。

キャンバスは原本の実寸（敵1254×1254、背景1672×941、人物1024×1536）を維持する。SVGの拡大書き出しを、納品解像度を満たす新規原画として扱わない。各PNG内部の髪・肌・衣装・筆致などの描画レイヤーは復元しておらず、絵の編集元納品条件は引き続き未達。これらは候補の合成作業を再現・編集するためのファイルである。
